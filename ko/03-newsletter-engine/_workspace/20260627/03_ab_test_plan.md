# A/B테스트 & 발송 최적화 계획

## A/B테스트 설계

### 테스트 1: 제목 (Subject Line)
- **변형 A**: 손흥민은 교체로 나왔고, 한국은 졌다 — 그래도 아직 끝이 아니다
- **변형 B**: 한국 1승 2패로 조별리그 마감 — 와일드카드, 남은 8장 중 하나를 잡을 수 있나
- **가설**: 스타 선수(손흥민) 서사와 감성적 긴장감을 담은 A안이 팩트 중심의 B안보다 오픈율이 높을 것이다. 축구 팬은 결과 수치보다 스토리에 반응하며, 대시(—)를 이용한 반전 구조("그래도 아직 끝이 아니다")가 호기심을 자극한다.
- **측정 지표**: 오픈율
- **테스트 비율**: 전체 구독자의 20% (A: 10%, B: 10%)
- **승리 기준**: 오픈율 차이 2%p 이상
- **최소 샘플**: 각 변형 최소 **1,000명 이상** (통계적 유의성 95%, 검출력 80%, 기준 오픈율 22%, 최소 감지 효과 2%p 기준. 총 발송 10,000명 이상 구독자 리스트 보유 시 유효)
- **테스트 기간**: 발송 후 **4시간** (긴급 뉴스 특성상 오픈 대부분이 첫 2~4시간에 집중)
- **결과 해석 가이드**:
  - A안 승리 → 스포츠 팬 감성 서사 접근이 유효. 이후 발행에서도 선수 개인 서사 헤드라인 우선 채택
  - B안 승리 → 정보 탐색 욕구가 강한 구독자 구성. 숫자·경우의 수 중심 팩트형 제목 전략으로 전환
  - 차이 2%p 미만 → 통계적 무결론. 다음 호 동일 구조로 재테스트 또는 프리헤더 조합 변수 추가
  - **주의**: 발송 시점이 경기 종료 직후인지 다음 날인지에 따라 긴박감 체감이 달라지므로 발송 시각을 기록·통제할 것

### 테스트 2: 인트로 프레임 (감성형 vs 팩트형)
- **변형 A**: 감성 유도형 — 손흥민 교체 투입 서사를 선제 배치, 4번째 월드컵이라는 맥락을 감정 앵커로 활용한 뒤 와일드카드 긴장감으로 전환
- **변형 B**: 팩트 선제형 — "0-1 패배, 1승 2패, 조 3위"로 시작, 와일드카드 8장 경우의 수를 표·수치로 즉시 설명
- **가설**: 고관여 독자(경우의 수 정보 탐색형)는 B안에서 더 깊이 스크롤하고 클릭률이 높을 것이다. 반면 감성형 독자는 A안에서 체류 시간과 공유율이 높을 것이다. 총 클릭률은 구독자 구성비에 따라 달라지나, 와일드카드 대기 시점이라는 긴박한 정보 욕구로 인해 B안의 CTA 클릭이 더 높을 가능성이 있다.
- **측정 지표**: 클릭률(CTA 클릭), 스크롤 깊이(픽셀 기준 50% / 75% / 100% 도달률), 메일 내 링크별 클릭 히트맵
- **승리 기준**: CTA 클릭률 차이 0.5%p 이상 또는 스크롤 75% 도달률 차이 5%p 이상
- **결과 해석 가이드**:
  - A안 높은 스크롤 + B안 높은 CTA → 독자 층이 분리됨을 시사. 향후 세그먼트별 맞춤 인트로 전략 적용
  - B안 전면 우위 → 뉴스 요약·경우의 수 포맷이 이 구독자군의 핵심 수요. 정보형 콘텐츠 강화
  - A안 전면 우위 → 스토리텔링 리드가 유효. 손흥민 외 다른 선수 서사도 테스트 후보
  - **주의**: 이메일 클라이언트에 따라 스크롤 추적 정확도가 다를 수 있음. 픽셀 트래킹 지원 여부 사전 확인 필요

### 테스트 3: CTA 문구
- **변형 A**: FIFA 공식 순위 및 일정 확인
- **변형 B**: 와일드카드 현황 실시간 확인 →
- **가설**: "실시간"과 "→" 화살표를 포함한 B안이 긴박감과 행동 유도력이 더 강해 클릭률이 높을 것이다. 실시간성이 핵심 가치인 긴급 뉴스 발행에서 "실시간"이라는 단어는 독자의 FOMO(놓칠 것 같은 두려움)를 자극하며, "→"는 시선 유도 및 클릭 의도를 높이는 시각 신호다.
- **측정 지표**: 클릭률
- **승리 기준**: 클릭률 차이 0.5%p 이상
- **결과 해석 가이드**:
  - B안 승리 → 이후 CTA에 "실시간", "→", "지금 확인" 등 긴박감·행동 유도 언어 표준화
  - A안 승리 → 공식 정보원 신뢰도("FIFA 공식") 프레이밍이 이 구독자군에게 더 설득력 있음. 권위 있는 출처 명시 전략 유지
  - 차이 0.5%p 미만 → 무결론. CTA 위치(본문 중간 vs. 하단) 또는 버튼 색상 변수를 다음 테스트에 추가
  - **주의**: A/B 인트로 테스트(테스트 2)와 CTA 테스트를 동시 진행 시 교락(confounding) 발생 가능. 구독자 그룹을 명확히 분리하여 운영할 것

## 발송 최적화

### 권장 발송 시점 (긴급 뉴스 특성 반영)
| 순위 | 요일 | 시간대 | 근거 |
|------|------|--------|------|
| 1 | 경기 당일(평일/주말 무관) | 경기 종료 후 **30~60분 이내** | 관심 피크 시점. 검색·SNS 트래픽이 최고조이며 이메일 오픈 의향도 가장 높음. 긴급 뉴스는 뉴스성 소멸이 빠르므로 즉시 발송이 핵심 |
| 2 | 경기 다음 날 | 오전 **07:00~08:30** | 출근·통학 전 모바일 확인 습관 시간대. 전날 경기 결과 재확인 및 와일드카드 상황 파악 욕구가 남아 있어 오픈율 2위권 |
| 3 | 경기 다음 날 | 오후 **12:00~13:00** | 점심시간 모바일 탐색. 당일 오전 발송 대비 오픈율은 낮으나, 오전 발송을 놓친 구독자의 보완 타이밍 |

> **긴급 발송 원칙**: 경기 종료 후 60분을 넘기면 주요 포털·SNS가 결과를 소화하여 이메일의 독점적 정보 가치가 급감한다. "경기 종료 30분 이내 발송" 목표를 SOP(표준운영절차)로 설정 권장.

### 세그먼트 전략 (BEAR 모델)
| 세그먼트 | 특성 (BEAR) | 맞춤 콘텐츠 | 발송 시점 |
|---------|------------|------------|----------|
| **코어 팬** | Behavior: 이전 스포츠 메일 전체 오픈·클릭 / Engagement: 높음 / Affinity: 월드컵·축구 태그 / RFM: 최근·반복 수신 | 손흥민 서사(감성 A안) + 와일드카드 경우의 수 표 전체 제공 + 팬 커뮤니티 공유 유도 CTA | 경기 종료 **30~60분** 이내 최우선 발송 |
| **라이트 팬** | Behavior: 월드컵 시즌만 오픈 / Engagement: 중간 / Affinity: 스포츠 일반 / RFM: 간헐적 | 팩트형 요약(B안) 인트로 + 와일드카드 생존 가능성 1줄 요약 + 간결 CTA | 경기 다음 날 오전 07:00~08:30 |
| **비활성 구독자** | Behavior: 최근 3개월 미오픈 / Engagement: 낮음 / Affinity: 불명확 / RFM: 오래됨 | 제목에 "한국 32강 가능?" 등 생존 가능성 강조 후킹 + 본문 극단 요약(3문장) + 간결 단일 CTA | 다음 날 점심 12:00~13:00 (리인게이지먼트 목적) |
| **신규 구독자** (30일 이내) | Behavior: 첫 수신 or 초기 / Engagement: 불명확 / Affinity: 미정 / RFM: 신규 | 온보딩 친화 서문("처음 오신 분께") + 팩트+감성 혼합형 + 뉴스레터 소개 1줄 추가 | 코어 팬과 동시 발송 (이탈 방지 우선) |

### 다음 호 발송 전략 (와일드카드 확정 후)
와일드카드 탈락 확정 시나리오와 진출 확정 시나리오를 **사전에 2개 버전 드래프트** 준비하여, 결과 확정 직후 즉시 발송할 수 있도록 대기한다.

- **32강 진출 확정 시**: 확정 후 **15~30분 이내** 긴급 발송. 제목 예시 — "한국 32강 진출 확정 — 다음 상대는 [국가명]" / CTA: 대진표 확인
- **탈락 확정 시**: 확정 후 **30~60분 이내** 발송. 감성 서사 주도 — "4년 후를 위한 기록 — 2026 한국 대표팀이 남긴 것" / 해지율 관리를 위해 과도한 비판 서사 배제, 회고·감사 프레임 유지
- **결과 대기 중 발행**: 다른 조 경기 진행 중 "현재 한국의 생존 조건" 실시간 업데이트형 이메일 → CTA를 "결과 업데이트 알림 신청"으로 설정하여 재구독 engagement 확보
- **발송 금지 시간대**: 새벽 00:00~06:00 (경기 결과가 새벽에 확정되더라도 발송 보류 → 오전 07:00 발송으로 대체)

## 성과 예측
| KPI | 업계 평균 | 예측치 | 근거 |
|-----|---------|--------|------|
| 오픈율 | 22% | **32~40%** | 스포츠 긴급 뉴스 장르(월드컵 시즌)의 업계 오픈율은 일반 뉴스레터 대비 1.5~1.8배. 경기 종료 직후 발송 시 FOMO 효과 가산. 와일드카드 생존 여부 미결이 추가 오픈 동인 |
| 클릭률 | 3.5% | **5~8%** | "와일드카드 경우의 수" 고관여 콘텐츠 특성상 정보 탐색 클릭 비율이 높음. 단일 명확 CTA 운영 시 클릭 분산 최소화 가능 |
| 공유율 | — | **2~4%** | 32강 경우의 수 인포그래픽·표 포함 시 SNS 공유 폭발 잠재력. "공유하면 응원하는 거다" 프레이밍의 CTA 추가 권장 |
| 구독 해지율 | 0.3% | **0.2~0.5%** | 긴급 뉴스 발행은 해지율이 낮은 편이나, 홍명보 감독 경질 등 정치화된 의견 서술 시 0.5% 초과 위험. 팩트 기반 중립 서술로 관리 |

**실측 데이터 부재**: 이 예측은 업계 벤치마크 및 스포츠/뉴스 장르 특성 기반 추정치입니다. 초회 발행 결과 수집 후 예측 모델을 보정해야 하며, 3회 이상 발행 데이터 축적 시 통계적으로 유의미한 자체 벤치마크 수립이 가능합니다.

## 개선 제안 (첫 발행 가이드)
| 영역 | 권장 사항 | 근거 |
|------|---------|------|
| 발송 인프라 | 경기 종료 시각에 맞춘 **발송 자동화 트리거** 설정 (경기 종료 +30분 예약 발송) | 수동 발송은 골든 타임(30~60분) 이탈 위험 |
| 이미지 최적화 | 본문 내 이미지 **Alt 텍스트 필수 작성** ("손흥민 교체 투입 장면", "와일드카드 현황표" 등) | 이미지 차단 환경에서도 콘텐츠 전달력 유지 |
| 모바일 최적화 | 제목 **40자 이내** 유지 (현 A안 37자 적합, B안 37자 적합), 프리헤더 **60자 이내** 설정 | 모바일 Gmail·네이버 메일 기준 잘림 방지 |
| UTM 파라미터 | 모든 CTA 링크에 `utm_source=newsletter&utm_medium=email&utm_campaign=worldcup_wildcard` 적용 | GA4·도구 내 유입 추적 없이는 클릭률·전환 데이터 확보 불가 |
| 해지 버튼 | List-Unsubscribe 헤더 + 본문 하단 해지 링크 **모두 포함** | CAN-SPAM·한국 정보통신망법 준수, 스팸 신고 대신 해지 유도로 발송 도메인 평판 보호 |
| 구독자 데이터 수집 시작 | 첫 발행 시 **오픈 시각·클릭 링크·기기 유형** 3가지 최소 로그 수집 | 2회 발행부터 세그먼트 전략 적용을 위한 BEAR 모델 기초 데이터 |
| 콘텐츠 위험 관리 | 홍명보 감독 거취·경질 관련 **입장·의견 서술 금지**. 팩트("홍명보 감독은 ~라 밝혔다") 인용 형식만 허용 | 정치화·팬 분열 가능성으로 해지율 급등 및 브랜드 신뢰 하락 위험 |
| 첫 발행 KPI 목표 | 오픈율 25% 이상, 클릭률 4% 이상, 해지율 0.5% 미만을 **최소 통과 기준**으로 설정 | 업계 평균 이상 달성 시 콘텐츠 방향성 유지, 미달 시 제목·인트로 프레임 전면 재검토 |
