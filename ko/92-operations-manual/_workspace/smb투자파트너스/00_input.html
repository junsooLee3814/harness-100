SMB투자파트너스 · 투자 업무 매뉴얼

00. 입력 정의서

01
조직 정보
  • 조직명: SMB투자파트너스
  • 업종: 중소기업 대상 메자닌·PE(사모펀드) 투자
02
매뉴얼화 범위 (투자 전 과정)
단계 명칭 설명
1 투자요청 접수 기업 투자제안서 접수, 초기 검토
2 예비심사 심사역 1차 검토, 리스크 스크리닝
3 본심사 실사(DD), 투자심의위원회(IC) 결의
4 투자 집행 계약, 자금 집행, 등기 등 법적 절차
5 사후관리 포트폴리오 모니터링, 밸류업, EXIT
03
소스 자료
  • 기존 문서 없음 → 에이전트가 PE/메자닌 업계 표준 프로세스 기반으로 생성
  • 에이전트 인터뷰 모드 적용 (모든 산출물에 "[현장 검증 필요]" 태그 포함)
04
대상 독자
  • 매뉴얼: 투자심사역 (신입~경력 3년), 펀드매니저, 준법감시인
  • 교육자료: 신입 심사역 (투자 경험 0~1년)
05
산출물 요건
  1. 단계별 업무 매뉴얼 — 담당자별 역할, 체크리스트, 예외처리 포함
  2. 프로세스 플로차트 — Mermaid 다이어그램 (Level 0 전체 맵 + 단계별 Level 1)
  3. FAQ — 실무자 관점 30건 이상, 예외상황·에스컬레이션 포함
  4. 오리엔테이션 교육자료 — 신입 심사역 대상, 퀴즈·실습과제 포함
06
제약 조건
  • 한국 자본시장법, 사모펀드 규정 준수 관점 반영
  • 투자심의위원회(IC) 결의 요건 명시
  • 면책 문구: "본 매뉴얼은 내부 업무 가이드이며 법적 효력을 갖지 않음"
