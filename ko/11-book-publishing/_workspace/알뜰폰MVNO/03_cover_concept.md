## 메인 컨셉 (A안) — "정점을 지난 곡선"

### 컨셉 설명
딥 네이비의 밤하늘 같은 배경 위에, 상승하다 정점을 찍고 완만히 꺾이는 앰버색 데이터 곡선 하나가 화면 하단을 가로지른다. 곡선의 정점에는 마커와 함께 "1,011만 · 정점 / 2025. 06" 라벨을 배치 — 이 책의 출발점인 "정점과 변곡점 사이 열 달"을 표지 한 장으로 요약한다. 상단 2/3는 대형 타이포 존, 하단 1/3은 데이터 곡선 존으로 분리해 썸네일에서도 제목이 먼저 읽힌다. 이코노미스트·맥킨지 리포트 계열의 절제된 그래픽 톤.

### 시각 요소
- 배경: 딥 네이비 대각 그라데이션(#0a1526 → #0d1e36) + 은은한 100px 데이터 그리드(투명도 5.5%)
- 핵심 모티프: SVG 단일 곡선 — 좌하단에서 급상승 → 정점(화면 우측 70% 지점) → 완만한 하강. 곡선 아래 앰버 그라데이션 필로 "채워진 성장의 시대"가 옅어지는 느낌
- 정점 마커: 앰버 도트 + 글로우 링 + 점선 수직 가이드 + "1,011만 · 정점 / 2025. 06" 소형 라벨
- 상단 오버라인: 앰버 대시 + "한국 MVNO 시장 분석서" (장르 신호)
- 하단 우측: "내부 자료 · 대외 배포 금지" 테두리형 소형 배지

### 컨셉 설명

## 뒷표지/소개 카피 (내부 공유 페이지용)

2025년 6월 1,011만 회선으로 정점을 찍은 한국 알뜰폰 시장은 열 달 만에 사상 첫 연속 순유출을 맞았다. 본서는 산업 구조, 경쟁 참가자, 소비자, 미래 트렌드를 공개 데이터로 해부하고, 독립계 사업자 사례 연구를 통해 "1,000만 회선 이후"의 생존 조건 7가지와 3단계 로드맵을 제시한다. 성숙기 시장의 규칙은 하나다 — 덜 잃는 자가 이긴다.

※ 뒷표지 하단 고정 표기: "본서는 정보 제공 목적의 시장 분석 자료입니다. · 내부 자료 · 대외 배포 금지"

## 경쟁 표지 분석 (시장분석서·업계 리포트 표지 관례)

| 유형 | 관례 | 본 표지 반영 |
|---|---|---|
| 글로벌 컨설팅 리포트 (맥킨지·BCG·딜로이트) | 단색/그라데이션 배경 + 추상 데이터 그래픽 1개 + 산세리프 대형 타이포 + 기관명 하단 고정. 장식 최소, 3색 이내 | A안의 기본 골격. 그리드+곡선 1개만 남기고 아이콘·사진 배제 |
| 이코노미스트/EIU 계열 | 딥 컬러 배경 + 고채도 시그널 1색 대비, 개념을 은유하는 단일 비주얼 | A안의 네이비+앰버 대비, "정점을 지난 곡선" 단일 은유 |
| 국내 증권사·산업연구원 보고서 | 백색/연회색 지면 + 괘선 프레임 + 기관 로고 존, 타이포 위계 뚜렷 | B안의 프레임·괘선 구조, 저자 존 분리 |
| 비즈니스 단행본 (서점 유통) | Big Title 레이아웃, 제목이 화면 폭 80% 이상, 파랑·검정 신뢰 팔레트, 띠지에 한 줄 훅 | 두 안 모두 Big Title + 썸네일 가독 우선. 띠지 카피 1문장 훅 |
| 차별점 | 통신·시장 리포트 표지의 상투구(스마트폰 실사, 지구본, 네트워크 노드망)를 의도적으로 배제 | "1,011만 정점" 실데이터를 곡선 모티프로 직접 표지화 — 본문 1페이지와 표지가 같은 이야기를 함 |

썸네일 테스트: 두 안 모두 3x4cm 축소 시 "알뜰폰의 다음 10년" 6자가 최우선 인지되도록 제목을 2행 초대형 배치, 요소 수 5개 이하(오버라인·제목·부제·곡선·저자/배지)로 제한.
