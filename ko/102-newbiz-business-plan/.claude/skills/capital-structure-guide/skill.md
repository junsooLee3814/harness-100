## 1. 조달 수단별 시장 눈높이 벤치마크

| 수단 | 금리/수익률 | 만기 | 핵심 조항 | 적합 상황 |
|---|---|---|---|---|
| **에쿼티** (모회사 출자) | 요구수익률 CAPM 8~15%+ | 영구 | 설립 자본금 실무 100만원~. **인허가 업종은 법정 하한 우선** (예: 일반화물운송 1억) | 지배력 유지 · J-curve 적자 흡수 · 초기 전 구간 |
| **RCPS** (외부 VC/PE) | 우선배당 ~1% + 상환 시 연복리 6~8% | 상환청구 통상 3~5년 후 | 상환권은 **배당가능이익 한도 내**에서만 · 전환권 · 사전동의권. 2026 벤처투자 표준계약 개정으로 CPS 전환 유도 진행 중 | 비상장 신사업 법인 외부 유치 · 밸류 검증 필요 시 |
| **CB** | 표면 0~2% + YTM 2~5% 복리 (금리 상승기 상단 확대) | 3~5년, 풋옵션 2년 후~ 3개월 단위 | 상장사 사모: **리픽싱 하한 최초 전환가의 70%** + 하향 시 상향 리픽싱 의무 · 콜옵션은 최대주주 지분율 한도 | 주가 상승 스토리 있는 상장사 · 프리IPO |
| **BW** | CB 유사 | 3~5년 | **상장사 사모 분리형 금지** — 결합형만 (공모만 분리형) | 원금 유지 + 신주 인수 여지 |
| **신용대출** | 연 4.2~9%+ (평균 4.2~4.5%, 등급별 가산) | 1~3년 (운전자금 1년 롤오버) | 이자보상배율 ≥1 심사 · **실적 없는 신설 법인은 자체 신용대출 곤란 — 모회사 보증·담보가 현실적** | 실적 있는 모회사 차원 조달 |
| **시설자금대출** | 연 4%대 (담보 시 하단) | 3~10년 | 담보(부동산·설비) · DSCR ≥1.2 · 신설법인은 모회사 보증 요구 | CAPEX 큰 신사업 (담보 확보 가능 시) |

## 3. 최소자본구조 산정 — 5단계 로직 ★

```
① 총소요자금 = CAPEX + 초기 운전자금 + BEP까지 누적 적자 (J-curve 면적)
② 자기자본 하한 = max( 총소요자금 × 1/3 (부채비율 200% 역산), 인허가 법정 자본금 )
   ※ 이때 '총소요자금'은 ④ 버퍼까지 포함한 최종값 기준 — 버퍼 제외 기저로 하한을 잡으면 과소 산정된다
③ 배분 = 담보 가능 한도까지 시설대출(최저 비용)
        → 잔여는 CB/RCPS(이자 이연·희석 대가)
        → 순수 신용대출은 실적 확보 후로 이연
④ 버퍼 = 월 burn rate × 12~18개월 현금 (하강기 18개월+)
        차기 조달은 런웨이 6개월 전 착수 원칙
⑤ 검증 = DSCR ≥1.2 · 이자보상배율 ≥1(안정 후 3+) · 부채비율 ≤200% · 유동비율 ≥100%
        미달 → ②~③ 재조정 (자기자본 증액이 1순위 해법)
```

- 부채비율 200%는 IMF 이후 **관행 기준선**(공식 규정 아님 — 이 한계를 명시하고 쓸 것)
- 보수 시나리오에서 이 검증을 통과해야 한다. 기준 시나리오 통과는 통과가 아니다

## 4. 건전성 지표 기준선

| 지표 | 기준선 | 의미 |
|---|---|---|
| DSCR | ≥1.2 (은행 1.15~1.35) | 원리금 상환 능력. 1 미만 = 상환 불능 |
| 이자보상배율 | ≥1 · 3년 연속 미만 = 한계기업(한은) | 안정 후 3 이상 목표 |
| 부채비율 | ≤200% (관행) | |
| 유동비율 | ≥100% (통상 100~200%) | |
| 런웨이 | 12~18개월 | 6개월 미만 조달 착수는 고위험 |

## 5. 자금조달 실패 패턴 — 차단 규칙

| # | 패턴 | 차단 규칙 |
|:-:|---|---|
| 1 | 상징적 자본금(100만원대) 설립 → 즉시 차입 의존 → 자본잠식 | 자기자본 하한(②)을 지켜 설계. 초기 6~12개월 소요자금 이상 |
| 2 | 런웨이 6개월 미만에서 조달 착수 → 협상력 상실 | 버퍼 12~18개월 + 차기 조달 6개월 전 착수를 구조에 명시 |
| 3 | 실적 없는 단계의 조기 CB → 풋 도래 시 상환 불능·리픽싱 희석 | 메자닌은 실적·스토리 확보 후. 초기 구간은 에쿼티 중심 |
| 4 | 변동금리·단기 롤오버 중 금리 인상기 진입 | 현재 인상 사이클임을 반영 — 금리 +1%p 민감도 필수 |
| 5 | JV 출구조항 부재 → 분쟁 시 청산·매각 불가 | JV 구조 제안 시 출자비율·교착해소·출구조항을 조건표에 포함 |

## 6. 사용 규칙

1. 벤치마크를 벗어난 조건을 제안할 때는 **사유를 명시**한다 (예: "담보 충분 → 하단 적용")
2. 사업주 제시값은 이 벤치마크와 대조해 `부합/낙관/보수` 판정한다 — 조용한 채택 금지
3. 모든 추정에 `[가정]` 태그 + 근거. 가정 목록 표 필수
4. 규제(리픽싱 70%·콜옵션 한도·사모 분리형 BW 금지)는 **상장사 한정 조항**임을 구분해 쓴다
