# 법률 콘텐츠 최신성·정확성 가드

법률 책의 특성: **조문번호·수치·판례는 개정으로 수시 변동**하고, LLM의 학습 지식은 옛 버전일 확률이 높다. 이 가드는 그 간극이 책에 스며드는 것을 막는다.

> 출처: 도정법 실무서 검증 체크리스트 관행 (70번 workspace — 실증 완료)

## 1. 기준 시행일 규칙

- 책 전체의 **기준 법령 시행일**을 서문과 목차에 명시 (예: "2026.1.1. 시행 법령 기준")
- **각 장 도입부에도 기준일 명시** — 장별로 개정 시점이 다르면 장별 기준일
- 집필 시점에 **웹 검색으로 현행 여부 확인** — 국가법령정보센터(law.go.kr) 현행본 기준. 실패 시 "법령 미조회" 표기
- 입법 진행 중(국회 계류·정부안) 사항은 본문과 분리해 **"개정 예고" 박스**로: "확정 아님 — 통과 시 변경"

## 2. 확인 상태 3단계 — 모든 조문·수치·판례에 부여

| 상태 | 기준 | 본문 사용 |
|---|---|---|
| **원문 확인** | law.go.kr·대법원 원문 대조 | 그대로 사용 |
| **복수 출처 일치** | 독립 2차 출처 2개+ 일치 | 사용 가능, 체크리스트에 "원문 대조" 등재 |
| **미확정** | 출처 불일치·단일 출처·기억 의존 | **번호·수치 사용 금지** — 법리만 서술, [검증필요] |

**철칙**: 사건번호·조문번호를 추측으로 만들지 않는다. "그럴듯한 번호"가 최악의 오류다.

## 3. [검증필요] 취합 체크리스트 — `02_verification_checklist.md`

목차설계자가 골격 생성 → 집필자가 장별로 추가 → 검증자가 유지·이동.

```markdown
# {법률명} 실무서 — 최종 검증 체크리스트 (조문·판례 대조용)

> 출판 전(11번 book-publishing 단계 전) 반드시 law.go.kr 현행본·대법원 종합법률정보로
> 대조하고, {해당 분야 전문가} 감수를 받을 것.

## 공통 원칙
- [ ] 모든 조문번호를 law.go.kr 현행본과 1:1 대조
- [ ] 모든 판례 사건번호를 원문으로 대조
- [ ] 최근 개정 시행일·법률 호수 확정
- [ ] 위임(시행령·조례) 의존 항목 "상이 가능" 주석 유지

## 장별 검증 항목
### {N}장 ({주제})
- [ ] (집필자가 남긴 [검증필요] 구체 항목)

## 확인 완료(대조된) 사실 — 그대로 사용 가능
- (검증자가 이동)
```

## 3-1. 감수자용 작업표 xlsx — `build_crosscheck_xlsx.py`

체크리스트 md는 사람이 읽는 문서고, **감수자(세무사·변호사)가 손에 들고 작업하는 것은 xlsx**다.
체크리스트를 파싱해 자동 생성하므로 원고가 바뀌면 재실행만 하면 된다.

```bash
PYTHONUTF8=1 python .claude/skills/legal-currency-guard/build_crosscheck_xlsx.py "_workspace/{법률명}"
```

- 출력: `_workspace/{법률명}/원문대조_작업표.xlsx`
- 시트: ①작업표(1행=[검증필요] 1건, 마커 원문·파일L행·우선순위·상태 드롭다운·결과 기재란,
  자동필터·틀고정·행 색상) ②요약(장별·우선순위별 + 진행률 수식) ③확인 방법(DRF API·MST·함정)
  ④확인 완료 이력(원문 확정 사실 — 중복 조사 방지) ⑤조문 인용 색인 ⑥핵심 수치
- **재실행 시 사람이 기입한 결과·확인자·확인일을 보존**하고, 원고 행번호가 밀려도 짝짓기를 유지한다
- 우선순위 3단계: 🔴 수치·세율·한도(틀리면 계산이 틀어짐) / 🟡 조문 항·호 번호 / 🟢 예규·판례·절차

## 3-2. 조문 원문 확보 경로 (law.go.kr 프레임 함정 회피)

law.go.kr의 일반 페이지(`lsInfoP.do`, `/법령/…/제N조`)는 **네비게이션만 반환하고 조문 본문을 주지 않는다.**
검색 요약만 보고 조문을 인용하면 구법을 그대로 쓰는 사고가 난다. 아래 경로를 쓸 것:

```
DRF 오픈API (권장):
  https://www.law.go.kr/DRF/lawService.do?OC=test&target=law&type=XML&LM={법령명}&JO={조문번호 6자리}
  예: LM=상속세 및 증여세법 시행령&JO=001500  → 시행령 제15조
인쇄뷰 우회:
  https://www.law.go.kr/LSW//lsLawLinkInfo.do?lsJoLnkSeq={SEQ}&lsId={ID}&chrClsCd=010202&print=print
```

- 연혁법령 API(`target=eflaw`)는 500 오류가 잦다 — 구법 대조는 2차 출처 + [검증필요] 유지
- 이미지로 된 산식(예: 상증법 §19 배우자공제 한도식)은 API로도 안 잡힌다 — 종이 법전 확인 필요
- lawnb(로그인)·lbox(403)·casenote(조문 404)는 조문 원문 취득에 부적합

## 4. 세법류 추가 규칙

- 금액 기준(공제액·과세표준 구간)은 **연도별 변동 이력 확인 후** 기재 — 옛 금액이 검색 상위에 흔하다
- "12억?" "8천만원?"처럼 **불확실한 금액은 물음표조차 본문에 넣지 않는다** — 체크리스트로만
- 예규·집행기준은 법령과 층위를 구분해 인용 ("국세청 해석" 명시 — 법원이 뒤집을 수 있음)
- 세제 개편 논의(예: 유산취득세 전환)는 "개정 예고" 박스 + 재확인 주기 명시

## 5. 면책 문구 — 의무 배치

- **서문**: "본 교재는 일반적 정보 제공 목적이며 법률·세무 자문을 대체하지 않는다. 구체적 사안은 변호사·세무사 등 전문가와 상의하라. {기준일} 시행 법령 기준이며 이후 개정으로 달라질 수 있다."
- **각 계산 사례**: "가상의 사례이며 실제 사안은 전문가 확인 필요"
- **출판 전 필수**: 전문가 감수 + 법령 1:1 대조는 사람의 몫 — 하네스가 대체 못 함을 최종 보고에 명시

## 6. 매 집필 세션 시 갱신 확인 대상

법령 개정 여부 / 판례 변경(전원합의체) / 시행령·고시 개정 / 입법 진행 상태 — 검색 실패 시 해당 장에 "미조회 (기준: {일자})" 표기.
