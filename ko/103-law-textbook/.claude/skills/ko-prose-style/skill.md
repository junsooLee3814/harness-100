# Ko Prose Style — 한국어 문체 격상 가이드

법률 용어는 법령에서 오므로 정확하다. 문제는 **그 용어들을 잇는 연결 어휘**다. 이 가이드는 연결 어휘를 대학교재·언론 수준의 절제된 문어체로 끌어올리는 기준이다.

## 대원칙 3

1. **품격은 올리되 난도는 올리지 않는다.** 목표는 "어렵게 쓰기"가 아니라 "품위 있게 쓰기"다. 쉬운 문장 구조는 그대로 두고 어휘의 격만 교체한다. 일반인 독자가 본문만 읽어 이해할 수 있어야 한다는 헌법 5조(이원 독자)는 교열 후에도 유효하다.
2. **사실은 한 글자도 바꾸지 않는다.** 조문번호·세율·금액·날짜·기간·사건번호·[검증필요] 마커·표의 수치는 불변이다. 숫자 표기 방식 변경(3개↔세 개)도 금지 — 기계 검증이 잡아낸다.
3. **분량을 깎지 않는다.** 교열 후 글자수는 원문의 97% 이상이어야 한다(기계 검증 항목). 문장을 다듬다 내용을 삭제하지 않는다. 이 책은 분량 미달로 전면 재작업한 이력이 있다.

## 불변 목록 (건드리면 반려)

- 조문 인용(제N조·제N항·§N), 세율·금액·날짜·기간 등 모든 수치, 사건번호
- `[검증필요]` 마커와 그 내용
- 장·절 번호와 5블록 구조, 표의 행·열 구성과 데이터 셀의 수치
- 콜아웃 마커·형식(💡 실무 팁 / ⚠️ 주의 / ■), 상호참조 `(→ 제N장)`, `(→ N.N)`
- 판례·법령의 직접 인용 문구, 용어집에 등재된 법률 전문용어
- 굵게/기울임 등 강조 표시의 위치(강조 대상 어휘가 교체되면 강조도 함께 이동)

## 교정 유형 1 — 고유어 서사·은유 → 한자어 개념어 (최우선 규칙)

이 책의 최대 결함이자 발주자(PO)가 직접 지정한 교정 방향이다. 이야기하듯 쓴 고유어 은유("길", "갈래", "넘어가다", "손을 바꾸다", "반쪽")를 **정확한 한자어 개념어("이전", "방법", "취득", "처분", "불완전")**로 교체한다. 은유를 전부 죽이라는 뜻이 아니다 — **한 절에 하나면 수사(修辭)고, 문단마다 나오면 소음이다.** 맞춤법·띄어쓰기는 표준 규범을 따른다(두 가지·대가 없이).

**PO 지정 표준 예 2건 (이 수준이 기준이다):**

| 이전 (고유어 서사체) | 이후 (한자어 개념어) |
|---|---|
| 재산이 대가 없이 다른 사람에게 **넘어가는 길은 두 갈래**다 | 재산이 대가 없이 다른 사람에게 **이전되는 방법은 두 가지**다 |
| 상속·증여세만 보면 **반쪽 설계**다 | 상속·증여세만 보면 **불완전한 설계**다 |

| 이전 (구어·헤드라인체) | 이후 (격상) |
|---|---|
| 이 질문에 상증세법만으로 답하면 틀린다 | 이 질문은 상증세법만으로는 정확히 답할 수 없다 |
| 재산 하나가 손을 바꿀 때 | 재산의 소유자가 바뀔 때 |
| 시계는 세 개가 돈다 | 과세의 계기는 세 차례에 걸쳐 찾아온다 |
| 설계 전체를 뒤집을 만큼 크다 | 설계 전체를 좌우할 만큼 크다 |
| 외워 두면 대부분의 경우 틀린다 | 일률적으로 단정하면 대부분의 경우에 맞지 않는다 |
| 미래의 양도세를 계산할 때 되살아나는 숫자다 | 장래의 양도소득세 계산에 다시 쓰이는 값이다 |
| 현금부터 막히는 일이 실제로 벌어진다 | 현금 확보가 먼저 문제되는 경우가 드물지 않다 |
| 발등의 불 / 세금 폭탄 / 함정 카드 | 당면한 부담 / 예상하지 못한 고액의 세부담 / 간과하기 쉬운 위험 |
| 챙겨야 한다 | 확인해 두어야 한다 |
| ~하면 큰일 난다 | ~하면 불이익이 크다 |
| 옛날 셈법이다 | 더 이상 유효하지 않은 계산 방식이다 |

의문문 남용도 헤드라인체다. "~일까?"로 절을 여는 방식은 장당 1~2회로 절제하고, 나머지는 평서문으로 바꾼다.

## 교정 유형 2 — 번역투 제거

| 번역투 | 교정 |
|---|---|
| ~에 대해 / ~에 대한 | ~에 관하여 / ~에 관한, 또는 조사로 풀기("상속세에 대해 알아본다"→"상속세를 살펴본다") |
| ~을 통해 | ~으로, ~을 거쳐 |
| ~에 있어(서) / ~함에 있어 | ~에서 / ~할 때 |
| ~하는 것이 가능하다 | ~할 수 있다 |
| ~하는 것이 필요하다 | ~해야 한다 / ~할 필요가 있다 |
| ~라고 할 수 있다 | (단정 가능하면) ~이다 |
| ~되어진다 / ~되어져 있다 | ~된다 / ~되어 있다 |
| ~로 인해 (남용) | ~때문에 / ~로 |
| 효력을 가진다 | 효력이 있다 |
| ~들 (불필요한 복수) | 삭제 |
| ~적(的) 남용 | 풀어쓰기("절세적 관점에서"→"절세의 관점에서") |
| "것" 남용 | 명사화 정리("신고하는 것이 중요한 것은"→"신고가 중요한 이유는") |

## 교정 유형 3 — 연결어·부사 격상

| 이전 | 이후 |
|---|---|
| 그래서 | 따라서, 그러므로 |
| 근데, 그런데(남용) | 그러나, 다만 |
| 하지만 | 그러나 |
| 게다가 | 더욱이, 나아가 |
| 이런 / 그런 / 저런 | 이러한 / 그러한 |
| 이렇게 / 그렇게 | 이처럼 / 그처럼 |
| 아무리 ~해도 | ~하더라도 |
| 꽤, 되게, 정말, 굉장히, 너무 | 상당히, 현저히 (또는 삭제) |
| ~하면 된다 | ~하면 충분하다 |
| ~해 준다 (법·제도가) | ~하도록 정하고 있다, ~을 허용한다 |
| ~일 뿐이다 | ~에 지나지 않는다 |
| ~는 게 / ~는 건 | ~하는 것이 / ~하는 편이 |
| 왜냐하면 ~기 때문이다 | ~기 때문이다 (문두 "왜냐하면" 삭제) |

## 교정 유형 4 — 문장 리듬

- **한 문장에 하나의 주장.** 두 주장이 접속사로 묶여 있으면 문장을 나눈다(내용 삭제 금지).
- **주어와 서술어의 거리를 좁힌다.** 긴 관형절이 주어를 삼키면 절을 앞뒤로 빼낸다.
- **피동 최소화.** 단, 법률 서술의 관행 피동(부과된다·과세된다·간주된다·의제된다)은 유지한다.
- **명사형 종결(~임/~함) 금지** — 본문은 항상 "~이다/~한다"체. 표 안의 개조식은 예외.

## 과교정 경계 (하지 말 것)

- 법률 전문용어를 유사어로 교체하지 않는다(용어 일관성은 검증 6축의 별도 축이다).
- 일반인용 풀이를 한자어로 뭉개지 않는다 — "쉽게 이해하기" 블록의 생활 언어("집 한 채", "물려받다")는 이 책의 설계다.
- 문단 순서 재배치·내용 추가·요약 금지. 교열은 문장 단위 성형이지 재집필이 아니다.
- 표 데이터 셀은 문장형 서술일 때만 문체를 다듬고, 수치·기호 셀은 통째로 불변.

## 기계 검증 — check_edit_integrity.py

교열이 끝난 파일은 반드시 무결성 검증을 통과해야 한다:

```
python .claude/skills/ko-prose-style/check_edit_integrity.py {교열 전 파일} {교열 후 파일}
```

검사 항목: ① 모든 수치의 다중집합 일치 ② 조문 인용(제N조·제N항·제N호·§N) 일치 ③ 사건번호 일치 ④ [검증필요] 건수 일치 ⑤ 글자수 ≥ 원문의 97%. **exit 0 전에는 교열 완료로 보고하지 않는다** — calc-verify와 같은 지위의 관문이다.
