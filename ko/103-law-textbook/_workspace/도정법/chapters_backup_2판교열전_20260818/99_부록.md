## A. 정비사업 전체 절차 플로우차트

조합방식 재개발·재건축의 표준 순서다. 일부 단계는 병행·조정된다. 동의율은 B절, 상세는 각 장에 있다.

```
[1] 기본계획 수립·고시 — 10년 단위 · 5년마다 타당성 검토   법 §4~§7
      │ ← [입안 요청] §13의2 / [입안 제안] §14
[2] 정비계획 입안 → 심의 → 정비구역 지정·고시   법 §8~§16
      지구단위계획 의제(§17) · 행위제한(§19)
      일몰제 : 미신청 시 해제(§20) · 직권해제(§21)
[3] 추진위원회 구성 · 시장·군수등 승인   법 §31~§34
      ★ 2025.6.4.부터 구역 지정·고시 前에도 구성 가능(§31②)
        → 면적 차 10% 이상이면 재승인(§31④)
[4] 창립총회 — 정관 확정 · 임원·대의원 선임   영 §27
[5] 조합설립인가 → 30일 이내 등기 = 조합 성립   법 §35·§38
[6] 시공자 선정 — 총회, 경쟁입찰 원칙 · 합동설명회 2회 이상   법 §29④⑧
   〔재건축 전용〕 재건축진단 — 사업시행계획인가 前까지,   법 §12
     시장·군수등이 실시 (재개발에는 없다)
[7] 사업시행계획 인가·고시 — 총회 의결 → 공람 → 통합심의   법 §50~§57
      ★ 고시일 = 종전자산 평가 기준일(§72①1) — 재산의 분기점
[8] 분양통지·공고(고시일부터 90일 이내) → 분양신청(30~60일)   법 §72
      미신청·철회 시 자동 현금청산(§73) — 조합원 지위 상실
[9] 관리처분계획 인가·고시  ★ 사업의 정점   법 §74~§78
      효력 : 사용·수익 정지(§81①) · 입주권 전환
[10] 이주·철거 — 재개발 = 수용 / 재건축 = 매도청구   법 §63·§64·§81
[11] 착공·공사 → [12] 준공인가·고시 · 정비구역 해제(§84)   법 §83
[13] 이전고시 — ★ 고시일 다음 날 소유권 취득,   법 §86·§87
      이후 관리처분계획을 다툴 이익이 사라진다
[14] 청산금 징수·지급(시효 5년) → 해산총회 → 청산   법 §89·§90·§86의2
```

> 💡 [1]~[2]는 **구역을 만드는 공적 절차**, [3]~[9]는 **조합이 사업을 확정하는 절차**, [10]~[14]는 **짓고 나누는 절차**다. 성패는 [9] 관리처분계획에서 갈리고, **다툴 문은 [13] 이전고시에서 닫힌다.**

### ■ 조직을 세우는 단계

| 국면 | 요건 | 근거 |
|---|---|---|
| **추진위원회 구성** | 토지등소유자 과반수 | 법 §31① |

| **조합설립 — 재건축**(주택단지) | 구분소유자 100분의 70 이상 및 면적 100분의 70 이상 및 각 동별 구분소유자 과반수 | **법 §35③** |

> ⚠️ **복리시설 「3분의 1」은 무조건이 아니라 조건부다.** 원칙은 **과반수**이고, 3분의 1은 **기준일 다음 날부터 조합설립인가 신청일까지 복리시설 구분소유자가 증가한 경우**에만 적용된다(영 §30③, 2025.4.29. 신설). 그 용도로 전유부분을 분할해 신청일까지 사용 중이면 증가로 보지 않아 **다시 과반수**다 (→ 제7장).

> ⚠️ **「재건축 75%」와 「재개발 70%」는 둘 다 현행 수치가 아니다.** 재건축의 100분의 70은 **2025.5.1.**부터이고 이전이 4분의 3이었다. 재개발은 **여전히 4분의 3**이며 완화는 입법 논의 단계다. `[검증필요 — 재개발 조합설립 동의율 완화 입법의 진행 경과]`

## C. 재개발 vs 재건축 비교 총정리표

제1장 비교표를 실무 항목까지 확장했다. **여기서 갈리는 항목이 이 책의 함정 1이다.**

| 구분 | **재개발사업** | **재건축사업** |
|---|---|---|
| 대상 지역 | 기반시설 열악 + 노후·불량건축물 밀집 | 기반시설 양호 + 노후·불량 공동주택 밀집 |
| 근거 정의 | 법 §2 2호 나목 | 법 §2 2호 다목 |
| **토지등소유자** | 토지 또는 건축물의 소유자, 또는 그 지상권자 | 건축물 및 그 부속토지의 소유자 |
| **조합원** | 토지등소유자 전원(사실상 강제가입) | 동의한 자만(법 §39① 괄호) |
| 시행방법 | 관리처분 또는 환지 | 관리처분 하나(법 §23③) |
| 토지등소유자 직접 시행 | 20인 미만이면 가능(법 §25①2) | 없다 |
| **재건축진단** | **없다** | **필수** — 사업시행계획인가 前까지(법 §12) |
| 조합설립 동의율 | 4분의 3 + 면적 2분의 1 | 100분의 70 + 면적 100분의 70 + 동별 과반수<br>주택단지 아닌 지역은 4분의 3 + 3분의 2 |
| 공유 부동산 대표 선임 | 그 부동산 소유자 4분의 3 이상 동의 | 요건 없음(영 §33①2가) |
| **미동의자 처리** | 손실보상 · 수용(법 §63) | 매도청구(법 §64) |
| 대가의 성격 | 보상액 — 개발이익 배제 | **시가 — 개발이익 포함**(2008다21549) |
| **세입자 주거이전비·영업손실보상** | 있다(보상법 시행규칙 §54·§45~§47) | **없다**(헌재 2018헌가17) |
| 임시거주시설 · 임시상가 | 있다(법 §61) | 없다 |
| 임대주택 건설계획 | 사업시행계획서 기재사항 | 제외(법 §52①6) |
| 국유재산 사용허가 의제 | 재개발 한정(법 §57①13·14) | 없다 |
| 양도 제한 기산점 | 관리처분계획인가 후 | 조합설립인가 후(법 §39②) |
| 사업 지연 양도 예외 | 영 §37③3호(착공 후 3년 미준공) 하나 | §37③1호·2호가 추가로 있다 |
| 종전자산 평가 | 시장·군수등 선정 2인 이상의 평균 | 시장·군수등 1인 + 총회 의결 1인(법 §74④1) |
| 청산기준가격 평가 | 위 방식 준용 | 사업시행자가 정한다(영 §76) |
| **취득세 감면(지특법 §74⑤)** | 있다 — 60㎡ 이하 75%, 60~85㎡ 50%(1가구 1주택, 일몰 2028.12.31.) | **없다** |
| **재건축부담금(재초환법 §3·§5)** | **없다** | **있다**(소규모재건축사업 포함) |
| 조합주택용 부동산 납세의무자 의제 | 없다 | 있다(지방세법 §7⑧) |
| 다주택 공급 | 없다(1+1은 공통) | 과밀억제권역 안 3주택, 밖은 소유 주택 수(법 §76①7) |
| 정비업체 겸업 금지 중 재건축진단 | 없다 | 작동(영 §83②) |

> 💡 「우리 동네 재개발」이라 불러도 법적으로는 재건축인 경우가 많다. 유형을 확인하지 않으면 **조합원이 되는지, 동의하지 않으면 무엇이 오는지, 세금이 붙는지 깎이는지**가 어긋난다. 유형은 이름이 아니라 **구역 지정·고시 내용**이 정한다.

> ⚠️ **방향이 정반대인 두 조문이 오해 둘을 한꺼번에 정리한다.** **취득세 감면은 재개발에만**, **재건축부담금은 재건축에만** 있다. 「두 사업은 비슷하다」와 「재초환은 정비사업이면 다 붙는다」가 함께 무너진다 (→ 제15장).

## E. 용어집 (가나다순)

일반 독자용 간단 정의다. 실무자용 개념 대조(설권적 처분↔보충행위, 부과금↔청산금↔분담금 등)는 H절, 조문 인용 위치는 I절에 있다.

| 용어 | 뜻 |
|---|---|
| **경미한 변경** | 인가 없이 신고만으로 되는 변경. 영 §46의 14개·§61의 6개로 한정 열거 |
| **공공재개발·공공재건축** | 별개 유형이 아니라 각 사업 안의 하위 범주다 |
| **관리처분계획** | 누가 어느 집을 받고 얼마를 더 내거나 돌려받는지 확정하는 계획(§74) |
| **권리가액** | 실무로는 종전자산 평가액 × 비례율. 서울시 조례 §2 4호는 곱하지 않은 값이다 |
| **권리산정 기준일** | 다음 날부터는 분할·신축으로 소유자가 늘어도 분양권이 늘지 않는다(§77) |
| **노후·불량건축물** | §2 3호 가~라목의 네 갈래. 연한(20~30년)은 시·도조례가 정하고 필요조건일 뿐이다 |
| **대의원회** | 조합원 100명 이상이면 의무 설치. 영 §43의 12개 사항은 대행할 수 없다 |
| **매도청구** | 재건축 미동의자 등에게 시가로 매도를 청구. 개발이익이 포함된다(§64) |

| **입안 요청 / 입안 제안** | 요청은 동의율이 낮고 회신 최장 6개월, 제안은 도서를 갖추고 90일(§13의2·§14) |
