## 재개 공정

### 1단계. 문체 교열 — prose-editor 에이전트 7개 병렬

배치(각 에이전트당 3파일, 부록은 단독):
A: 01·02·03 / B: 04·05·06 / C: 07·08·09 / D: 10·11·12 / E: 13·14·15 / F: 16·17·18 / G: 99부록

에이전트 지시서에 반드시 넣을 것 (상증세법 1호기 실증 교훈):
- 기준은 `.claude/skills/ko-prose-style/SKILL.md` 격상표·금지 목록 (먼저 정독시킬 것)
- **하위 에이전트 띄우지 말 것** (1호기에서 대기 정지 사고 5건+)
- 사실 불변(조문·수치·사건번호·[검증필요]·표 데이터 셀) · 분량 97%+ · 종결어미 서술체(~이다) 유지
- "쉽게 이해하기" 블록의 생활 언어는 설계이므로 보존
- 파일마다 무결성 검증 exit 0 확인 후 완료 보고:
  ```
  PYTHONUTF8=1 "C:/Users/juncp/AppData/Local/Programs/Python/Python312/python.exe" \
    .claude/skills/ko-prose-style/check_edit_integrity.py \
    "_workspace/도정법/chapters_backup_교열전_20260814/{파일}" "_workspace/도정법/chapters/{파일}"
  ```

교열 완료 후 오케스트레이터가 19개 전 파일 무결성 재실행으로 총검수한다.

    $cur=(Get-Content $_.FullName -Raw -Encoding UTF8); $bak=(Get-Content "$base\chapters_backup_교열전_20260814\$($_.Name)" -Raw -Encoding UTF8);
