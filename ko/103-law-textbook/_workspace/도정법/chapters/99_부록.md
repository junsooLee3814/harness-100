## A. 정비사업 전체 절차 플로우차트

재개발·재건축(조합방식 기준)의 표준 진행 순서이다. 다만 실제로는 지자체·사업별로 일부 단계의 순서가 조정되거나 여러 단계가 병행되는 경우가 있다.

```
[1] 도시·주거환경정비 기본계획 수립          (특별시·광역시·시장 / 10년 단위, 5년마다 타당성 검토)
        │
        ▼
[2] 정비계획 입안 · 정비구역 지정             (정비구역 지정권자 / 주민공람·지방의회 의견·심의)
        │                                     ※ 2025 개정: 입안요청 제도, 입안요건 완화
        ▼
[3] 조합설립추진위원회 구성 · 승인            (토지등소유자 과반수 동의 → 시장·군수등 승인)
        │
        ▼
[4] 조합 설립 인가                            (동의율 요건 충족 → 인가 → 법인 설립등기)
        │
        ▼
[5] (재건축) 재건축진단                        (구 '안전진단' / 2025 개정: 사업시행계획인가 前까지 완료 가능)
        │                                     ※ 재개발은 해당 없음
        ▼
[6] 시공자 선정                               (경쟁입찰 원칙 / 총회 의결)
        │
        ▼
[7] 사업시행계획 인가                          (사업시행계획서 작성 → 인가권자 인가)
        │
        ▼
[8] 분양신청                                  (분양공고 → 분양신청 기간 / 미신청자 = 현금청산 대상)
        │
        ▼
[9] 관리처분계획 인가  ★ 사업의 핵심 단계      (종전·종후자산 평가, 비례율·분담금 확정 → 인가)
        │
        ▼
[10] 이주 · 철거                              (손실보상·수용(재개발) / 매도청구(재건축), 세입자 대책)
        │
        ▼
[11] 착공 · 공사                              (건축)
        │
        ▼
[12] 준공 인가                                (인가권자 준공검사)
        │
        ▼
[13] 이전고시                                 (소유권 이전 / 대지·건축물 확정 — 물권변동의 기준시점)
        │
        ▼
[14] 청산                                     (청산금 징수·지급 → 조합 해산·청산)
```

> 💡 **읽는 법** — [1]~[2]는 "구역을 만드는" 공적 절차, [3]~[9]는 "조합이 사업을 설계·확정하는" 절차, [10]~[14]는 "실제로 짓고 나누는" 절차이다. 사업의 성패는 대개 **[9] 관리처분계획** 단계에서 결정된다.

## B. 단계별 동의율 요약표

각 절차 단계에서 요구되는 동의 요건이다. 수치는 확인된 현행 조문을 기준으로 하며, 조례로 가중되는 경우가 있다.

| 단계 | 근거(도정법) | 재개발 | 재건축 |
|------|------|--------|--------|
| **추진위원회 구성** | 제31조 | 토지등소유자 **과반수** 동의 → 시장·군수등 승인 | 토지등소유자 **과반수** 동의 → 승인 |
| **조합 설립 인가** | 제35조 | 토지등소유자 **3/4 이상** + 토지면적 **1/2 이상** | 각 동별 구분소유자 **과반수**(5인 이하 동 제외) + 전체 구분소유자 **3/4 이상** + 토지면적 **3/4 이상** |
| **사업시행계획 인가(총회 의결)** | 제45조·제50조 | 조합원 **과반수** 찬성(총회 의결정족수) [세부는 정관] | 좌동 [세부는 정관] |
| **관리처분계획 수립(총회 의결)** | 제45조·제74조 | 조합원 **과반수** 찬성(다만 정비사업비 10% 이상 증가 시 조합원 **2/3 이상**) | 좌동 |
| **시공자 선정** | 제29조 | 경쟁입찰 원칙 + **총회 의결** | 좌동 |
| **정관 변경(일반)** | 제40조 | 조합원 **과반수** 찬성 | 좌동 |
| **정관 변경(주요사항)** | 제40조 | 조합원 **2/3 이상** 찬성(조합원 자격·비용분담·시공자 등 중요사항) | 좌동 |

> ⚠️ **주의 1** — 위 "총회 의결" 정족수는 도정법의 원칙 규정이며, **직접 참석·서면·전자 의결의 정족수 계산은 정관과 제45조 세부 항을 함께 확인**해야 한다. [검증필요: 사업시행계획·관리처분 총회의 직접출석 요건 세부]
> ⚠️ **주의 2** — 조합설립 동의율은 **조례로 강화**되거나, 일부 항목이 2025년 개정으로 완화 논의 중이다(→ 부록 D). 각주의 완화 수치를 그대로 적용하기 전에 현행본을 확인하여야 한다.

## C. 재개발 vs 재건축 비교 총정리표

1장의 비교표를 실무 항목 단위까지 확장하여 집대성한 종합표이다.

| 구분 | 재개발사업 | 재건축사업 |
|------|-----------|-----------|
| **대상 지역** | 기반시설 열악 + 노후·불량 건축물 밀집 | 기반시설 양호 + 노후·불량 건축물 밀집(주로 아파트) |
| **사업 성격** | 공익성 강함(기반시설 정비 포함) | 상대적으로 사익성(단지 내 건물 재축) |
| **재건축진단(구 안전진단)** | 불필요 | **필요**(통과가 사업 착수의 관문) |
| **조합원 자격** | 토지 **또는** 건축물 소유자, 지상권자 | 건축물 **및** 그 부속토지를 **함께** 소유한 자 |
| **조합 가입** | 사실상 강제(미동의자도 조합원, 미신청 시 현금청산) | **임의가입**(동의자만 조합원) |
| **미동의자 처리** | 손실보상 · **수용**(공용수용) | **매도청구**(민사) |
| **조합설립 동의율** | 3/4 + 토지면적 1/2 | 각 동 과반 + 전체 3/4 + 토지면적 3/4 |
| **세입자 대책** | 주거이전비·영업손실보상 등 **두터움** | 상대적으로 제한적 |
| **임대주택 의무** | 원칙적으로 부과(비율은 조례) | 원칙적 미부과(단, 용적률 인센티브 연계 시 발생) [검증필요: 비율·요건] |
| **재건축초과이익환수제(재초환)** | 미적용 | **적용 대상** |
| **적용 근거의 대표 조문** | 제2조·제35조·제63조(수용) | 제2조·제35조·제64조(매도청구) |

> 💡 **핵심** — "우리 동네 재개발"이라 불러도 법적으로는 재건축인 경우가 많다. **조합원 자격·미동의자 처리(수용 vs 매도청구)·세금(재초환)**이 모두 달라지므로 사업 유형의 확인이 무엇보다 우선한다.

## D. 2025~2026 개정 타임라인

이른바 **'재건축 패스트트랙'** 등 신속화 개정이 집중된 시기이다. 시행일이 항목마다 다르므로 반드시 항목별로 개별 확인을 거쳐야 한다.

| 시행(예정)일 | 개정 항목 | 핵심 내용 |
|------|------|------|
| **2025. 5. 1.** | 재건축 조합설립 동의요건 **완화** | 재건축 전체 구분소유자·토지면적 동의율을 **70%** 수준으로 완화(복리시설 동별 동의: 과반수 → **1/3 이상**) [검증필요: 제35조 개정 반영 여부·전면적용 시점] |
| **2025. 5. 1.** | 분담금 통지 기한 단축 | 관리처분 관련 분담금 통지 기한 **120일 → 90일** [검증필요: 조문·정확 문언] |
| **2025. 5. 1.** | 관리처분계획 **사전 검증** | 인가 전 사전 검증 신청 근거 마련 [검증필요] |
| **2025. 6. 4.** | **재건축진단**(명칭 변경) | '재건축 안전진단' → **'재건축진단'**. 준공 30년 경과 단지는 **사업시행계획인가 前까지** 진단 완료를 조건으로 조기 착수 가능 |
| **2025. 6. 4.** | 진단 절차 간소화 | 예비단계 **현지조사 폐지**, **연접 단지 통합진단** 허용, 요청 접수 후 **30일 내** 실시계획 통보 [검증필요: 30일 기한 조문] |
| **정비계획 단계** | 입안요건 완화 · **입안요청** 제도 | 노후도 등 정비구역 지정요건 완화, 토지등소유자·추진위의 **정비계획 입안요청권** 신설 [검증필요: 노후도 산정 완화 수치·시행일] |
| **추진 단계** | **사전협약** 제도 | 사업 초기 지자체·시행자 간 협약으로 인허가 예측성 제고 [검증필요: 근거조문·시행일] |
| **온라인화** | 전자적 동의·온라인 총회 | 전자서명 동의, 온라인 총회 활성화 [검증필요: 각 시행일] |

> ⚠️ **재개발 동의율 완화(75% → 70%)는 별건**으로 국회 논의가 진행된 사안이며, 본 표의 5/1 완화(재건축)와 혼동하지 않아야 한다. 재개발 완화의 입법·시행 여부는 [검증필요].

## E. 용어집 (가나다순)

| 용어 | 간단 정의 |
|------|------|
| **관리처분계획** | 종전자산을 종후자산(새 아파트 등)에 어떻게 배분하고 분담금·청산금을 얼마로 정할지 확정하는 계획. 정비사업의 성패를 좌우하는 핵심 절차(제74조). |
| **노후·불량 건축물** | 구조 안전·기능·주거환경 등이 기준에 미달하는 건축물. 정비구역 지정의 핵심 요건. |
| **대의원회** | 조합원 수가 많을 때 총회 권한 일부를 대행하는 기구(조합원 100명 이상 시 필수). |
| **매도청구** | 재건축에 동의하지 않은 자에게 조합이 시가로 소유권 매도를 청구하는 제도(제64조). |
| **비례율** | (종후자산 총액 − 총사업비) ÷ 종전자산 총액. 조합원 권리가액 산정의 핵심 지표. |
| **분담금** | 조합원이 새 자산을 취득하기 위하여 추가로 부담하는 금액(권리가액 < 분양가일 때). |
| **사업시행계획인가** | 사업의 구체적 설계(건축·기반시설·이주 등)를 담은 계획을 인가받는 절차(제50조). |
| **수용** | 재개발에서 미동의자 등의 토지·건물을 공용수용 절차로 취득하는 방식(제63조). |
| **이전고시** | 준공 후 대지·건축물 소유권을 확정하여 조합원에게 이전하는 공적 고시. 물권변동의 기준시점. |
| **재건축진단** | 구 '재건축 안전진단'. 재건축 실시 여부를 판정하는 진단(2025년 명칭·절차 개편). |
| **재건축초과이익환수제(재초환)** | 재건축으로 발생한 초과이익의 일부를 부담금으로 환수하는 제도(재건축만 적용). |
| **정관** | 조합의 조직·운영·권리의무를 정한 자치규범. 필수기재사항은 제40조. |
| **정비계획** | 정비구역에서 시행할 사업의 방향·용도·기반시설 등을 담은 계획. |
| **정비구역** | 정비사업을 시행하기 위해 지정·고시된 구역. |
| **정비기반시설** | 도로·상하수도·공원·공용주차장 등 정비구역의 공공기반시설. |
| **정비사업전문관리업(정비업체)** | 조합 업무를 위탁·지원하는 등록업체(법 제6장). |
| **조합** | 토지등소유자로 구성되어 정비사업을 시행하는 법인. |
| **조합설립추진위원회(추진위)** | 조합 설립을 준비하는 임시기구. 토지등소유자 과반수 동의로 구성·승인(제31조). |
| **조합원 입주권** | 관리처분계획 인가로 조합원이 취득하는, 새 주택을 분양받을 권리(세법상 과세 대상). |
| **종전자산 / 종후자산** | 정비 전 소유 자산 / 정비 후 배분받는 자산. 평가액이 비례율·분담금의 기초. |
| **주거환경개선사업** | 저소득 주민 밀집·기반시설 극히 열악 지역의 공공성 강한 정비사업. |
| **청산금** | 권리가액과 분양가의 차액 정산금(받거나 내는 금액). |

## F. 참고 법령·자료 색인

정확한 조문·수치·판례는 아래 **1차 출처(공식)**의 현행본과 대조하여야 한다.

**■ 법령 원문 (반드시 '현행' 버전 확인)**
- **국가법령정보센터** law.go.kr — 「도시 및 주거환경정비법」 / 시행령 / 시행규칙 원문·연혁·신구조문 대비표. *조문 인용의 최종 근거.*
- **자치법규정보시스템** elis.go.kr — 각 시·도 **도시정비 조례**(동의율 가중·임대주택 비율 등 지역별 상세는 조례에서 확정).

**■ 유권해석·법령해석**
- **법제처 국가법령정보센터 / 법령해석례** moleg.go.kr — 조문 적용에 관한 정부 유권해석.
- **찾기 쉬운 생활법령정보** easylaw.go.kr — 재개발·재건축 절차·동의요건의 쉬운 해설(입문용, 조문은 원문 재확인 필요).

**■ 정책·개정 동향**
- **국토교통부** molit.go.kr — 재건축진단 기준 고시, 정비사업 활성화(패스트트랙) 정책자료·개정 보도자료.
- **국토교통부 정비사업 통계·고시** — 재건축진단 기준·노후도 산정 기준 등 하위 고시.

**■ 판례**
- **대법원 종합법률정보** glaw.scourt.go.kr — 조합설립인가 무효, 매도청구, 총회결의 하자 등 주요 선례의 **사건번호 확정**(→ 본문 16장).
- **판례 검색 보조** casenote.kr 등 — 조문·판례 열람 보조(원문은 위 공식 사이트 재확인).

> ⚠️ **인용 원칙** — 이 책의 조문·수치는 집필 시점 기준이다. 실제 사업 적용·법률 자문 시에는 (1) law.go.kr 현행 조문, (2) 해당 지자체 조례, (3) 필요 시 변호사·정비업체 확인을 거쳐야 한다. 판례는 반드시 **대법원 종합법률정보에서 사건번호로 원문 확인** 후 인용하여야 한다.
