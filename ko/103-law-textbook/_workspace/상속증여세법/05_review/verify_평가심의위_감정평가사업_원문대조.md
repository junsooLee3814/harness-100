# 원문대조 검증 결과 — 평가심의위원회·부동산 감정평가 사업 (2026-08-13, 21·22장 검수용)

## 평가심의위원회 (시행령 제49조의2) — 확정 사항

1. 현행 명칭은 **"평가심의위원회"** — "재산평가심의위원회"는 구 명칭, 혼용 금지. 현행 훈령명 「평가심의위원회 운영 규정」(국세청 훈령 제2545호, 2022.12.22.).
2. 설치: 시행령 제49조의2 제1항 — **국세청과 지방국세청에 각각** 설치.
3. 위원 수는 **훈령 제4조 기준으로만 인용**: 국세청 = 내부 3 + 외부 11명 이내(위원장 자산과세국장), 지방청 = 내부 3 + 외부 4명 이내(위원장 성실납세지원국장), 외부위원 임기 2년·1회 연임. **시행령 제2항 자체의 위원 수는 원문 미확인 — 미러 수치 인용 금지.**
4. 심의 사항 6종: 설치·운영 / 시가인정 심의 / 비상장주식 평가(시행령 **제54조 제6항** 연결 확정) / 시가불인정 감정기관 지정 / 가업상속·승계 업종변경 승인 / 오피스텔·상업용 건물 기준시가 자문(제49조의2 제1항 **제4호** 확정).
5. 법 제60조 제1항·제2항 문언 확정 (시가 원칙 + "대통령령으로 정하는 바에 따라 시가로 인정되는 것 포함"). 시행령 제49조 제1항 단서: **평가기준일 전 2년 이내** 매매등도 평가심의위 심의 거쳐 시가 포함 가능.
6. **대법원 2026.4.2. 선고 2025두35499** — 평가기간 밖 가액 규정이 모법 위임범위 내로 유효 판시. 공식 판례검색 확인: lx.scourt.go.kr/search/detail/precedent/0/2026000036467 — **가장 신뢰도 높은 인용처.**

## 부동산 감정평가 사업 (舊 꼬마빌딩 감정평가) — 확정 사항

1. 명칭: 2025.6.11. 훈령(제2681호)부터 **"부동산 감정평가 사업"** — "비주거용 부동산 감정평가 사업"은 구 명칭. 대상은 주택·비주거용 부동산·나대지·부동산에 관한 권리까지 포함.
2. 선정 기준 (사무처리규정 제72조 제2항, 원문 축자 확인): 추정시가(5개 이상 감정평가법인, 최고·최소 제외 평균)와 보충적 평가액의 **차이 5억원 이상 또는 차이 비율 10% 이상** — 단 "고려하여 선정할 수 있으며"의 **재량** 규정. 5억 기준은 **2025.1.1. 시행**(종전 10억), 법정 결정기한 도래분부터 적용.
3. 근거 구조: 제72조 ① 시행령 제49조 제1항 → ④ 감정가액은 **평가심의위원회 시가 인정 심의 필수** — 두 제도의 직접 연결 고리.
4. 판례: ① 대법원 2026.4.30. 2024두61780 — 소급감정 과세 적법, 단 "가격변동의 특별한 사정이 없을 것" 요건은 **감정가액평가서 작성일까지** 충족 필요(요건 강화). 사건번호는 언론 3곳 교차확인, 공식 DB 대조 미완 → 인용 시 [검증필요]. ② 서울고법 2024.8.20. 2023누42333 — 과세관청 감정 의뢰는 정당한 권한 (국세청 보도자료 명기).
5. **예산은 2026년 감액** (2025년 96억 → 2026년 67억, 약 30%↓) — "증액" 서술 금지 (언론 보도 기반, 1차 자료 아님).

## [검증필요] 유지 항목

- 평가기간 문언 현행판 ("증여일 전 6개월~후 3개월") — 미러는 구버전, 원문 미확보.
- 시가불인정 감정기관 지정 근거 항번호 (제49조 제7항 vs 제8항 — 미러 엇갈림).
- 훈령 제2760호(2026.8.3. 시행)의 제72조 개정 여부.
- 지방청 외부위원 4→9명 확대 — 행정예고 단계로만 서술.
- 한국경제 2025.12.25. "꼬마빌딩 감정평가 위법" 하급심 보도 — 사건번호 미확인. "법원이 일관되게 인정" 식 서술 금지.
