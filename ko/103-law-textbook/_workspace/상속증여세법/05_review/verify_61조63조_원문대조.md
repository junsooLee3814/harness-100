# 조문 원문대조 검증 결과 — 법 제61조·제63조 (2026-08-13, 22장 검수용)

검증 기준: 상속세 및 증여세법 [시행 2026. 1. 2.] [법률 제21065호] / 시행령 [시행 2026. 2. 27.] [대통령령 제36131호]
1차 출처: law.go.kr lsLinkCommonInfo.do (법 제60~66조 원문) · lumLsLinkPop.do (시행령 제50조·제52조의2)

## 확정 교정 사항 (본문 반영 필수)

1. **제61조 제1항 제2호 (건물)**: 현행 문언은 "~등을 **고려하여**" — "참작하여" 아님.
2. **제63조 제1항 제1호 가목**: 법 문언은 "「자본시장과 금융투자업에 관한 법률」에 따른 증권시장으로서 **대통령령으로 정하는 증권시장**" — '유가증권시장·코스닥시장'은 법이 아니라 **시행령 제52조의2 제1항**에 명시.
3. **가목 평가**: "**거래소** 최종 시세가액" ("한국거래소"는 구법 표현) / "(**거래실적 유무를 따지지 아니한다**)" ("불문한다" 아님) / 평가기준일이 매매 없는 날인 경우 **전일 기준** 단서 존재.
4. **코스닥 상장주식은 현행법상 가목**으로 평가 (구법에서는 별도 나목 — 각주 소재로만 사용).
5. **다목은 삭제 <2016.12.20.>** — 현행 조문으로 인용 금지. 기업공개 준비 중 주식은 **제63조 제2항**.
6. **2개월 기간 계산 특례 = 시행령 제52조의2 제2항** (제53조 아님 — 제53조 인용 시 삭제 권장).
7. **임대료 환산가액 = 법 제61조 제5항** + 시행령 제50조 제7항 "(1년간의 임대료 ÷ 기획재정부령으로 정하는 율) + 임대보증금". **큰 금액(higher-of) 규칙**이지 대체 규칙 아님.

## [검증필요] 유지 항목 (1차 출처 미확보)

- 시행규칙상 임대료 환산율 **100분의 12** — 검색 요약에만 등장, 시행규칙 제15조의2 원문 미확인. 본문 게재 시 [검증필요] 표기 유지.
- 제61조 제6항 문언 (고시가액 의견청취·재산정 절차) — 요약 확인만 됨.
- 시행령 제52조의2 제2항 각 호 세부 문언 — 조문 번호는 확정, 문언은 부분 확인.
