## 10장 — 금융재산·동거주택·재해손실·종합한도

| 항목 | 내용 | 상태 |
|---|---|---|
| 금융재산공제 §22 | 순금융재산(금융재산−금융채무): 2천만 이하 **전액** / 초과 시 **Max(20%, 2천만)** / **한도 2억**. 거주자만 | ✅ |
| 제외 | **최대주주 주식** + 미신고 **차명 금융재산**(§22②) | ✅ |
| 동거주택 §23의2 | 주택가액(부수토지 포함, 담보채무 차감) **100%, 한도 6억**. ⚠️ "40%·5억"은 2019 이전 옛 수치 — 검색 오염 | ✅ |
| 동거주택 요건 3 | ①소급 **10년 동거**(미성년 기간 제외) ②10년간 계속 1세대1주택(무주택 기간 포함) ③상속개시일 현재 무주택(또는 공동 1주택)인 **직계비속(+그 배우자)** — 배우자 상속인은 불가 | ✅ |
| 동거 특례 | 징집·취학·근무·요양 — 계속 동거 간주하되 **기간 불산입** (두 규칙 혼동 주의) | ✅ |
| 재해손실 §23 | **신고기한 내** 재난 멸실·훼손, 보험 보전분 제외, 거주자만 | ✅ |
| **종합한도 §24** | 공제한도 = 과세가액 − ①상속인 아닌 자 유증·사인증여 − ②상속포기로 후순위가 받은 재산 − ③사전증여 가산분(공제 차감 후, **과세가액 5억 초과 시에만**) | ✅ |

## 13장 — 비거주자·국제상속

| 항목 | 내용 | 상태 |
|---|---|---|
| 과세범위 | 비거주자 사망 → 국내 소재 재산만 (§3) | ✅ |
| 공제 제한 | **기초 2억 + 감정평가수수료만** — 배우자·일괄·금융·동거주택 전부 불가 | ✅ |
| 신고기한 | §67④ 외국 주소 시 9개월 — 주어("전원" 여부) 자구 원문 대조 필요 ⚠️ | ⚠️ |
| 외국납부세액공제 §29 | 거주자 사망 + 외국 소재 재산 외국 과세 시. 한도 = 산출세액 × (외국 과세 재산 과표 ÷ 전체 과표), 실납부액 한도 | ✅/⚠️ |
| 조세조약 | **한미 상속세 조약 없음** (한미조세조약은 소득용) — 이중과세는 각국 국내법 공제로만 | ✅ |

## 오해·함정 9건

①동거주택 "40%·5억" 옛 수치 ②배우자가 동거주택 상속 시 공제 불가(직계비속 한정) ③최대주주 주식·차명계좌는 금융재산공제 제외 ④**손자 유증 → §24 종합한도 축소 → 일괄공제 5억조차 못 받을 수 있음** ⑤가업상속 후 5년 사후관리 위반 추징 ⑥영주권≠비거주자 (생활관계 기준) ⑦비거주자도 국내 재산 과세 + 공제 2억뿐 ⑧한미조세조약은 상속세 무관 ⑨재해손실은 신고기한 내 + 보험 보전분 제외
