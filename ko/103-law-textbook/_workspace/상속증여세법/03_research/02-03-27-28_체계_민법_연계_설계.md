# 제2·3·27·28장 조사 자료 — 법령 체계·민법 기초·연계 세목·설계

## 2장 — 법령 체계

| 항목 | 내용 | 상태 |
|---|---|---|
| 편제 | 6개 장: 1장 총칙(§1~6) / 2장 상속세(§7~30) / 3장 증여세(§31~59) / 4장 평가(§60~66) / 5장 신고·납부(§67~75) / 6장 보칙·결정경정(§76~) — △제6장 제목·범위 원문 확정 필요 | ◐ |
| 해석 서열 | **기본통칙은 행정규칙 — 법원·국민 비구속**, 과세처분의 적법 근거 불가 (대법 2007.2.8. 2005두5611). 법률·령·규칙(법규) > 통칙·집행기준·예규(내부 지침) > 판례·심판례(사실상 선례) | ● |
| 신뢰 보호 접점 | 국기법 §18③ 소급과세 금지(비과세 관행) — 예규 신뢰의 부분적 보호 | ◐ |
| 국기법 소관 | 가산세(무신고 20%·부정 40%·납부지연 일 22/100,000)·제척기간(10년/부정·무신고 15년, 50억 초과 은닉 '안 날부터 1년' 특례)·불복(심사·심판 전치) | ◐ |

## 3장 — 민법 기초

| 항목 | 내용 | 상태 |
|---|---|---|
| 상속순위 | 1 직계비속 / 2 직계존속 / 3 형제자매 / 4 4촌 이내 방계 (민법 §1000). 배우자는 1·2순위와 공동, 없으면 단독(§1003) | ● |
| 상속분 | 배우자 = 공동상속인 상속분의 **5할 가산**(§1009②) — "1.5배"의 정확한 표현 | ● |
| 대습상속 | §1001·§1003② / 상속결격 §1004 (당연 결격 — 선고 불요) | ● |
| 포기·한정승인 | 안 날부터 **3개월**(§1019①). 특별한정승인(§1019④ — 몰랐던 채무초과, 안 날부터 3개월) | ● |
| 세무 접점 함정 | ①포기해도 사전증여 합산·납부의무 ②**보험금은 포기해도 수령 가능하나 상속세 과세** | ◐ |
| 유류분 헌재 | 2024.4.25. 2020헌가4등: **형제자매 유류분 단순위헌(즉시 상실)** + 상실사유 부재·기여분 미반영 헌법불합치(2025.12.31 시한) | ● |
| 유류분 개정 | **2026.2.12. 민법 개정 통과**(법률 제21454호 추정 △): 유류분 상실 사유 신설·동거간호 기여 증여 산정 제외·가액(현금)반환 원칙화 — **법률번호·조문 원문 대조 필수** | ◐/△ |
| 잔존 유류분율 | 직계비속·배우자 1/2, 직계존속 1/3 (형제자매는 위헌으로 소멸) | ● |
| **상속권 상실 (구하라법)** | 민법 **§1004의2** 신설, **2026.1.1. 시행**: 직계존속의 부양의무 중대 위반·중대 범죄·심히 부당한 대우 → **가정법원 선고**로 상속권 상실 (유언 또는 공동상속인 청구, 확정 시 상속개시로 소급) | ● |
| △ | 상속권 상실자의 자녀 대습상속 처리 — 2026.2 개정과 얽힘, 원문 확인 | △ |

## 27장 — 다른 세금과의 관계

| 항목 | 내용 | 상태 |
|---|---|---|
| 취득세 (상속) | 농지 **2.3%** / 농지 외 **2.8%** (+지방교육세 등). **무주택 가구 1주택 상속 0.8%** 특례 | ● |
| 취득세 (증여) | 표준 **3.5%** / 조정대상지역 3억↑ 주택 **12%** 중과(1세대1주택자의 배우자·직계 증여는 예외). 과표 = 시가인정액(2023~) | ●/◐ |
| **이월과세** | 소법 §97의2 — 배우자·직계존비속 증여 부동산을 **10년 내 양도** 시 취득가액 = 증여자의 당초 취득가액 (수증자 증여세는 필요경비). **2023.1.1. 이후 증여분 10년**(이전 5년). 예외: 비교과세(이월이 유리하면 미적용)·수용·1세대1주택 비과세 등 ◐ | ● |
| 양도 취득가액 | 소법 령§163⑨ — 상속·증여 재산의 취득가액 = **상증법 §60~66 평가액**(결정·경정 가액 우선). **무신고→기준시가 결정→취득가액↓→양도세 폭탄.** 단 평가 서열(매매사례→감정→기준시가)은 신고 유무와 무관 — 뉘앙스 병기 | ● |
| 종부세 특례 | 상속주택 주택 수 제외: 상속 후 **5년** 미경과, 또는 **지분 40% 이하**, 또는 지분 공시가 **6억(비수도권 3억) 이하** — 세율·1주택 판정에서만 제외(과표 합산) | ● |

## 28장 — 설계 종합

- **"10년"의 삼중 구조**: §53 공제 10년 통산 + §47② 동일인 10년 합산 + §13 상속 전 10년 가산 — 세 조문이 맞물려 "10년 주기 증여"가 성립 ●
- 증여 당시 평가액 합산 → 가치상승 자산 조기 증여 근거 ●
- **흔한 실수 (복수 출처)**: ①10년 내 상속 개시로 사전증여가 오히려 증세(§24 한도 축소) ②분산증여 합산 간과 ③이월과세 10년 무시 ④무신고로 취득가액 상실 ⑤2차 상속 미고려(배우자 몰아주기의 역설)
- **세무사 자문 필수 경계**: 비상장주식 평가·가업승계·유류분 병존·부담부증여 실행·감정평가 신고·국외재산·평가심의위·연부연납/물납·협의분할 재분할(증여 의제 위험) — "구조 이해까지가 책, 실행은 자문"
