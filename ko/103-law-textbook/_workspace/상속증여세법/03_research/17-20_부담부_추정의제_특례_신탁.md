# 제17~20장 조사 자료 — 부담부증여·증여추정의제·조특법 특례·신탁

> law-researcher 위탁 조사 (2026-08-12). ● 법령원문/국세청 / ◐ 복수 2차출처 / ○ 미확정

## 17장 — 부담부증여

| 항목 | 내용 | 근거 | 상태 |
|---|---|---|---|
| 구조 | 증여재산가액 − **그 재산에 담보된 채무**(임대보증금 포함, 수증자 인수분) = 증여세 과세가액. 재산과 무관한 일반 채무 인수는 차감 불가 | §47① | ● |
| 배우자·직계 추정 | 채무 미인수 **추정** — 국가·금융기관 채무 등 객관적 입증 시 배제 (금융기관 대출·확정일자 임대차) | §47③ | ● |
| 양도세 처리 | 채무 상당분 = 유상이전 → **증여자에게 양도세.** 안분: 양도가액=인수채무액, 취득가액=전체 취득가액×(채무/증여가액) | 소법§88·령**§159** | ● |
| 취득세 | 채무분 유상세율(주택 1~3%, 중과 8·12%) + 증여분 무상 3.5%(조정지역 기준시가 3억↑ 주택 12%). 무상 과표는 시가인정액(2023~) | 지방세법 | ◐ (조정지역 범위 2025.10 확대 — ○ 재확인) |
| 함정 | 이월과세(소법§97의2, 10년)와 결합 검토 / 국세청 **부채 사후관리** — 인수 채무 상환 시 자금출처 재검증 | | ◐ |

## 18장 — 증여추정·의제

| 항목 | 내용 | 근거 | 상태 |
|---|---|---|---|
| 배우자 등 양도 추정 | 배우자·직계존비속 양도 → 증여 추정. 특수관계인 경유 **3년 내** 재양도도 추정. 배제: 경매·공매·대가 입증 | §44 | ● |
| 취득자금 추정 | 자력취득 곤란 시 추정. **배제: 미입증액 < Min(취득가×20%, 2억)** ("10억 미만 80%"는 이 산식의 귀결) | §45·령§34 | ● |
| 배제기준 (훈령) | 10년 합산: 30세 미만 총 1억 / 30세↑ 총 2억(주택 1.5억) / 40세↑ 총 4억(주택 3억). **기준 이내라도 증여사실 확인 시 과세** | 사무처리규정§42 | ◐ (○ 훈령 개정 빈번) |
| 명의신탁 의제 | 등기 필요 재산(**토지·건물 제외** — 주식 중심). 조세회피 목적 없음 입증 시 배제(입증책임 명의자). **2019~ 납세의무자 = 실제소유자** | §45의2 | ● |
| 일감몰아주기 | 거래비율 30%(중견 40·중소 50) + 보유비율 3%(중소·중견 10) 초과 시 매년 증여의제 | §45의3 | ● |
| 특정법인 거래 | 30% 지배 법인 무상제공 — 개인별 이익 1억 기준 | §45의5 | ○ (1억 기준 조문 확인 필요) |
| 출처조사 실무 | 소득금액증명·이자 실지급 내역·통장 흐름. 차용증만으론 부족 — 무이자 차용은 §41의4 병행 | | ◐ |

## 19장 — 창업자금·가업승계 특례 (**근거법 = 조세특례제한법** ●)

| 항목 | 내용 | 근거 | 상태 |
|---|---|---|---|
| 창업자금 | 18세↑ 자녀 ← **60세↑ 부모**, 양도세 과세대상 재산 제외. **5억 공제 + 10% 단일세율.** 한도 **50억(신규고용 10명↑ 시 100억)** ⚠️ "30억/50억"은 2022 이전 옛 수치 | 조특법 §30의5 | ● |
| 창업자금 사후 | **2년 내 창업·4년 내 전액 사용**·10년 내 목적 외 사용 시 추징+이자상당액 | 동조 | ● |
| 가업승계 주식 | **10억 공제, 과표 120억 이하 10% / 초과 20%.** 한도 300/400/600억(영위 10/20/30년) | 조특법 §30의6 | ● (○ 한도 상향 기사 = 개정안 단계) |
| 가업승계 사후 | **3년 내 대표 취임**(구 5년 주의)·**5년 사후관리**(구 7년 주의) | 동조 | ● |
| 상속 시 정산 | 특례 재산은 **기간 제한 없이** 상속세 과세가액 가산 정산 (기납부 특례세액 공제). 가업승계분은 요건 충족 시 가업상속공제 연결 가능 | §30의5⑧ | ●/◐ |
