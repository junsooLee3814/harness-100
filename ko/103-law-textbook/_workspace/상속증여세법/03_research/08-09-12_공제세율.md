## 근거 조문 — 9장 (배우자상속공제)

| 항목 | 내용 | 근거 | 확인상태 |
|---|---|---|---|
| 기본 구조 | **실제 상속받은 금액** 공제. 한도 = min(한도식, **30억**) | §19① | 원문 확인 |
| 최소공제 | 실제 상속액 없거나 5억 미만 → **5억** (분할기한 요건 불문) | §19④ | 원문 확인 |
| 한도식 | **(A−B+C)×D−E** — A: 상속재산가액(본래+간주+추정, 비과세·불산입·공과금·채무 차감) / B: **상속인 아닌 수유자** 유증분 / C: 사전증여 중 상속인 수증분 / D: 배우자 **법정상속분**(상속포기 무시) / E: 사전증여 중 배우자 수증분의 **과세표준** | §19①1 + 령§17 | 복수 출처 (법문 수식 이미지 — 축자 대조 미완) |
| 분할기한 | 신고기한 다음날부터 **9개월** (등기 필요 재산은 완료분 한정). 미분할 → 5억만 | §19② | 원문 확인 |
| 부득이한 사유 | 소송·심판 종료일 다음날부터 6개월 | §19③ | 원문 확인 |

## 근거 조문 — 12장 (세율·세액 계산)

| 항목 | 수치 | 근거 | 확인상태 |
|---|---|---|---|
| 세율표 | 1억↓ 10%(공제0) / 1억~5억 20%(1천만) / 5억~10억 30%(6천만) / 10억~30억 40%(1.6억) / 30억↑ 50%(4.6억) — 법문 가산식과 누진공제형 **산술 일치 검산 완료** | §26 | 복수 출처 (국세청+법제처 완전 일치) |
| 과세최저한 | 과표 50만원 미만 부과 제외 | §25② | 원문 확인 |
| 세대생략 할증 | **자녀 제외 직계비속**: 산출세액 × (그 수유·상속분/총상속재산) × **30%**. 미성년+20억 초과 → **40%**. **대습상속 제외** | §27 | 원문 확인 |
| 신고세액공제 | **3%** (2019 이후. 옛 5·7·10% 주의) | §69① | 원문 확인 |
| 증여세액공제 | 사전증여분의 증여 당시 산출세액 공제 (안분한도 §28②) | §28 | 원문 확인 |
| 단기재상속 공제 | 10년 내 재상속 — 1년 내 100% → 연 10%p 체감 | §30 | 복수 출처 |

## 계산 순서 (12장 종합 사례 골격)

총상속재산(본래+간주+추정) → 차감(비과세·불산입·공과금·장례비·채무 §14) → 가산(사전증여 §13) = **과세가액** → 상속공제(§24 종합한도 내: max(기초+인적, 일괄5억) + 배우자공제 + 금융재산·동거주택) → 감정평가수수료 → **과세표준**(§25) → ×세율(§26) = **산출세액** → 세대생략 할증(§27) → 세액공제(증여§28→외국§29→단기재상속§30→신고 3% §69) → 가산세·분납·연부연납 → **납부세액**

## 집필자 주의 — 함정 9건

1. **2024 개정안(최고세율 40%·자녀공제 5억)은 부결** — 검색 상위 오염. 현행: 자녀 5천만·최고 50%
2. 유산취득세: 2028 시행 목표 발표, **미통과** — "개정 예고"로만
3. 신고세액공제 옛 비율(10→7→5%) 자료 유통 중 — 현행 **3%**
4. 인적공제 옛 금액(자녀 3천만·연로 60세) 구자료 흔함 / 미성년 기준 19세 (옛 20세)
5. 태아 포함은 2023.1.1. 이후 상속분부터
6. 장애인공제 조문 인용 시 "국가데이터처장" (2025.10 개칭)
7. 배우자 한도식: C는 상속인 수증 **가액**, E는 배우자 수증분 **과세표준** — 혼동 빈발. 법정상속분은 상속포기 무시
8. 일괄공제 무신고 5억 자동 / §21② 단독상속 배제는 "배우자가 유일한 상속인"인 경우 — 협의분할 전부 취득은 실무상 가능 해석 (예규 미확정)
9. AI·포털 요약의 세율표 오염 실재 (조사 중 "10/15/20/25/30%" 오표 실제 발생) — 반드시 국세청 표 대조
