### 사례 13-2 〔표준〕: 미국에 2억을 냈는데 1억 7,600만원만 빼 준다

**상황** — 거주자 김국제 씨가 사망했다. 상속재산은 국내 15억원 + 미국 소재 부동산 10억원 = 과세가액 25억원. 상속인은 배우자와 자녀이며 배우자 상속공제는 최소 5억원을 적용한다. 유족은 미국에 유산세(estate tax) 2억원을 실제로 납부했다.

| 단계 | 계산 | 금액 |
|---|---|--:|
| 과세가액 | 국내 15억 + 국외 10억 | 25억원 |
| 상속공제 | 일괄 5억 + 배우자 최소 5억 | 10억원 |
| 과세표준 | 25억 − 10억 | 15억원 |
| 산출세액 | 15억 × 40% − 누진공제 1.6억 | 4억 4,000만원 |
| 외국재산분 과세표준 | 15억 × (10억 ÷ 25억) | 6억원 |
| **§29 공제한도** | 4.4억 × (6억 ÷ 15억) | **1억 7,600만원** |
| 외국납부세액공제 | min(실납부 2억, 한도 1.76억) | 1억 7,600만원 |
| **한도 초과 소멸분** | 2억 − 1.76억 | **2,400만원** |
| 공제 후 세액 | 4.4억 − 1.76억 | 2억 6,400만원 |
| 신고세액공제 | 2.64억 × 3% | 792만원 |
| **납부세액** | 2.64억 − 792만 | **2억 5,608만원** |

**결론** — 미국에 낸 2억원이 전액 공제되지 않는다. **2,400만원**은 어느 나라에서도 회수되지 않고 사라진다. 외국 세율이 한국보다 높을수록 이 소멸분이 커진다. 또한 신고세액공제 3%는 산출세액이 아니라 **외국납부세액공제를 뺀 금액**을 기준으로 계산된다(§69).

### 사례 13-3 〔변형〕: 국외재산이 크면 공제절벽이 거꾸로 선다

**상황** — 재산 구성이 국내 5억원 + 국외 20억원인 경우. 국외재산 소재국에는 상속세가 없다고 가정한다(홍콩·싱가포르 유형). 상속인은 배우자와 자녀.

| | (A) 거주자 | (B) 비거주자 |
|---|--:|--:|
| 과세 범위 | 국내외 전부 25억 | **국내 5억만** |
| 공제 | 일괄 5억 + 배우자 5억 = 10억 | 기초 2억 |
| 과세표준 | 15억 | 3억 |
| 산출세액 | 15억×40% − 1.6억 = 4억 4,000만 | 3억×20% − 1,000만 = 5,000만 |
| 신고세액공제 | 1,320만 | 150만 |
| **납부세액** | **4억 2,680만원** | **4,850만원** |
| **격차** | | **3억 7,830만원** |

**결론** — 사례 13-1(국내재산 10억)에서는 비거주자가 1억 7,460만원 더 냈는데, 여기서는 비거주자가 3억 7,830만원 **덜** 낸다. 공제절벽의 방향은 고정된 것이 아니라 **국내재산 대 국외재산의 비중**이 결정한다. "비거주자는 불리하다"도 "비거주자는 유리하다"도 둘 다 반쪽이다.

### 사례 13-4 〔함정〕: 상속인이 비거주자라고 공제가 깎이지 않는다

**상황** — 피상속인은 한국 거주자, 국내재산 12억원. 유일한 상속인인 자녀는 미국 영주권자로 세법상 비거주자다(배우자 없음).

| 단계 | ✗ 흔한 오해 (상속인 기준) | ✓ 실제 (피상속인 기준) |
|---|--:|--:|
| 적용 공제 | 기초 2억 | 일괄 5억 |
| 과세표준 | 10억 | 7억 |
| 산출세액 | 10억×30% − 6,000만 = 2억 4,000만 | 7억×30% − 6,000만 = 1억 5,000만 |
| 신고세액공제 | 720만 | 450만 |
| **납부세액** | **2억 3,280만원** | **1억 4,550만원** |
| **과다계산액** | | **8,730만원** |

**결론** — 상속공제의 적용 여부는 **돌아가신 분**이 거주자였는지로 정해진다. 상속인이 전원 해외에 살아도 피상속인이 거주자면 일괄공제·배우자공제가 그대로 살아 있다. 다만 **신고기한은 상속인의 주소도 본다** — 이 사안은 세액은 그대로인 채 기한만 9개월이 된다. 판정 기준이 항목마다 다르다는 점이 이 장의 핵심 함정이다.
