# 제17장 · 부담부증여 — 빚과 함께 넘기기

> **이 장에서 다루는 것** — 실무 질문 최다 유형이다. (1) 대출·전세보증금이 낀 부동산을 증여하면 채무 부분은 **양도**, 나머지만 **증여**로 구분되는 구조, (2) 배우자·직계존비속 간에는 채무 인수를 **인정하지 않는다는 추정**과 그 번복(입증) 방법, (3) 유리한지 불리한지를 판정하는 실익 판단, (4) 검산 완료 안분 사례, (5) 총부담 비교와 유불리의 결론이 역전되는 사례, 그리고 자주 묻는 질문. **2026년 시행 상증세법 기준이다.**

---

## 17.1 쉽게 이해하기 — 10억짜리 집을 "6억짜리 증여"로 만드는 구조

시가 10억 아파트에 은행 대출 4억이 걸려 있다. 이 집을 대출과 함께 자녀에게 넘기면 자녀가 실제로 공짜로 받는 것은 6억뿐이다. 세법도 그렇게 본다.

- **증여 부분 (6억)** — 자녀에게 증여세
- **채무 부분 (4억)** — 자녀가 빚을 대신 갚아주는 대가를 받고 판 것과 같으므로, **부모에게 양도소득세**

한 번의 이전에 두 개의 세금이 병렬로 부과되는 것이 부담부증여다. 증여세 누진구간을 낮추는 효과가 있어 절세 수단으로 흔히 거론되지만, **양도세·취득세까지 합산한 총액**을 계산해 보기 전에는 유불리를 알 수 없다.

> **부담부증여 = 채무를 함께 넘기는 증여.** 하나의 재산 이전이 무상분(증여)과 유상분(양도)으로 구분되어, **서로 다른 사람에게 서로 다른 세금**이 동시에 부과된다.

> **⚠️ 주의 — "부담부증여는 무조건 절세"가 이 주제 최대의 오해다.** 줄어드는 것은 증여세뿐이고, 그 대신 **없던 양도세가 새로 발생한다.** 증여세는 재산가액 전체에 누진세율이 붙는 반면 양도세는 차익에만 붙으므로, **차익이 작을수록(=취득가액이 높을수록) 유리하고 차익이 클수록 불리하다.** 부모가 오래전 낮은 가액에 취득한 집일수록 효과가 떨어진다는 뜻이다 — 절세 상담에서 결론이 가장 자주 역전되는 지점이며, 역전되는 실제 계산은 17.4의 사례 17-2와 17-3에서 나란히 본다.

## 17.2 법령 근거 (법 제47조)

**■ 차감되는 채무의 요건 (제1항)** — 모든 채무가 해당되는 것은 아니다. **그 증여재산에 담보된 채무**(전세보증금·임대보증금 포함)로서 **수증자가 실제로 인수**한 것만 증여재산가액에서 뺀다. 그 재산과 무관한 부모의 신용대출을 자녀가 대신 변제하기로 하였다는 식의 약정은 차감되지 않는다.

**■ 배우자·직계존비속 간 추정 (제3항)** — 가족 간 부담부증여에서는 **채무를 수증자가 인수하지 않은 것으로 추정**한다. 채무 차감을 겨냥한 위장 인수가 빈번하기 때문이다. 추정을 번복하려면 **객관적으로 인정되는 채무**임을 입증해야 한다 — 실무상 ① 금융기관 담보대출(대출계약·채무인수 약정) ② 확정일자 있는 임대차계약서상 보증금이 대표적 방법이다.

**■ 양도 부분의 계산 (소득세법 시행령 §159)** — 증여자의 양도차익은 안분으로 구한다:

```
양도가액   = 인수된 채무액
취득가액   = 전체 취득가액 × (채무액 ÷ 증여재산가액)
```

**■ 인정받는 부담부증여의 3요건** — 과세관청에서 부인되는 사안은 대개 아래 셋 중 하나가 결여되어 있다. 셋은 함께 갖추어져야 하며, 하나라도 흠결되면 채무 차감이 전부 부인되어 **재산 전체에 증여세**가 부과된다.

| 요건 | 내용 | 무너지는 전형 |
|---|---|---|
| ① 채무의 실재 | 증여일 현재 **실제로 존재하고 잔액이 남아 있는** 채무 | 이미 상환된 대출을 서류로만 남겨 둠 |
| ② 담보·임대차 결부 | **그 증여재산에** 담보된 채무 — 근저당·전세권·확정일자 임대차 | 재산과 무관한 신용대출·사업자금 대출 |
| ③ 수증자의 인수 | 형식(약정서)이 아니라 실질 — **채무자 명의 변경**과 이자의 실제 부담 | 명의는 그대로 두고 "갚기로 했다"는 합의만 |

> **⚠️ 주의 — 인수는 끝이 아니라 시작이다.** 국세청은 부담부증여의 인수 채무를 **사후관리**한다. 수년 뒤 그 대출을 누가 상환하였는지 다시 확인한다 — 부모가 대신 상환하였다면 그 상환액이 새로운 증여로 과세된다. 자녀의 소득으로 이자·원금을 감당할 수 있는지가 설계의 전제조건이다.

> **💡 실무 팁 (사후관리는 수년 뒤에 이루어진다)** — 인수된 채무는 국세청의 **부채 관리 대상**으로 등록되어, 상환·감소 사실이 확인되면 해명자료 제출 안내가 발송되는 것이 실무 흐름이다. 이때 확인되는 것은 두 가지다 — **원금을 누구 돈으로 갚았는가**, 그리고 **이자를 누가 냈는가.** 이자 대납도 추적 대상이라, 자녀 계좌에서 이자가 출금되더라도 그 계좌에 부모의 자금이 입금되는 구조는 소명되지 않는다. 따라서 증여 시점에 종결되는 것이 아니라 **상환이 완료될 때까지 자녀 명의의 소득·자금 흐름을 축적해 두어야** 한다. [검증필요: 해명자료 안내 서식 명칭·사후관리 주기의 국세청 원문]

## 17.3 실무 절차 — 실익 판단 4요소

| 요소 | 유리한 경우 | 불리한 경우 |
|---|---|---|
| 증여세 | 채무만큼 과세가액↓ → 누진 완화 | — |
| 양도세 (증여자) | 취득가액이 높아 차익 작을 때·1세대1주택 비과세 해당 시 | **다주택 중과·취득가 낮아 차익 큰 자산** |
| 취득세 (수증자) | — | 채무분 유상세율 + 증여분 무상 3.5%(조정대상지역 기준시가 3억↑ 주택은 12% 중과 — [검증필요: 조정지역 범위 2025.10 대책 이후]) |
| 이월과세 | — | 수증자가 10년 내 양도 시 이월과세(소법 §97의2) 결합 검토 필수 (→ 제27장) |

**절차**: ① 채무의 담보·인수 요건 확인 ② 증여·양도 양쪽 세액 시뮬레이션(단순 증여와 총액 비교) ③ 자녀의 상환 능력 검증 ④ 채무인수 약정·금융기관 명의 변경 ⑤ 신고 — 증여세(수증자, 3개월)와 양도세(증여자, 예정신고)를 **각각** 기한 내에.

**■ 유불리 판정 기준 — 세 축으로 압축한다** — 위 4요소를 실제 판단에 쓰려면 결국 아래 세 축이다. **셋 다 왼쪽이면 부담부증여, 셋 다 오른쪽이면 단순증여**가 대체로 유리하고, 혼재되어 있으면 반드시 계산으로 확인해야 한다.

| 축 | 부담부증여가 유리 | 부담부증여가 불리 |
|---|---|---|
| **시가 대비 취득가액 비율** | 높다 (시가의 70%↑) — 양도차익이 작다 | 낮다 (시가의 30%↓) — 양도차익이 크다 |
| **보유기간** | 길다 — 장기보유특별공제(연 2%, 15년 이상 30%)가 차익을 깎는다 | 짧다 — 3년 미만은 공제 0%, 2년 미만 주택은 단기 중과세율 |
| **조정대상지역·주택 수** | 비조정지역이거나 **1세대1주택 비과세** 해당 | 조정지역 다주택 — 양도세 중과 + 취득세 12% 중과 |

> **⚠️ 주의 — 2026년 5월 9일, 다주택자 양도세 중과 유예가 종료됐다.** 그동안은 조정대상지역 다주택자도 기본세율로 계산할 수 있었으나, 유예가 예정대로 끝나 **조정대상지역 2주택 +20%p, 3주택 이상 +30%p**의 중과가 다시 적용된다. 더 심각한 것은 세율이 아니라 공제다 — **중과 대상이 되면 장기보유특별공제를 아예 받지 못한다.** 장기 보유의 이점이 무의미해지면서 위 세 축 중 둘이 동시에 사라지고, 유불리 계산이 전면적으로 달라진다. 조정대상지역은 2025.10.15. 대책으로 서울 전 자치구와 경기 일부까지 확대된 상태이므로, 서울 소재 주택의 부담부증여는 **증여자의 주택 수를 확인하는 것**이 첫 단계다. [검증필요: 조정대상지역 최신 지정 범위, 중과 유예 종료 후 보완조치(토지거래허가 관련)의 적용 범위]

> **💡 실무 팁 (12% 취득세 중과는 3요건이 모두 맞을 때다)** — 증여 취득세 12% 중과는 ① 증여재산이 **조정대상지역** 내 주택이고 ② 시가표준액 **3억원 이상**이며 ③ **증여자가 다주택자**일 것 — 셋이 동시에 충족될 때 적용되는 것으로 실무상 정리된다. 증여자가 1세대1주택자라면 조정지역·3억 이상이어도 기본 3.5%가 적용된다. 세 요건 중 하나만 어긋나도 부담이 크게 달라지므로, "조정지역이니 무조건 12%"라고 속단할 일은 아니다. [검증필요: 지방세법상 3요건 조문·1세대1주택 예외 규정 원문 대조]

## 17.4 판례·사례 — 검산 완료 안분 사례

### 사례 17-1: 대출 4억 낀 10억 아파트의 부담부증여
> 가상의 사례입니다. 2026년 시행 법령 기준. 양도세액·장기보유특별공제·취득세는 소득세법·지방세법 영역이라 별도 계산이 필요하며, 여기서는 안분 구조까지만 다룹니다.

**상황** — 아버지가 15년 전 5억에 취득한 아파트(현재 시가인정액 10억, 담보대출 4억)를 성년 자녀에게 대출 인수 조건으로 증여. 자녀는 재직 중으로 이자 상환 능력이 있고, 금융기관 채무인수 절차를 마쳤다.

| 구분 | 단계 | 계산 | 금액 |
|---|---|---|---|
| **증여세 (자녀)** | 과세가액 | 10억 − 채무 4억 | 6억 |
| | 과세표준 | 6억 − 증여재산공제 5,000만 | 5.5억 |
| | 산출세액 | 5.5억×30% − 6,000만 | 1억 500만 |
| | **납부세액** | 신고세액공제 3% 차감 | **1억 185만원** |
| **양도세 (아버지)** | 양도가액 | 인수 채무 | 4억 |
| | 취득가액 안분 | 5억 × (4/10) | 2억 |
| | **양도차익** | | **2억** (세액은 보유기간·주택 수에 따라 별도 계산) |

**결론** — 단순 증여였다면 증여세 과세표준이 9.5억(10억−5천만)으로 산출세액 2.25억이다. 부담부증여로 증여세는 1.05억으로 줄었지만, **아버지의 양도차익 2억에 대한 양도세와 자녀의 취득세를 더한 총액**이 단순 증여보다 작을 때만 성공한 설계다. 1세대1주택 비과세에 해당하면 양도세가 0이 되어 가장 유리해진다 — 반대로 다주택 중과라면 역효과가 난다.

### 사례 17-2: 총부담 비교 — 끝까지 계산하면 8,045만원 절감
> 가상의 사례입니다. 2026년 시행 법령 기준. **비조정대상지역** 소재로 양도세 중과가 적용되지 않는 경우이며, 취득세는 지방세법 영역이라 제외했습니다. 실제 사안은 전문가 확인이 필요합니다.

**상황** — 사례 17-1과 같은 조건(시가 10억, 취득가 5억, 채무 4억, 보유 15년, 성년 자녀)에서 아버지의 양도세까지 끝까지 계산해 단순증여와 **총액**을 견준다.

| 구분 | 단계 | 계산 | 금액 |
|---|---|---|---|
| **부담부증여** | 증여세 납부 | 사례 17-1과 동일 | 1억 185만원 |
| | 양도차익 | 4억 − 2억(안분) | 2억 |
| | 장기보유특별공제 | 2억 × 30% (15년) | 6,000만 |
| | 양도소득 과세표준 | 1.4억 − 기본공제 250만 | 1억 3,750만 |
| | 양도소득세 | 1억 3,750만×35% − 1,544만 | 3,268만 5,000원 |
| | 지방소득세 | 양도소득세의 10% | 326만 8,500원 |
| | **총부담** | 증여세+양도세+지방소득세 | **1억 3,780만 3,500원** |
| **단순증여** | 과세표준 | 10억 − 5,000만 | 9.5억 |
| | 산출세액 | 9.5억×30% − 6,000만 | 2억 2,500만 |
| | **총부담** | 신고세액공제 3% 차감 | **2억 1,825만원** |
| **차액** | | 2억 1,825만 − 1억 3,780만 3,500 | **8,044만 6,500원 절감** |

**결론** — 취득가액이 시가의 절반이고 15년을 보유해 장기보유특별공제 30%가 온전히 붙는, **부담부증여에 가장 유리한 전형**이다. 그런데도 절세액은 증여세 감소분(2억 2,500만 − 1억 500만 = 1억 2,000만)이 아니라 **8,045만원** — 새로 발생한 양도세·지방소득세 3,595만원이 절감분의 절반 가까이를 상쇄한 결과다. "증여세가 얼마나 줄었나"가 아니라 **"총액이 얼마나 줄었나"**로 물어야 하는 이유다.

### 사례 17-3: 유불리가 역전되는 경우 — 오히려 5,475만원 더 낸다
> 가상의 사례입니다. 2026년 시행 법령 기준. 비조정대상지역 소재 전제이며, 실제 사안은 전문가 확인이 필요합니다.

**상황** — 아버지가 **2년 6개월 전 1.5억에 취득**한 주택(현재 시가 10억)에 채무 7억의 인수를 조건으로 성년 자녀에게 증여한다. 취득가액이 시가의 15%에 불과하고 보유 3년 미만이라 **장기보유특별공제가 0%**다. 사례 17-2와 시가·수증자는 같고 **취득가액과 보유기간만 다르다.**

| 구분 | 단계 | 계산 | 금액 |
|---|---|---|---|
| **부담부증여** | 증여세 과세가액 | 10억 − 채무 7억 | 3억 |
| | 증여세 납부 | (3억−5,000만)×20%−1,000만, 3% 공제 | 3,880만원 |
| | 취득가액 안분 | 1.5억 × (7/10) | 1억 500만 |
| | 양도차익 | 7억 − 1억 500만 | 5억 9,500만 |
| | 양도소득 과세표준 | 장특공제 0 − 기본공제 250만 | 5억 9,250만 |
| | 양도세+지방소득세 | (5억 9,250만×42% − 3,594만) × 1.1 | 2억 3,420만 1,000원 |
| | **총부담** | | **2억 7,300만 1,000원** |
| **단순증여** | **총부담** | 사례 17-2와 동일 | **2억 1,825만원** |
| **역전폭** | | 2억 7,300만 1,000 − 2억 1,825만 | **5,475만 1,000원 추가 부담** |

**결론** — 같은 10억 주택임에도 **부담부증여의 총부담이 5,475만원 더 크다.** 취득세를 넣어도 결론은 유지된다 — 비조정지역 무상취득세율 3.5% 기준으로 단순증여의 취득세는 3,500만원, 부담부증여의 증여분(3억)에 붙는 취득세만 해도 1,050만원이므로 **취득세 차이는 아무리 커야 2,450만원**이고, 이는 역전폭 5,475만원을 상쇄하지 못한다. **취득가액이 낮고 보유기간이 짧으면 부담부증여는 절세가 아니라 손해다** — 인수시키는 채무가 클수록 증여세는 더 줄지만 그만큼 양도가액이 커져 양도세가 더 빠르게 증가하기 때문이다.

## 17.5 자주 묻는 질문

**Q1. 전세보증금이 낀 아파트를 증여해도 부담부증여인가요?**
해당됩니다. 전세보증금·임대보증금도 **그 재산에 담보된 채무**로 보아 차감됩니다(§47①). 다만 수증자가 **임대인 지위를 실제로 승계**해야 하므로 임대차계약의 임대인 명의를 바꾸고 보증금 반환 의무를 넘겨받는 절차를 마쳐야 합니다. 확정일자 있는 임대차계약서는 가족 간 미인수 추정(§47③)을 번복하는 대표적 입증 수단이기도 하여, 은행 대출이 없는 집에서 가장 흔히 활용되는 방법입니다.

**Q2. 자녀가 인수한 대출을 부모가 대신 갚아주면 어떻게 되나요?**
그 상환액이 **새로운 증여**로 과세됩니다. 증여 당시에는 채무만큼 증여세를 덜 냈는데 그 채무를 부모가 갚았다면 결국 그 금액도 무상으로 이전한 것과 같기 때문입니다. 국세청 부채 사후관리에서 드러나며 본세에 가산세까지 붙습니다. 원금뿐 아니라 **이자 대납**도 같은 문제를 일으킵니다.

**Q3. 국세청에서 부채 관련 해명자료 제출 안내를 받았습니다.**
인수한 채무가 줄었거나 상환된 사실이 포착됐다는 뜻입니다. 요구되는 것은 **상환 자금의 출처**이므로 자녀 본인의 근로·사업소득 증빙, 금융기관 거래내역, 별도로 증여받아 신고한 이력 등으로 소명합니다. 소명하지 못하면 그 상환액이 증여로 과세됩니다 (→ 제18장 자금출처).

**Q4. 부모의 신용대출을 자녀가 갚기로 하면 채무로 빼주나요?**
빼주지 않습니다. 차감되는 것은 **그 증여재산에 담보된 채무**뿐입니다. 재산과 무관한 신용대출·사업자금 대출은 약정서를 아무리 잘 써도 증여재산가액에서 차감되지 않습니다 (17.2의 3요건 중 ②).

**Q5. 소득이 없는 자녀에게도 부담부증여를 할 수 있나요?**
형식상으로는 가능하지만 실질에서 인정받기 어렵습니다. 소득이 없으면 가족 간 미인수 추정(§47③)을 번복하기 어렵고, 설령 인정받더라도 사후관리에서 **누가 갚았는지**를 소명하지 못해 결국 증여로 과세되기 쉽습니다. 상환 능력은 부담부증여의 선택 사항이 아니라 **전제 조건**입니다.

**Q6. 증여세와 양도세는 누가 언제 신고하나요?**
주체도 기한도 다릅니다. **증여세는 수증자(자녀)가 증여일이 속하는 달의 말일부터 3개월** 이내에, **양도세는 증여자(부모)가 양도일이 속하는 달의 말일부터 2개월** 이내에 예정신고·납부합니다. 한 번의 거래에 신고가 둘이므로 **한쪽 신고를 누락하는 실수**가 잦습니다 (→ 제23장).
