# 제19장 · 창업자금·가업승계 증여세 과세특례 (실무자 심화)

> **이 장에서 다루는 것** — 생전 승계를 위한 두 개의 특별 통로다. (1) 창업자금 특례 — 5억 공제 후 10% 단일세율, (2) 가업승계 주식 특례 — 10억 공제 후 10~20%, (3) 두 특례의 공통 운명 — **기간 제한 없이 상속 시 정산**된다는 구조. 근거 법률이 상증세법이 아니라 **조세특례제한법**이라는 점부터 특별하다. **2026년 시행 기준이다.**

---

## 19.1 쉽게 이해하기 — 미리 주되, 정산은 상속 때

일반 증여는 10~50% 누진세율을 문다. 그러나 "부모의 재산이 자녀의 **생산적 활동**(창업·가업 승계)으로 이어지는 증여"에는 나라가 두 개의 특별 통로를 열어 두었다 — 낮은 단일세율로 미리 넘기게 하고, **최종 정산은 상속 때** 한다.

이 "정산" 구조가 특례의 본질이다. 일반 증여는 10년이 지나면 상속재산에 합산되지 않지만(→ 제6장), **특례 증여는 기간 제한 없이 — 30년 전 것이라도 — 상속세 과세가액에 다시 합산**된다(기납부 특례 세액은 공제). 즉 특례는 세금의 면제가 아니라 **저율 선납 + 사후 정산**이며, 그 대가로 자금의 조기 이전과 누진 완화 효과를 얻는 거래다.

## 19.2 법령 근거 — 창업자금 특례 (조특법 §30의5)

| 항목 | 내용 |
|---|---|
| 당사자 | **60세 이상 부모** → 18세 이상 자녀 |
| 대상 | 중소기업 창업 목적 자금 (**양도소득세 과세대상 재산은 제외** — 현금·예금 중심) |
| 세율 | **5억 공제 후 10% 단일세율** |
| 한도 | **50억** (신규 고용 10명 이상 시 **100억**) |
| 사후 요건 | **2년 내 창업 + 4년 내 전액 사용**, 10년 내 목적 외 사용·휴폐업 시 일반 증여세 + 이자상당액 추징 |

⚠️ **주의 (옛 수치)** — "한도 30억(고용 시 50억)"은 **2022년 이전 옛 수치**다. 현행은 50억/100억. 그리고 대상에서 부동산·주식 등 양도세 과세대상 재산이 제외되므로 "건물을 창업자금으로" 같은 설계는 애초에 성립하지 않는다.

## 19.3 법령 근거 — 가업승계 주식 특례 (조특법 §30의6)

| 항목 | 내용 |
|---|---|
| 당사자 | 60세 이상 부모(10년 이상 가업 경영) → 18세 이상 자녀 |
| 대상 | 가업 법인의 주식 |
| 세율 | **10억 공제, 과세표준 120억 이하 10% / 초과분 20%** |
| 한도 | 가업 영위기간 10년↑ **300억** / 20년↑ 400억 / 30년↑ **600억** [검증필요: 한도 상향 개정안 보도 존재 — 현행 300/400/600 유지가 복수 출처] |
| 사후 요건 | 증여일부터 **3년 내 대표이사 취임**(구법 5년 — 옛 수치 주의) + **5년 사후관리**(구법 7년): 대표직·지분·가업 유지. 위반 시 추징+이자상당액 |
| 상속 연결 | 상속개시 시 요건을 충족하면 **가업상속공제(→ 제11장)로 갈아탈 수 있다** — 증여 특례와 상속 공제의 연결 통로 |

> **💡 실무 팁** — 가업 승계의 시간표 설계: 부모 생전에 §30의6으로 주식을 **저율(10%)로 미리** 넘겨 자녀의 경영권을 조기 안정시키고, 상속 시점에는 정산 과정에서 **가업상속공제 요건**을 충족시켜 최종 세부담을 다시 낮추는 2단 구조가 정석이다. 다만 두 제도의 사후관리(증여 5년 + 상속 5년)가 이어지므로, 10년 가까운 관리 캘린더를 각오해야 한다.

## 19.4 사례 — 특례와 일반 증여의 거리

> 가상의 사례입니다. 2026년 시행 기준. 개략 비교이며 실제는 요건 검토가 선행되어야 합니다.

**상황** — 62세 창업주가 가업 주식 50억원어치를 장남에게 증여하려 한다.

| | 일반 증여 | §30의6 특례 |
|---|---|---|
| 공제 | 5,000만 | **10억** |
| 세율 | 누진 (50억대 → 한계 50%) | **10%** (과표 120억 이하) |
| 개략 세액 | 49.5억 과표 → 산출 약 **20.15억** (49.5×50%−4.6) | 40억 과표 → **4억** |
| 상속 시 | 10년 경과 시 합산 안 됨 | **기간 불문 합산 정산** (기납부 4억 공제, 가업상속공제 연결 가능) |

**결론** — 증여 시점 세부담은 5배 차이다. 그 대가는 사후관리 의무와 상속 시 정산이다. 부모가 장수하여 가업이 성장할수록(정산 시점의 가업상속공제 활용 여지가 클수록) 특례의 실익이 커진다 — **특례는 세금 계산이 아니라 승계 시간표의 문제**다.

## 19.5 이 장의 핵심 체크리스트

- [ ] 근거가 상증세법이 아닌 **조특법**임을 확인했는가? (§30의5·§30의6)
- [ ] 창업자금 — 현금성 자산인가? (양도세 과세대상 재산 제외) 한도 50억/100억 **현행 수치**인가?
- [ ] 창업 2년·전액 사용 4년·유지 10년의 시간표를 캘린더에 박았는가?
- [ ] 가업승계 — 대표 취임 3년·사후관리 5년(현행)을 구법 수치(5년·7년)와 혼동하지 않았는가?
- [ ] **상속 시 기간 불문 정산**을 가족 전체의 상속 계획에 반영했는가? (→ 제11·28장)
