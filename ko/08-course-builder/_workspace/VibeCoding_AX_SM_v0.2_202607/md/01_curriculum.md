# 과정 설계서 — VibeCoding_AX_SM (v0.2 교수설계 정교화)

> SSOT: `00_input.md` (VibeCoding_AX_SM 상세커리큘럼 v0.2 + 탭형 강의계획서)
> 본 설계서는 v0.2의 강 구조·타임라인·산출물을 **그대로 유지**하되, 블룸 분류학·역방향 설계(UbD)·가네 9단계·인지부하 이론을 적용해 교수설계 관점에서 정교화한 것이다.

## 과정 개요

- **과정명**: VibeCoding_AX (바이브코딩 기반 업무 자동화 실전) — "코딩하지 않고 자연어로 지시하며, 검증은 사람이 한다"
- **대상 학습자**: **전원 초보자(사내 정규직 전 직군 — 회계·세무·법무·미디어·MICE)**. 코딩 무경험 전제. 컴퓨터·웹 도구 숙련도 편차 큼.
- **총 학습 시간**: **본과정 8시간(2h×4강)** + **0강 사전 온보딩 60~90분** + **30일 팔로업 클리닉 90분**
- **편성 권장**: 2일 × 2강(1·2강 / 3·4강). 초보자에게 하루 4시간 연속은 인지부하가 크므로 분산 편성.
- **과정 목표** (수료 시 학습자가 할 수 있는 것):
  1. 자연어 지시(바이브코딩)로 실동작하는 웹 산출물을 **배포**할 수 있다. (창조)
  2. 자동화 생태계 7개념(스킬·에이전트·에이전트팀·MCP·커넥터·플러그인·프로젝트·하네스)을 구분하고 목적에 맞게 **선택**할 수 있다. (분석·평가)
  3. 4역할(수집·분석·검증·요약) 에이전트팀을 **하네스로 구축**하고 재실행할 수 있다. (창조)
  4. 본인 업무 시나리오로 위 하네스를 **미러링(복제·개조)**할 수 있다. (창조·전이)
  5. 산출물을 수료 루브릭 3기준(실데이터 동작·결과 지향·재현성)과 안전수칙으로 **자기 검증**할 수 있다. (평가)

### 역방향 설계(UbD) 앵커
- **Step 1 (원하는 결과)**: 본인 업무를 자동화하는 **에이전트팀 + 재생산 하네스**를 스스로 구축.
- **Step 2 (평가 증거)**: 배포된 데모 URL + 재실행 가능한 하네스 산출 영상/기록 → 루브릭 3기준 통과.
- **Step 3 (학습 경험)**: 1강(배포)→2강(환경·콘텐츠)→3강(부품)→4강(오케스트레이션)의 **누적 부품 조립** 경로.

## 선수학습 요건 (0강에서 전부 충족)

- **코딩 지식 불필요** — 자연어 지시와 결과 검증 능력만 요구.
- **계정 5종**: Claude Pro(유료, 해외결제 카드 필요) · GitHub · Vercel · Supabase · 타 LLM 택1(ChatGPT/Gemini/Grok).
- **설치 6종**: Node.js · Git · VS Code · Claude Code(CLI) · Claude 데스크톱(커넥터) · Antigravity(선택).
- **사전과제**: 본인 업무 2~3개를 **입력→처리→출력** 형태로 적어오기(4강 미러링 소재).
- 위 전부 0강에서 완료. **1~4강은 0강 완료를 절대 선수조건으로 함** — 미완료자는 조교가 강 시작 전 개별 보정.

## 누적 부품 이월 지도 (Backward Assembly)

각 강의 산출물이 다음 강의 부품이 되도록 설계한다. 4강에서 전부 집결.

```
0강: 도구 10종 + 사전과제(본인 업무 I/P/O)   ──┐
                                                │ (미러링 소재)
1강: 배포된 랜딩페이지 URL (프론트+Supabase)   ──┤→ 4강 하네스의 "출력/배포 채널"
2강: 코딩환경 3종 + 콘텐츠 엔진(블로그·유튜브) ──┤→ 4강 요약 에이전트의 "산출 포맷"
3강: 스킬 2~3개 + MCP 연결 1개 + 프로젝트     ──┤→ 4강 4역할 에이전트의 "부품 재료"
                                                │
4강: 4역할 에이전트팀 → 하네스 1개  ←───────────┘ (집결·오케스트레이션)
     └→ 각자 본인 업무로 미러링(전이)
```

**학습 경로 유형**: 선형(Linear) — 각 강이 다음 강의 선행 조건인 누적적 기술. (learning-design 선형 경로 패턴)

각 강 타임라인은 실제 진행 분(0강 60~90분 / 1~4강 120분)에 맞춰 블록 분할했다. 유형 표기: **강의**(개념 전달) / **시연**(강사 완성본 시범, 원칙⓶) / **실습**(학습자 따라하기·조별) / **발표**(공유·피드백).

### 0강: 사전 온보딩 (비대면 60~90분) — "출발선 정렬"

**모듈 목표**
- (이해) LLM 기반 업무 자동화가 "코딩이 아니라 지시와 검증"임을 **설명할 수 있다**.
- (적용) 도구 10종을 설치·로그인하고 체크리스트를 **완료할 수 있다**.
- (적용) 본인 업무 2~3개를 입력→처리→출력 형식으로 **기술할 수 있다**.

| 블록 | 제목 | 유형 | 시간 | 학습목표 (블룸) | 선수 |
|------|------|------|------|----------------|------|
| 0-1 | 과정 오리엔테이션 · 바이브코딩 개념 | 강의 | 15분 | 이해 — 바이브코딩 3대 원칙과 8시간 여정을 설명한다 | 없음 |
| 0-2 | 계정 5종 개설 + 결제 (가이드 시연) | 시연→실습 | 25분 | 적용 — Claude Pro·GitHub·Vercel·Supabase·타LLM 계정을 개설·로그인한다 | 0-1 |
| 0-3 | 설치 6종 (Node·Git·VS Code·Claude Code·데스크톱·[Antigravity]) | 시연→실습 | 20분 | 적용 — CLI에서 `claude` 실행 성공까지 환경을 구성한다 | 0-2 |
| 0-4 | 진단 미니체크 + 사전과제 안내 | 실습 | 15분 | 적용 — 본인 업무 2~3개를 I/P/O로 적고 제출한다 | 0-3 |

**모듈 평가**: 10종 도구 체크리스트 100% 완료(스크린샷/CLI 실행 확인) + 사전과제 제출.
**산출물**: ✅ 10종 체크리스트 · 📄 본인 업무 I/P/O 시트(→4강 미러링 소재).
**안전수칙**: Claude Pro 해외결제 카드 필요 · **service_role 등 비밀키는 어디에도 올리지 않는다**(스크린샷 포함).
**조교 개입 포인트**: 설치 실패는 개별 원격 지원. 강 시작 전 미완료자 0명 목표.

### 2강: 작업환경 & 콘텐츠 엔진 (대면 2h) — "일하는 3계층과 결과물"

**모듈 목표**
- (이해) Claude 3계층(chat/cowork/code)의 차이와 코딩환경 3종의 용도를 **구분할 수 있다**.
- (적용) 코딩환경을 열어 콘텐츠 생성 파이프라인을 **실행할 수 있다**.
- (창조) 블로그 글 1편 + 유튜브 세트를 생성·게시하고 **사실 근거를 사람이 검증할 수 있다**.

| 블록 | 제목 | 유형 | 시간 | 학습목표 (블룸) | 선수 |
|------|------|------|------|----------------|------|
| 2-1 | 도입: 완성된 블로그·유튜브 세트 데모 | 시연 | 10분 | — 주의 획득: 결과물 먼저 보여주기 | 1강 |
| 2-2 | Claude 3계층 (chat / cowork / code) 지형 | 강의 | 20분 | 이해 — 3계층을 업무 상황에 매핑해 설명한다 | 2-1 |
| 2-3 | 코딩환경 3종 (Claude Code · 데스크톱 · [Antigravity]) | 강의→시연 | 20분 | 이해 — 3종 환경의 역할과 진입 방법을 구분한다 | 2-2 |
| 2-4 | 콘텐츠 엔진 시연: 블로그 초안 생성 | 시연 | 15분 | 이해 — 프롬프트→초안→사람 검증 루프를 관찰한다 | 2-3 |
| 2-5 | 블로그 글 1편 작성·게시 (조별) | 실습 | 30분 | 창조 — 자기 직군 소재로 블로그 1편을 완성·게시한다 | 2-4 |
| 2-6 | 유튜브 콘텐츠 세트 제작 (조별) | 실습 | 15분 | 적용 — 제목·설명·썸네일 문구 세트를 생성한다 | 2-5 |

**모듈 평가**: 형성평가 퀴즈(3계층 구분 + "AI는 문장, 근거는 사람" 원칙) · 산출물 = 게시된 블로그 글 URL.
