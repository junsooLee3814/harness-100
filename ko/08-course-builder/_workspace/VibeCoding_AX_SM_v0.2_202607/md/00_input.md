# 강의 입력 정보 — VibeCoding_AX_SM (v0.2)

> 출처: 확정본 `html/01_curriculum_tab.html`(탭형 상세 강의계획서) + `html/00_input.html`
> 이 문서는 course-builder 파이프라인의 SSOT(단일 진실 원천)이다. 하위 산출물은 이 v0.2 확정 구조를 따른다.

## 과정 주제
VibeCoding_AX (바이브코딩 기반 업무 자동화 실전) — "코딩하지 않고 자연어로 지시하며, 검증은 사람이 한다"

## 과정 설명
전원 초보자(사내 정규직)를 대상으로, 8시간(2h×4강) + 0강 프로그램 설치 안내 + 30일 팔로우업 구조로 설계한다.
목표는 수료 시 **본인 업무를 자동화하는 에이전트팀 + 이를 재생산하는 하네스**를 스스로 구축하는 것. 전 강 공통 프로젝트(글로벌 증시·뉴스 인사이트)를 실습선으로 일관 도입한다.

## 대상 학습자
- **전원 초보자 (전체 정규직)**: 회계·세무·법무·미디어·MICE 등 전 직군. 코딩 무경험 전제.
- 컴퓨터·웹 도구 숙련도 편차 큼 → 3인 1조 + 강사 1 + 조교 1~2 배치로 실습 중 즉시 개입.

## 과정 규모
- **본과정 총 8시간 = 2시간 × 4강**
- **0강 프로그램 설치 안내**: 본과정 2~3일 전, 비대면 60~90분, **강의 없음** (두 안내서 전달·설명 + 계정·설치·결제 각자 완료 + 사전과제 + 진단)
- **30일 팔로우업**: 수료 30일 후, 대면/온라인 90분 (실사용 회고·오류 수정·공유 확산·스킬 공유 저장소)
- 권장 편성: 8시간 = 2일 × 2강 (1·2강 / 3·4강). 초보자에게 하루 4시간 연속은 인지부하 큼.

## 3대 설계 원칙 (전 강 관통)
1. **⓵ 백지 시작 금지** — 모든 실습은 강사가 준비한 템플릿·스켈레톤·스니펫에서 출발. 채우고·고치고·검증하는 데 시간을 쓴다.
2. **⓶ 데모 먼저, 따라하기 나중** — 매 실습은 강사 시연(완성본 먼저 보여주기) → 학습자 따라하기.
3. **⓷ 강사 + 조교 배석** — 3인 1조 + 강사 1 + 조교 1~2로 실습 중 즉시 개입. 한 명이 막히면 조 전체가 멈춘다.

## 공통 프로젝트 — 글로벌 증시·뉴스 인사이트 에이전트팀
4강에서 Claude Code CLI·에신Lite로 함께 만들고, 각자 본인 업무로 복제한다. 4역할 구성:
| 역할 | 하는 일 | 연동 부품 |
|------|---------|----------|
| 수집 에이전트 | 글로벌 주제 지수·주요 기업 뉴스 수집 | 웹검색 MCP/커넥터 |
| 분석 에이전트 | 뉴스 전조·패턴·숨은 인사이트 도출 | 3개 분석 스킬 |
| 검증 에이전트 | 사실·숫자·출처 교차검증 (VibeCoding 검증 원칙) | 검증 스킬 |
| 요약 에이전트 | 의사결정용 브리핑·카드 생성 | 요약 스킬 |

## 수료 루브릭 (3기준, AX 2차 계승)
| 기준 | 확인 질문 | 판정 |
|------|----------|------|
| ⓵ 실데이터 동작 | 실제 본인/공통 업무 데이터로 동작하는가 | 통과/보완 |
| ⓶ 결과 지향 | "응답이 있다"가 아니라 "결과가 만들어진다"인가 | 통과/보완 |
| ⓷ 재현성 | 같은 입력 2회 실행 시 동일 품질인가 | 통과/보완 |
- 3기준 모두 통과 시 수료. 보완 시 30일 팔로우업에서 마무리. 수료 증명 = 배포된 데모 URL + 동작하는 하네스 산출 영상/기록.

## 각 강 안전·성실 수칙 (필수 반영)
- 0강: **service_role 등 비밀키는 어디에도 올리지 않는다.**
- 1강: anon 공개키만 페이지에 · service_role 키 금지 · 개인정보는 폼 예시에 넣지 않기.
- 2강: AI는 문장, 사실 근거는 사람이 준다 · 허위 숫자·법조항 금지 · 고객정보 프롬프트 금지.
- 3강: 고객정보 프롬프트 금지 · MCP가 데이터를 어디로 보내는지 확인 · 키를 코드에 하드코딩 금지.
- 4강: 검증 단계 생략 금지 · 출처 없는 주장 배제 · 고객 식별정보/기밀 입력 금지 · 최종 확인은 사람.

## 강의 구성 요청 (산출물 범위)
- 커리큘럼 (강별 학습목표·진도표·타임라인 60~90/120분 단위)
- 교안/강의노트 (강사 시연 스크립트 + 학습자 따라하기 + 배포자료 템플릿/스켈레톤/스니펫 안내)
- 퀴즈/형성·총괄평가 (초보자 눈높이, 개념 이해 + 안전수칙 확인)
- 실습과제/캡스톤 (0강 사전과제 → 강별 실습 → 4강 하네스 캡스톤)
- 리뷰 보고서 (학습목표 커버리지·난이도 정합성·설계원칙 준수 검증)

## 실행 모드
풀 파이프라인 (커리큘럼 설계 → 교안·퀴즈·실습 병렬 → 과정 검증), 5명 전원 투입.
