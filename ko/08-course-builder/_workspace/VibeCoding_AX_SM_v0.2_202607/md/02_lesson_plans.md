## 이 교안을 읽는 법 (강사용)

- 모든 실습 블록은 **3단 구조**로 고정한다 → ① **강사 시연**(완성본 먼저: 대사 + 화면 흐름) → ② **학습자 따라하기**(스켈레톤/스니펫에서 출발, 절대 백지 아님) → ③ **배포자료 안내**(그 블록에서 나눠줄 템플릿·스켈레톤·스니펫).
- **0강은 예외**: 강의·실습이 아니라 **두 안내서를 전달·설명**하고 학습자가 **각자 완료**하는 세션이다. '강의' 유형 블록을 넣지 않는다. 교안도 강의체가 아니라 **안내서 전달·설명 대본**으로 쓴다.
- **3대 설계원칙**은 각 블록 상단에 아이콘으로 표기: **⓵ 백지금지** · **⓶ 데모먼저** · **⓷ 강사+조교**.
- **🛡 안전수칙 삽입 지점**은 본문에 인라인으로 박아 두었다. 강사는 이 지점에서 반드시 말로 짚고 넘어간다(건너뛰기 금지).
- **가네 9단계** 태그를 블록별로 표기: [가네1 주의] [가네3 선행상기] [가네4 자극] [가네6 수행유도] [가네9 전이] 등.
- 타임라인은 **[표준]** + **[압축]** 두 버전을 각 강 끝에 제공한다(0강 90/60분, 1~4강 120/100분).

## 배포자료 패키지 개요 (강사 사전 준비물)

강사·조교는 강 시작 전 아래 폴더를 학습자에게 배포(또는 공유드라이브/USB)한다. **내용은 채워 넣기·고치기용 빈칸/스켈레톤 상태**로 배포한다(완성본은 강사 시연용으로만 별도 보관).

| 강 | 배포 폴더 | 핵심 내용물 |
|----|-----------|------------|
| 0강 | `00강_온보딩킷/` (킷) | 두 안내서(`프로그램 설치 안내서.html`·`사전과제 작성 안내서.html`), 계정 5종+설치 6종 체크리스트, I/P/O 워크시트(예시행 1개 채워짐), 진단 미니체크 |
| 1강 | `01강_템플릿_fullstack-landing/` | 풀스택 랜딩페이지 스켈레톤(프론트 섹션 주석 + Supabase 연결 자리), 배포·게시 절차 카드(빈칸), 프롬프트 스니펫 3장 |
| 2강 | `02강_템플릿_content-engine/` | 블로그 프롬프트 템플릿(빈칸), 유튜브 세트 프롬프트, 사실검증 체크리스트 |
| 3강 | `03강_템플릿_회의록-에이전트/` | SKILL.md 스켈레톤(생성·문서화), 메일 발송 MCP 설정 스니펫(`.mcp.json`), 8개념 지형도 카드 |

## 용어집

전문용어는 **첫 등장 강**에서 1줄 정의 + 업무 비유로 소개한다. 강사는 이 표를 슬라이드 하단 각주로도 노출한다.

| 용어 | 1줄 정의 | 업무 비유 | 첫 등장 |
|------|---------|----------|--------|
| 바이브코딩 | 자연어로 지시해 결과물을 만들고, 검증은 사람이 하는 방식 | "받아쓰게 하고, 결재는 내가" | 0강 |
| I/P/O | 입력(Input)→처리(Process)→출력(Output)으로 업무를 3토막 내는 사고틀 | 서류 접수→검토→발송 | 0강 |
| 비밀키(service_role 등) | 외부에 노출되면 안 되는 관리자 마스터키 | 금고 마스터키 | 0강 |
| LLM | 자연어를 이해·생성하는 대규모 언어모델(Claude·GPT·Gemini·Grok 등) | 말귀 알아듣는 만능 신입 | 1강 |
| 스켈레톤 | 뼈대만 있고 빈칸이 뚫린 시작 파일 | 결재양식 빈 서식 | 1강 |
| 배포(Deploy)·게시(Publish) | 만든 결과물을 인터넷에 올려 URL로 접속 가능하게 공개하는 것 | 문서를 사내 게시판에 게시 | 1강 |
| 풀스택 | 화면(프론트)과 데이터 저장(백엔드=Supabase)을 함께 갖춘 웹 | 접수창구+보관창고 한 세트 | 1강 |
| Supabase | 폼 입력을 저장하는 클라우드 데이터베이스 | 온라인 캐비닛 | 1강 |

| Claude 3계층 | chat(대화)·cowork(문서·작업 협업)·code(개발환경) 세 가지 사용 층 | 메신저 / 협업문서 / 작업실 | 2강 |
| 코딩환경 3종 | Claude Code(CLI)·Claude 데스크톱·Antigravity(선택) | 작업실 / 사무실 앱 / 보조도구 | 2강 |
| 스킬 | 특정 작업을 하도록 미리 짜둔 재사용 지시서 | 업무 매뉴얼 1건 | 3강 |

| MCP | LLM이 외부 데이터·도구(메일·검색 등)에 접속하는 표준 연결구 | 만능 신입에게 쥐여주는 외부 전화기 | 3강 |
| 커넥터 | MCP 규격으로 특정 앱(메일·캘린더)을 꽂는 연결 | 규격 맞는 플러그 | 3강 |

## 전 강 관통 예시 — 공통 프로젝트

**글로벌 증시·뉴스 인사이트 에이전트팀**을 0강부터 4강까지 "우리가 함께 만드는 배(실습선)"로 일관 등장시킨다. 강마다 이 프로젝트의 한 부품이 완성돼 4강에서 집결한다.

| 강 | 공통 프로젝트에서 만드는 부품 | 직군별 미러링(4강에서 각자 복제) |
|----|------------------------------|-------------------------------|
| 1강 | 인사이트를 보여줄 **풀스택 랜딩페이지(출력/배포·게시 채널)** | 회계=상담접수 폼 / 법무=상담예약 / MICE=행사 사전등록 |
| 2강 | 브리핑을 담을 **콘텐츠 포맷(블로그·유튜브)** | 미디어=기사 초안 / 투자=시황 코멘트 |
| 3강 | **동작하는 회의록 에이전트**(스킬 2~3 + 메일 MCP) — 부품·조립 노하우 | 회계=마감 체크 스킬 / 법무=판례 요약 스킬 |
| 4강 | 4역할 **에이전트팀 하네스**(Claude Code CLI·에신Lite) | 각자 0강 I/P/O 시나리오로 미러링 |

강사는 매 강 도입 데모에서 "지난 강에 만든 부품이 이 프로젝트의 어디에 꽂히는지"를 한 장의 조립도로 상기시킨다(가네3 선행학습 자극).

**모듈 학습목표** (커리큘럼 인용)
- (이해) LLM 기반 업무 자동화가 "코딩이 아니라 지시와 검증"임을 두 안내서를 통해 파악할 수 있다.

**이 강의 성격**: **강의하지 않는다.** 강사는 두 안내서(`프로그램 설치 안내서.html`, `사전과제(입력·처리·출력) 작성 안내서.html`)를 **전달·설명**하고 확인 포인트를 짚어주며, 학습자는 각자 계정·설치·결제·사전과제를 **스스로 완료**한다. 진단 미니체크로 출발선을 맞춘다.

**준비물(학습자)**: 노트북, 안정적 인터넷, 조용한 공간. *(결제 수단은 각자 안내서 안내대로 준비 — 특정 결제수단 강요 문구는 두지 않는다)*
**준비물(강사·조교)**: `00강_온보딩킷/`(두 안내서 포함), 화면공유 회의룸, 조교별 원격지원 대기, 조교 백업 계정.

### ① 강사 시연 스크립트 (완성본 먼저 · 8분)
- 화면 흐름: 강사가 **이미 로그인된 5개 탭**(Claude Pro·GitHub·Vercel·Supabase·타LLM)과 터미널에서 `claude` 실행 성공 화면을 순서대로 보여준다 → "이게 오늘 끝에 여러분 화면입니다."(⓶)
