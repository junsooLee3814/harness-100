## 이 교안을 읽는 법 (강사용)

- 모든 실습 블록은 **3단 구조**로 고정한다 → ① **강사 시연**(완성본 먼저: 대사 + 화면 흐름) → ② **학습자 따라하기**(스켈레톤/스니펫에서 출발, 절대 백지 아님) → ③ **배포자료 안내**(그 블록에서 나눠줄 템플릿·스켈레톤·스니펫).
- **3대 설계원칙**은 각 블록 상단에 아이콘으로 표기: **⓵ 백지금지** · **⓶ 데모먼저** · **⓷ 강사+조교**.
- **🛡 안전수칙 삽입 지점**은 본문에 인라인으로 박아 두었다. 강사는 이 지점에서 반드시 말로 짚고 넘어간다(건너뛰기 금지).
- **가네 9단계** 태그를 블록별로 표기: [가네1 주의] [가네3 선행상기] [가네4 자극] [가네6 수행유도] [가네9 전이] 등.
- 타임라인은 **[120분 표준]** + **[100분 압축]** 두 버전을 각 강 끝에 제공한다.

강사·조교는 강 시작 전 아래 폴더를 학습자에게 배포(또는 공유드라이브/USB)한다. **내용은 채워 넣기·고치기용 빈칸/스켈레톤 상태**로 배포한다(완성본은 강사 시연용으로만 별도 보관).

| 강 | 배포 폴더 | 핵심 내용물 |
|----|-----------|------------|
| 0강 | `00강_온보딩킷/` (킷) | 도구 10종 설치 체크리스트, I/P/O 워크시트(예시행 1개 채워짐), 진단 미니체크 |
| 1강 | `01강_템플릿_landing-page/` | 랜딩페이지 HTML 스켈레톤(섹션 주석 뚫림), 배포 절차 카드(빈칸), 프롬프트 스니펫 3장 |
| 2강 | `02강_템플릿_content-engine/` | 블로그 프롬프트 템플릿(빈칸), 유튜브 세트 프롬프트, 사실검증 체크리스트 |
| 3강 | `03강_템플릿_skill-mcp/` | SKILL.md 스켈레톤, MCP 설정 스니펫(`.mcp.json`), 7개념 지형도 카드 |

> **완성본(참조본)은 조교가 미리 배포/실행해 두고, 시연 때만 화면에 띄운다.** 학습자에게 완성본 소스를 처음부터 주면 "따라 치기"만 하고 사고가 멈춘다 — 스켈레톤 배포 원칙(⓵)의 핵심 이유.

## 용어집

전문용어는 **첫 등장 강**에서 1줄 정의 + 업무 비유로 소개한다. 강사는 이 표를 슬라이드 하단 각주로도 노출한다.

| 용어 | 1줄 정의 | 업무 비유 | 첫 등장 |
|------|---------|----------|--------|
| 바이브코딩 | 자연어로 지시해 결과물을 만들고, 검증은 사람이 하는 방식 | "받아쓰게 하고, 결재는 내가" | 0강 |
| I/P/O | 입력(Input)→처리(Process)→출력(Output)으로 업무를 3토막 내는 사고틀 | 서류 접수→검토→발송 | 0강 |
| LLM | 자연어를 이해·생성하는 대규모 언어모델(Claude·GPT·Gemini·Grok 등) | 말귀 알아듣는 만능 신입 | 1강 |
| 스켈레톤 | 뼈대만 있고 빈칸이 뚫린 시작 파일 | 결재양식 빈 서식 | 1강 |
| 배포(Deploy) | 만든 페이지를 인터넷에 올려 URL로 접속 가능하게 하는 것 | 문서를 사내 게시판에 게시 | 1강 |
| anon 키 / service_role 키 | anon=공개용 열쇠(밖에 노출 OK) / service_role=관리자 마스터키(절대 노출 금지) | 로비 출입증 vs 마스터키 | 1강 |
| Claude 3계층 | chat(대화)·cowork(문서·작업 협업)·code(개발환경) 세 가지 사용 층 | 메신저 / 협업문서 / 작업실 | 2강 |
| MCP | LLM이 외부 데이터·도구에 접속하는 표준 연결구 | 만능 신입에게 쥐여주는 외부 전화기 | 3강 |
| 스킬 | 특정 작업을 하도록 미리 짜둔 재사용 지시서 | 업무 매뉴얼 1건 | 3강 |
| 에이전트 | 목표를 받아 스스로 판단·실행하는 AI 일꾼 | 담당 하나 붙인 대리 | 3강 |
| 에이전트팀 | 역할 나눈 여러 에이전트가 협업하는 구성 | 수집·분석·검증·요약 4인 TF | 4강 |
| 하네스 | 에이전트팀을 재실행 가능하게 묶은 자동화 틀 | 버튼 누르면 도는 결재라인 | 4강 |
| 미러링 | 공통 프로젝트를 본인 업무로 복제·개조하는 것 | 표준양식을 우리 팀용으로 개조 | 4강 |

## 전 강 관통 예시 — 좌착 공통 프로젝트

**글로벌 증시·뉴스 인사이트 에이전트팀**을 0강부터 4강까지 "우리가 함께 만드는 배(실습선)"로 일관 등장시킨다. 강마다 이 프로젝트의 한 부품이 완성된다.

| 강 | 공통 프로젝트에서 만드는 부품 | 직군별 미러링(4강에서 각자 복제) |
|----|------------------------------|-------------------------------|
| 1강 | 인사이트를 보여줄 **랜딩페이지(출력 채널)** | 회계=상담접수 폼 / 법무=상담예약 / MICE=행사 사전등록 |
| 2강 | 브리핑을 담을 **콘텐츠 포맷(블로그·유튜브)** | 미디어=기사 초안 / 투자=시황 코멘트 |
| 3강 | 수집·분석에 쓸 **스킬·MCP 부품** | 회계=마감 체크 스킬 / 법무=판례 요약 스킬 |
