과정 설계서 — VibeCoding_AX_SM (v0.2 교수설계 정교화)

SSOT: 00_input.md (VibeCoding_AX_SM 상세커리큘럼 v0.2 + 탭형 강의계획서) 본 설계서는 v0.2의 강 구조·타임라인·산출물을 그대로 유지하되, 블룸 분류학·역방향 설계(UbD)·가네 9단계·인지부하 이론을 적용해 교수설계 관점에서 정교화한 것이다.

01
과정 개요
  • 과정명: VibeCoding_AX (바이브코딩 기반 업무 자동화 실전) — "코딩하지 않고 자연어로 지시하며, 검증은 사람이 한다"
  • 대상 학습자: 전원 초보자(사내 정규직 전 직군 — 회계·세무·법무·미디어·MICE). 코딩 무경험 전제. 컴퓨터·웹 도구 숙련도 편차 큼.
  • 총 학습 시간: 본과정 8시간(2h×4강) + 0강 사전 온보딩 60~90분 + 30일 팔로업 클리닉 90분
  • 편성 권장: 2일 × 2강(1·2강 / 3·4강). 초보자에게 하루 4시간 연속은 인지부하가 크므로 분산 편성.
  • 과정 목표 (수료 시 학습자가 할 수 있는 것): 1. 자연어 지시(바이브코딩)로 실동작하는 웹 산출물을 배포할 수 있다. (창조) 2. 자동화 생태계 7개념(스킬·에이전트·에이전트팀·MCP·커넥터·플러그인·프로젝트·하네스)을 구분하고 목적에 맞게 선택할 수 있다. (분석·평가) 3. 4역할(수집·분석·검증·요약) 에이전트팀을 하네스로 구축하고 재실행할 수 있다. (창조) 4. 본인 업무 시나리오로 위 하네스를 미러링(복제·개조)할 수 있다. (창조·전이) 5. 산출물을 수료 루브릭 3기준(실데이터 동작·결과 지향·재현성)과 안전수칙으로 자기 검증할 수 있다. (평가)

역방향 설계(UbD) 앵커

  • Step 1 (원하는 결과): 본인 업무를 자동화하는 에이전트팀 + 재생산 하네스를 스스로 구축.
  • Step 2 (평가 증거): 배포된 데모 URL + 재실행 가능한 하네스 산출 영상/기록 → 루브릭 3기준 통과.
  • Step 3 (학습 경험): 1강(배포)→2강(환경·콘텐츠)→3강(부품)→4강(오케스트레이션)의 누적 부품 조립 경로.
02
선수학습 요건 (0강에서 전부 충족)
  • 코딩 지식 불필요 — 자연어 지시와 결과 검증 능력만 요구.
  • 계정 5종: Claude Pro(유료, 해외결제 카드 필요) · GitHub · Vercel · Supabase · 타 LLM 택1(ChatGPT/Gemini/Grok).
  • 설치 6종: Node.js · Git · VS Code · Claude Code(CLI) · Claude 데스크톱(커넥터) · Antigravity(선택).
  • 사전과제: 본인 업무 2~3개를 입력→처리→출력 형태로 적어오기(4강 미러링 소재).
  • 위 전부 0강에서 완료. 1~4강은 0강 완료를 절대 선수조건으로 함 — 미완료자는 조교가 강 시작 전 개별 보정.
03
3대 설계 원칙 (전 강 관통 — 모든 레슨 설계에 강제 적용)
원칙 내용 교수설계 근거
⓵ 백지 시작 금지 모든 실습은 강사 제공 템플릿·스켈레톤·스니펫에서 출발. 채우고·고치고·검증하는 데 시간 사용. 인지부하 이론 — 외재적 부하 제거, 유의미 부하에 집중
⓶ 데모 먼저, 따라하기 나중 매 실습은 강사 시연(완성본 먼저) → 학습자 따라하기. 가네 1·4단계(주의 획득·자극 제시) + 완성 예제(worked example) 효과
⓷ 강사+조교 배석 3인 1조 + 강사 1 + 조교 1~2. 한 명이 막히면 조 전체가 멈춘다 → 즉시 개입. 비계 설정(scaffolding), 실시간 피드백(가네 7단계)
04
누적 부품 이월 지도 (Backward Assembly)

각 강의 산출물이 다음 강의 부품이 되도록 설계한다. 4강에서 전부 집결.

0강: 도구 10종 + 사전과제(본인 업무 I/P/O)   ──┐
                                                │ (미러링 소재)
1강: 배포된 랜딩페이지 URL (프론트+Supabase)   ──┤→ 4강 하네스의 "출력/배포 채널"
2강: 코딩환경 3종 + 콘텐츠 엔진(블로그·유튜브) ──┤→ 4강 요약 에이전트의 "산출 포맷"
3강: 스킬 2~3개 + MCP 연결 1개 + 프로젝트     ──┤→ 4강 4역할 에이전트의 "부품 재료"
                                                │
4강: 4역할 에이전트팀 → 하네스 1개  ←───────────┘ (집결·오케스트레이션)
     └→ 각자 본인 업무로 미러링(전이)

학습 경로 유형: 선형(Linear) — 각 강이 다음 강의 선행 조건인 누적적 기술. (learning-design 선형 경로 패턴)

05
커리큘럼 구조

각 강 타임라인은 실제 진행 분(0강 60~90분 / 1~4강 120분)에 맞춰 블록 분할했다. 유형 표기: 강의(개념 전달) / 시연(강사 완성본 시범, 원칙⓶) / 실습(학습자 따라하기·조별) / 발표(공유·피드백).

0강: 사전 온보딩 (비대면 60~90분) — "출발선 정렬"

모듈 목표

  • (이해) LLM 기반 업무 자동화가 "코딩이 아니라 지시와 검증"임을 설명할 수 있다.
  • (적용) 도구 10종을 설치·로그인하고 체크리스트를 완료할 수 있다.
  • (적용) 본인 업무 2~3개를 입력→처리→출력 형식으로 기술할 수 있다.
