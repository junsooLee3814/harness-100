과정 설계서 — VibeCoding_AX_SM (v0.2 교수설계 정교화)

SSOT: html/01_curriculum_tab.html (탭형 상세 강의계획서 확정본) + html/00_input.html 본 설계서는 확정본의 강 제목·타임라인·산출물·안전수칙을 정답으로 삼아 반영하되, 블룸 분류학·역방향 설계(UbD)·가네 9단계·인지부하 이론을 적용해 교수설계 관점에서 정교화한 것이다.

01
과정 개요
  • 과정명: VibeCoding_AX (바이브코딩 기반 업무 자동화 실전) — "코딩하지 않고 자연어로 지시하며, 검증은 사람이 한다"
  • 대상 학습자: 전원 초보자(사내 정규직 전 직군 — 회계·세무·법무·미디어·MICE). 코딩 무경험 전제. 컴퓨터·웹 도구 숙련도 편차 큼.
  • 총 학습 시간: 본과정 8시간(2h×4강) + 0강 프로그램 설치 안내 60~90분(강의 없음) + 30일 팔로우업 90분
  • 편성 권장: 2일 × 2강(1·2강 / 3·4강). 초보자에게 하루 4시간 연속은 인지부하가 크므로 분산 편성.
  • 과정 목표 (수료 시 학습자가 할 수 있는 것): 1. 자연어 지시(바이브코딩)로 풀스택 웹 산출물(프론트+Supabase)을 배포·게시할 수 있다. (창조) 2. 자동화 개념 8종(스킬 + "스킬 외 7종" = 에이전트·에이전트팀·MCP·커넥터·플러그인·프로젝트·하네스)을 구분하고 목적에 맞게 선택할 수 있다. (분석·평가) 3. 스킬과 MCP를 묶어 동작하는 회의록 에이전트 1개를 구축할 수 있다. (창조·종합) 4. Claude Code CLI·에신Lite로 4역할(수집·분석·검증·요약) 에이전트팀을 하네스로 구축·게시하고 재실행할 수 있다. (창조) 5. 본인 업무 시나리오로 위 하네스를 미러링(복제·개조)하고, 수료 루브릭 3기준(실데이터 동작·결과 지향·재현성)으로 자기 검증할 수 있다. (전이·평가)

역방향 설계(UbD) 앵커

  • Step 1 (원하는 결과): 본인 업무를 자동화하는 에이전트팀 + 재생산 하네스를 스스로 구축.
  • Step 2 (평가 증거): 배포된 데모 URL + 재실행 가능한 하네스 산출 영상/기록 → 루브릭 3기준 통과.
  • Step 3 (학습 경험): 1강(풀스택 배포·게시)→2강(3계층·콘텐츠)→3강(개념+회의록 에이전트)→4강(CLI·에신Lite 오케스트레이션)의 누적 부품 조립 경로.
02
선수학습 요건 (0강에서 전부 충족 — 각자 완료)
  • 코딩 지식 불필요 — 자연어 지시와 결과 검증 능력만 요구.
  • 계정 5종: Claude Pro(유료 구독) · GitHub · Vercel · Supabase · 타 LLM 택1(ChatGPT/Gemini/Grok).
  • 설치 6종: Node.js · Git · VS Code · Claude Code(CLI) · Claude 데스크톱(커넥터) · Antigravity(선택).
  • 두 안내서 숙지: ① 프로그램 설치 안내서.html ② 사전과제(입력·처리·출력) 작성 안내서.html.
  • 사전과제: 본인 업무 2~3개를 입력→처리→출력 형태로 적어오기(4강 미러링 소재).
  • 위 전부 0강에서 각자 완료. 1~4강은 0강 완료를 절대 선수조건으로 함 — 미완료자는 조교가 강 시작 전 개별 보정.

04
누적 부품 이월 지도 (Backward Assembly)

각 강의 산출물이 다음 강의 부품이 되도록 설계한다. 4강에서 전부 집결.

0강: 계정5+설치+결제 + 사전과제(본인 업무 I/P/O)      ──┐
                                                        │ (미러링 소재)
1강: 배포된 풀스택 랜딩페이지 URL (프론트+Supabase)    ──┤→ 4강 하네스의 "출력/배포·게시 채널"
2강: Claude 3계층 + 콘텐츠 엔진(블로그·유튜브)+검증루프──┤→ 4강 요약·검증 에이전트의 "산출 포맷"
3강: 동작하는 회의록 에이전트 1개 (스킬 2~3 + 메일 MCP)──┤→ 4강 4역할 에이전트의 "부품·조립 노하우"
                                                        │
4강: Claude Code CLI·에신Lite로 4역할 에이전트팀→하네스 1개 ←┘ (집결·오케스트레이션·게시)
     └→ 각자 본인 업무로 미러링(전이)

학습 경로 유형: 선형(Linear) — 각 강이 다음 강의 선행 조건인 누적적 기술. (learning-design 선형 경로 패턴)

05
커리큘럼 구조

각 강 타임라인은 실제 진행 분(0강 60~90분 / 1~4강 120분)에 맞춰 블록 분할했다. 유형 표기: 강의(개념 전달) / 시연(강사 완성본 시범, 원칙⓶) / 실습(학습자 따라하기·조별) / 발표(공유·회고). ※ 0강은 강의 없이 전달·설명 / 각자 완료 / 진단으로만 구성한다.

0강: 프로그램 설치 안내 (비대면 60~90분, 강의 없음) — "출발선 정렬"

모듈 목표

  • (이해) LLM 기반 업무 자동화가 "코딩이 아니라 지시와 검증"임을 두 안내서를 통해 파악할 수 있다.
  • (적용) 계정 5종·설치·결제를 각자 완료하고 도구 체크리스트를 완료할 수 있다.
  • (분석) 본인 업무 2~3개를 입력→처리→출력 구조로 분해해 기술할 수 있다.

실습설계자(lab-designer) 전달 사항

실습 가능한 도구/환경: Claude Pro · Claude Code(CLI) · Claude 데스크톱 · 에신Lite · GitHub · Vercel · Supabase · 웹검색/메일 MCP. (0강에서 전원 세팅 완료 전제)

실습 스캐폴딩 원칙

  • 원칙⓵ 강제: 모든 실습은 스타터(스켈레톤/템플릿/스니펫) 제공. 난이도 피라미드는 "빈칸 채우기 → 수정 → 확장" 순.
  • 원칙⓶ 강제: 실습 전 완성본 데모 산출물(예: 배포된 풀스택 페이지, 완성 회의록 에이전트, 완성 하네스)을 참조용으로 제공.
  • 누적 부품 이월: 각 강 실습 산출물을 다음 강에서 재사용 가능한 형태로 저장(URL·스킬 파일·MCP 설정·프로젝트 폴더).

강별 실무 연계 시나리오

  • 0강 사전과제: 본인 업무 2~3개 → I/P/O 시트(4강 미러링 시드).
  • 1강: 본인 직무 풀스택 랜딩페이지(회계 상담 접수 폼 등) 배포·게시.
  • 2강: 본인 직군 소재 블로그 1편 + 유튜브 세트.
  • 3강: 동작하는 회의록 에이전트 1개(회의록 생성·문서화 스킬 2~3개 + 메일 발송 MCP).
  • 4강 캡스톤: Claude Code CLI·에신Lite로 공통 프로젝트(수집·분석·검증·요약 4역할) 하네스 완성·게시 → 본인 업무로 미러링.

기준확인 질문판정
