개념 한 줄 정의 비유 처음 체험 방식

에이전트팀 역할 다른 에이전트들이 협업하는 구조 스타트업 소규모 팀 1강 강사 라이브 시연 관람
MCP Claude와 외부 도구를 연결하는 표준 규약 USB 규격 3강 개념 / 8강 실습 개념 소개 → 직접 연결
하네스 (Harness) 에이전트팀+스킬+MCP 묶음 반복 실행 파이프라인 공장 생산 라인 1강 시연 / 8강 직접 구동 결과물 감상 → 직접 실행
