## AI 도구 생태계 전체 지도

### Claude 계열 (Anthropic)

| 도구 | 접근 방법 | 핵심 특성 | 주요 사용 장면 |
|------|---------|---------|-------------|
| **Claude Chat** | claude.ai 웹 브라우저 | 빠른 대화, 즉시 코드 생성 | 아이디어 검증, 단발 코드 요청 |
| **Claude Co-work** | claude.ai → Projects | 파일·지침 영구 저장, 팀 공유 | 반복 작업, 스킬 파일 운용 |
| **Claude Code CLI** | 터미널 `claude` 명령어 | 코드베이스 전체 인식, 파일 직접 수정 | 실제 프로젝트 코딩, 에이전트 실행 |

### Google 계열 (Google 계정 공통 인증)

| 도구 | 접근 방법 | 핵심 특성 | 주요 사용 장면 |
|------|---------|---------|-------------|
| **Gemini** | gemini.google.com | Google 서비스 통합, 멀티모달 | Claude 대안 비교, 이미지 분석 |
| **Google AI Studio** | aistudio.google.com | API 키 발급, 프롬프트 플레이그라운드 | Gemini API 테스트, 시스템 지침 실험 |
| **NotebookLM** | notebooklm.google.com | 문서 기반 AI, 팟캐스트 생성 | 논문·PDF 요약, 강의 자료 분석 |
| **안티그래비티** | 강사 확인 | AI 자동화 특화 | 실무 자동화 워크플로우 |
