# 강의 입력 정보 — AX강의 2026.08 (v3)

> 이 문서는 course-builder 파이프라인의 SSOT(단일 진실 원천)이다. 하위 산출물(01~05)은 이 v3 확정 구조를 따른다.
> 전신: `_workspace/VibeCoding_AX_SM_v0.2_202607/` (0강+2h×4강+30일 팔로우업, 8h). v3에서 **주 1회 3시간 × 5주 = 총 15시간**으로 전면 재편성.

## 과정 주제
VibeCoding_AX (바이브코딩 기반 업무 자동화 실전) v3 — "코딩하지 않고 자연어로 지시하며, 검증은 사람이 한다"

## 과정 설명
전원 초보자(사내 정규직)를 대상으로 **주 1회 3시간 × 5주(총 15시간)** 구조로 설계한다.
목표는 수료 시 **본인 업무를 자동화하는 에이전트팀 + 이를 재생산하는 하네스**를 스스로 구축하는 것.
전 강 공통 프로젝트(글로벌 증시·뉴스 인사이트)를 실습선으로 일관 도입하고, 5강에서 본인 업무 하네스로 전이한다.
주간 간격을 활용해 **매 강 종료 시 다음 주까지의 과제**를 부여한다(정착·복습 효과).

## v0.2 → v3 주요 변경 (재작업 사유)
1. **시간 구조**: 0강(비대면)+2h×4강+30일 팔로우업 → **3h×5강(주 1회, 5주)**. 0강 설치는 1강 전반부에 흡수(대면·조교 개입), 30일 팔로우업의 하네스 정착 내용은 정식 **5강**으로 승격.
2. **1강**: 프로그램 설치 + **프로필 랜딩페이지**(풀스택) 생성·배포·게시.
3. **2강**: Claude 3계층 + 블로그·유튜브 **계정생성 → 작성 → 업로드** (계정생성이 정식 실습 단계로 추가).
4. **3강**: 자동화 개념 **5종(스킬·MCP·커넥터·에이전트·프로젝트)**으로 축소·집중 (에이전트팀은 4강에서, 하네스는 5강에서 각각 도입). 회의록 작성 프로젝트의 메일 발송을 **G메일(Gmail) 연동**으로 구체화.
5. **4강**: 증시·뉴스 인사이트 에이전트팀 — **에신Lite**(+Claude Code CLI)로 구축·게시.
6. **5강**: **업무자동화 하네스 개발** — 본인 업무 미러링 → 재실행 가능한 하네스 완성 → 수료 루브릭 판정 → 공유·확산.
7. 30일 팔로우업은 별도 세션으로 두지 않는다. (선택: 수료 30일 후 온라인 60분 사후 점검을 운영 옵션으로만 언급 가능)

## 대상 학습자
- **전원 초보자 (전체 정규직)**: 회계·세무·법무·미디어·MICE 등 전 직군. 코딩 무경험 전제.
- 컴퓨터·웹 도구 숙련도 편차 큼 → 3인 1조 + 강사 1 + 조교 1~2 배치로 실습 중 즉시 개입.

## 과정 규모
- **총 15시간 = 3시간 × 5강, 주 1회 (5주)**
- 각 강 180분 = 중간 휴식 10분 내외 포함 편성(타임라인에 휴식 블록 명시).
- 1강 전 사전 안내: 두 안내서(① 프로그램 설치 안내서 ② 사전과제 작성 안내서)를 **1강 2~3일 전 배포**, 설치는 미리 시도해 오되 **완료 확인·보정은 1강 전반부에서 대면 수행**(조교 개입).

## 3대 설계 원칙 (전 강 관통 — v0.2 계승)
1. **⓵ 백지 시작 금지** — 모든 실습은 강사가 준비한 템플릿·스켈레톤·스니펫에서 출발. 채우고·고치고·검증하는 데 시간을 쓴다.
2. **⓶ 데모 먼저, 따라하기 나중** — 매 실습은 강사 시연(완성본 먼저 보여주기) → 학습자 따라하기.
3. **⓷ 강사 + 조교 배석** — 3인 1조 + 강사 1 + 조교 1~2로 실습 중 즉시 개입. 한 명이 막히면 조 전체가 멈춘다.

## 각 강 안전·성실 수칙 (필수 반영)
- 1강: **service_role 등 비밀키는 어디에도 올리지 않는다** · anon 공개키만 페이지에 · 개인정보는 폼 예시에 넣지 않기.
