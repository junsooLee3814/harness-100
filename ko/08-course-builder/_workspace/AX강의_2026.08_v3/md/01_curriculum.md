## 과정 개요

- **과정명**: VibeCoding_AX (바이브코딩 기반 업무 자동화 실전) v3 — "코딩하지 않고 자연어로 지시하며, 검증은 사람이 한다"
- **대상 학습자**: **전원 초보자(사내 정규직 전 직군 — 회계·세무·법무·미디어·MICE)**. 코딩 무경험 전제. 컴퓨터·웹 도구 숙련도 편차 큼 → 3인 1조 + 강사 1 + 조교 1~2 배치.
- **총 학습 시간**: **15시간 = 3시간 × 5강, 주 1회(5주)**. 각 강 180분(중간 휴식 10분 내외 블록 포함 편성).
- **사전 안내**: 두 안내서(① 프로그램 설치 안내서 ② 사전과제 작성 안내서)를 **1강 2~3일 전 배포**. 설치는 미리 시도해 오되 **완료 확인·보정은 1강 전반부에서 대면 수행**(조교 개입).
- **과정 목표** (수료 시 학습자가 할 수 있는 것):
  1. 자연어 지시(바이브코딩)로 **풀스택 프로필 랜딩페이지(프론트+Supabase)를 생성·배포·게시**할 수 있다. (창조)
  2. Claude 3계층(chat/cowork/code)을 구분하고, 블로그·유튜브 채널을 **직접 개설해 콘텐츠를 생성-수정-검증-게시**할 수 있다. (이해·창조)
  3. 자동화 개념 5종(스킬·MCP·커넥터·에이전트·프로젝트)을 구분하고, 스킬 + **Gmail MCP/커넥터 연동**으로 **동작하는 회의록 에이전트 1개를 구축**할 수 있다. (분석·종합)
  4. **Claude Code CLI + 에신Lite**로 4역할(수집·분석·검증·요약) **에이전트팀을 구축·실행·게시**할 수 있다. (창조)
  5. 본인 업무를 I/P/O로 분해해 **재실행 가능한 업무자동화 하네스를 개발**하고, 수료 루브릭 3기준(실데이터 동작·결과 지향·재현성)으로 **자기 검증**할 수 있다. (전이·평가)

### 역방향 설계(UbD) 앵커
- **Step 1 (원하는 결과)**: 본인 업무를 자동화하는 **에이전트팀 + 이를 재생산하는 하네스**를 스스로 구축.
- **Step 2 (평가 증거)**: 배포된 데모 URL + 재실행 가능한 하네스 산출 영상/기록 → 수료 루브릭 3기준 통과 (5강 판정).
- **Step 3 (학습 경험)**: 1강(배포 채널)→2강(콘텐츠 포맷)→3강(회의록 에이전트=스킬+Gmail)→4강(에이전트팀)→5강(하네스)의 **누적 부품 조립** 경로 + 주간 과제로 강 간 정착.

## 선수학습 요건

- **코딩 지식 불필요** — 자연어 지시와 결과 검증 능력만 요구.
- **1강 전 사전 시도** (완료 확인·보정은 1강 전반부에서 대면 수행):
  - 계정 5종: Claude Pro(유료) · GitHub · Vercel · Supabase · 타 LLM 택1(ChatGPT/Gemini/Grok)
  - 설치: Node.js · Git · VS Code · Claude Code(CLI) · Claude 데스크톱(커넥터) · Antigravity(선택)
  - 두 안내서 숙지: ① 프로그램 설치 안내서 ② 사전과제 작성 안내서
- **콘텐츠 계정 2종**(블로그·유튜브)은 선수 요건이 아니다 — **2강에서 정식 실습으로 개설**한다.
- 미완료자는 1강 블록 1-2에서 조교가 개별 보정. **1강 종료 시 도구 체크리스트 100%가 2강 이후의 절대 선수조건.**

## 누적 부품 이월 지도 (Backward Assembly — 5강 집결)

각 강의 산출물이 다음 강의 부품이 되도록 설계한다. 4강에서 에이전트팀으로 조립되고, 5강에서 하네스로 최종 집결한다.

```
1강: 배포 채널 ──────────────────────────────────────────┐
     (프로필 랜딩페이지 URL = GitHub→Vercel 배포·게시     │
      + Supabase 데이터 흐름)                             │
                                                          ▼
2강: 콘텐츠 포맷 ────────────────────────────────────────┐
     (블로그·유튜브 채널 + 생성-수정-검증 루프            │
      = 산출물의 "모양"과 "품질 검증법")                  │
                                                          ▼
3강: 회의록 에이전트 ────────────────────────────────────┐
     (스킬 2~3개 + Gmail MCP/커넥터 연동 + 프로젝트 폴더  │
      = 부품 제작·연결·조립 노하우)                       │
                                                          ▼
4강: 에이전트팀 ─────────────────────────────────────────┐
     (수집·분석·검증·요약 4역할, Claude Code CLI+에신Lite │
      · 1강 채널로 게시 · 2강 포맷으로 산출               │
      · 3강 노하우로 부품 조립)                           │
      + (주간 과제) 본인 업무 I/P/O 시트 ────────┐        │
                                                 ▼        ▼
5강: 하네스 ══════════════════════════════════════════════
     (공통 프로젝트 하네스화 시연 → 본인 업무 미러링
      → 재실행 가능한 업무자동화 하네스 완성
      → 수료 루브릭 3기준 판정 → 공유·확산)
```

**학습 경로 유형**: 선형(Linear) — 각 강이 다음 강의 선행 조건인 누적적 기술. 분기 없음(전원 초보자 동일 경로), 편차는 3인 1조 + 조교로 실시간 흡수. **주간 과제가 강 사이의 이월 다리** 역할을 한다(특히 4강 후 I/P/O 시트 → 5강 핵심 소재).

**주간 과제(4강 후)**: **본인 업무 2~3개를 입력→처리→출력(I/P/O) 시트로 작성** — **5강 하네스 개발의 핵심 소재**이므로 미제출 시 5강 실습 진행 불가임을 명시. 조교가 주중 시트 초안을 1회 피드백(운영 권장).

### 5강: 업무자동화 하네스 개발 (대면 3h) — "팀을 재생산 구조로, 내 업무로 전이"

**모듈 목표**
- (이해) **하네스** 개념(5강에서 첫 도입 — 재생산 구조)을 에이전트팀과의 관계로 **설명할 수 있다**.

## 콘텐츠작성자(content-writer) 전달 사항

**공통 지침**
- 모든 실습 블록 교안은 **원칙⓶(데모 먼저)** 구조로: ① 강사 시연 스크립트(완성본 시범) → ② 학습자 따라하기 스텝 → ③ 배포자료(템플릿·스켈레톤·스니펫).
- **원칙⓵(백지 금지)**: 각 실습마다 채울 스켈레톤/스니펫을 반드시 첨부. "빈 화면에서 시작"하는 지시문 금지.
- **원칙⓷(조교 개입)**: 실습 블록마다 "막힘 예상 지점 + 조교 개입 스크립트"를 교안에 명시(특히 1-2 설치 보정, 2-4 계정 본인인증, 3-7 Gmail 권한, 5-5 미러링).
- 가네 9단계로 각 블록 구성(1주의획득=도입 데모, 3선행학습자극=**직전 주 과제 회고**, 6수행유도=조별 따라하기, 9전이=본인 업무 연결).
- 초보자 눈높이: 전문용어 첫 등장 시 1줄 정의 + 업무 비유. 새 개념 3개/블록 이하.
- **매 강 도입 블록(x-1)은 주간 과제 확인 대본 포함** — 주 1회 간격의 망각을 회고로 상쇄하는 것이 v3의 핵심 장치.
- **1강 교안 주의**: 1-3 LLM 브리핑은 **15~20분 압축 대본**으로 작성(표 A·B는 배포자료化, 강의는 판단 기준만). 1-2 설치 확인은 강의체가 아니라 **체크리스트 진행 + 트러블슈팅 대본**으로 작성.

**강별 핵심 개념 키워드**
- 1강: 10종 도구 체크리스트, LLM 4종 지형도(압축), 템플릿 채우기, **풀스택(프론트+Supabase)**, GitHub→Vercel 배포·게시, anon/service_role 키.

## 실습설계자(lab-designer) 전달 사항

**실습 가능한 도구/환경**: Claude Pro · **Claude Code(CLI)** · Claude 데스크톱(커넥터) · **에신Lite** · GitHub · Vercel · Supabase · **Gmail MCP/커넥터**(3강) · 웹검색 MCP/커넥터(4강) · 블로그(네이버/티스토리)·유튜브(2강 개설). 1강 전반부에서 도구 체크리스트 100% 완료 전제.

**실습 스캐폴딩 원칙**
- **원칙⓵ 강제**: 모든 실습은 스타터(스켈레톤/템플릿/스니펫) 제공. 난이도 피라미드는 "빈칸 채우기 → 수정 → 확장" 순.
- **원칙⓶ 강제**: 실습 전 완성본 데모 산출물(배포된 랜딩페이지, 게시된 블로그·유튜브, 완성 회의록 에이전트, 실행되는 에이전트팀, 재실행되는 하네스)을 참조용으로 제공.
- **원칙⓷ 강제**: 실습별 조교 개입 체크포인트(막힘 신호·개입 기준·백업 수단 — 예: 1강 배포 실패 시 조교 백업 계정) 명시.
- **누적 부품 이월**: 각 강 실습 산출물을 다음 강에서 재사용 가능한 형태로 저장(URL·채널·스킬 파일·Gmail 연동 설정·프로젝트 폴더·에이전트팀 정의). 4-7에서 1·2강 부품 재사용을 실습 절차에 명시적으로 포함할 것.
- **주간 과제 연동**: 각 강 실습 산출물이 주간 과제의 출발점이 되도록 설계(과제 = 강 내 실습의 소폭 변형·실전 적용). **4강 후 I/P/O 시트는 과제가 아니라 5강 실습의 입력물**이므로 시트 템플릿 + 작성 예시 2종(직군 상이)을 배포자료로 제공.

**강별 실무 연계 시나리오**
- 1강: 본인 직무 프로필 랜딩페이지(회계 상담 접수 폼, 법무 문의 폼 등) 배포·게시 + 재배포 과제.
- 2강: 본인 명의 블로그·유튜브 채널 개설 + 본인 직군 소재 글 1편 게시 + 유튜브 세트 업로드.
- 3강: **동작하는 회의록 에이전트 1개**(생성·문서화 스킬 2~3개 + Gmail 연동, 본인 메일 테스트) → 실제 회의 1건 적용 과제.
- 4강: 공통 프로젝트(글로벌 증시·뉴스 인사이트) 4역할 에이전트팀 구축·실행·게시(에신Lite+CLI).
- **5강 캡스톤**: 본인 업무 I/P/O 시트 → 미러링 설계 → **재실행 가능한 업무자동화 하네스** 완성 → 루브릭 판정.

**캡스톤 평가 루브릭 (수료 3기준 — 5강 5-7 판정)**

| 기준 | 확인 질문 | 판정 |
|------|----------|------|
| ⓵ 실데이터 동작 | 실제 본인/공통 업무 데이터로 동작하는가 | 통과 / 보완 |
| ⓶ 결과 지향 | "응답이 있다"가 아니라 "결과가 만들어진다"인가 | 통과 / 보완 |
| ⓷ 재현성 | 같은 입력 2회 실행 시 동일 품질인가 | 통과 / 보완 |

- 3기준 모두 통과 = 수료. 수료 증명 = **배포된 데모 URL + 동작하는 하네스 산출 영상/기록**. 보완 판정자는 수료 후 온라인 사후 점검(운영 옵션, 60분)에서 마무리.
- **안전 루브릭 (전 실습 공통 게이트, 5항목)**: ① 비밀키 노출 0(service_role·하드코딩 포함) · ② 고객/개인정보 프롬프트 입력 0(5강은 가명화 확인) · ③ 검증 단계 수행(출처·숫자 확인) · ④ 데이터 흐름 확인(Gmail·MCP 데이터 행선지 + 테스트 발송은 본인 메일) · ⑤ 대외 산출·사내 등재 전 사람 최종 확인(비밀키·내부정보 제거). 하나라도 위반 시 산출물 반려 후 재실행.
