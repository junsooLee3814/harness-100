강의 입력 정보 — VibeCoding_AX v3

"코딩하지 않고 자연어로 지시하며, 검증은 사람이 한다." 전원 초보자(사내 정규직) 대상 주 1회 3시간 × 5주 = 총 15시간 재편성판. 수료 시 본인 업무를 자동화하는 에이전트팀 + 이를 재생산하는 하네스를 스스로 구축한다. 이 문서는 course-builder 파이프라인의 단일 진실 원천(SSOT)이며, 하위 산출물(01~05)은 이 구조를 따른다.

v0.2 → v3 주요 변경 (재작업 사유)
  • 시간 구조: 0강(비대면)+2h×4강+30일 팔로우업 → 3h×5강(주 1회, 5주). 0강 설치는 1강 전반부에 흡수(대면·조교 개입), 30일 팔로우업의 하네스 정착 내용은 정식 5강으로 승격.
  • 1강: 프로그램 설치 + 프로필 랜딩페이지(풀스택) 생성·배포·게시.
  • 2강: Claude 3계층 + 블로그·유튜브 계정생성 → 작성 → 업로드 (계정생성이 정식 실습으로 추가).
  • 3강: 자동화 개념 5종(스킬·MCP·커넥터·에이전트·프로젝트)으로 축소·집중. 회의록 작성 프로젝트의 메일 발송을 G메일(Gmail) 연동으로 구체화.
  • 4강: 증시·뉴스 인사이트 에이전트팀 — 에신Lite(+Claude Code CLI)로 구축·게시.
  • 5강: 업무자동화 하네스 개발 — 본인 업무 미러링 → 재실행 가능한 하네스 → 수료 루브릭 판정 → 공유·확산.

3대 설계 원칙 (전 강 관통)

  • ⓵ 백지 시작 금지 — 모든 실습은 템플릿·스켈레톤·스니펫에서 출발.
  • ⓶ 데모 먼저, 따라하기 나중 — 강사 시연(완성본 먼저) → 학습자 따라하기.
  • ⓷ 강사 + 조교 배석 — 3인 1조 + 강사 1 + 조교 1~2, 실습 중 즉시 개입.

대상 학습자 · 편성

  • 숙련도 편차 큼 → 3인 1조 + 조교 즉시 개입.

각 강 안전·성실 수칙 (필수 반영)

  • 1강: service_role 등 비밀키는 어디에도 올리지 않는다 · anon 공개키만 페이지에 · 개인정보는 폼 예시에 넣지 않기.
  • 2강: AI는 문장, 사실 근거는 사람이 준다 · 허위 숫자·법조항 금지 · 고객정보 프롬프트 금지 · 계정 비밀번호는 개인 관리(공유 금지).
  • 3강: 고객정보 프롬프트 금지 · Gmail 연동이 데이터를 어디로 보내는지 확인 · 키 하드코딩 금지 · 테스트 발송은 본인 메일로만.
  • 4강: 검증 단계 생략 금지 · 출처 없는 주장 배제 · 고객 식별정보/기밀 입력 금지 · 최종 확인은 사람.
  • 5강: 기밀·개인정보는 가명화 후 사용 · 재현성 확인 전 "완성" 선언 금지 · 공유 저장소 등재 시 비밀키·내부정보 제거.
