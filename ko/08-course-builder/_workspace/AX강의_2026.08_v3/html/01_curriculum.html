과정 설계서 — AX강의 2026.08 v3 (VibeCoding_AX 주 1회 3h × 5주)

과정 개요

  • 과정명: VibeCoding_AX (바이브코딩 기반 업무 자동화 실전) v3 — "코딩하지 않고 자연어로 지시하며, 검증은 사람이 한다"
  • 대상 학습자: 전원 초보자(사내 정규직 전 직군 — 회계·세무·법무·미디어·MICE). 코딩 무경험 전제. 컴퓨터·웹 도구 숙련도 편차 큼 → 3인 1조 + 강사 1 + 조교 1~2 배치.
  • 총 학습 시간: 15시간 = 3시간 × 5강, 주 1회(5주). 각 강 180분(중간 휴식 10분 내외 블록 포함 편성).
  • 사전 안내: 두 안내서(① 프로그램 설치 안내서 ② 사전과제 작성 안내서)를 1강 2~3일 전 배포. 설치는 미리 시도해 오되 완료 확인·보정은 1강 전반부에서 대면 수행(조교 개입).
ⓘ SSOT · 전신 SSOT: md/00_input.md (v3 확정 구조 — 강 제목·시간 구조·산출물·안전수칙·주간 과제를 정답으로 삼음) · 전신: _workspace/VibeCoding_AX_SM_v0.2_202607/md/01_curriculum.md — 교수설계 스타일(블룸·UbD·가네·인지부하)을 계승하되, 3h×5강(주 1회 5주, 총 15시간) 구조로 전면 재작성.

과정 목표 (수료 시 학습자가 할 수 있는 것)

  • 창조 자연어 지시(바이브코딩)로 풀스택 프로필 랜딩페이지(프론트+Supabase)를 생성·배포·게시할 수 있다.
  • 이해·창조 Claude 3계층(chat/cowork/code)을 구분하고, 블로그·유튜브 채널을 직접 개설해 콘텐츠를 생성-수정-검증-게시할 수 있다.
  • 분석·종합 자동화 개념 5종(스킬·MCP·커넥터·에이전트·프로젝트)을 구분하고, 스킬 + Gmail MCP/커넥터 연동으로 동작하는 회의록 에이전트 1개를 구축할 수 있다.
  • 창조 Claude Code CLI + 에신Lite로 4역할(수집·분석·검증·요약) 에이전트팀을 구축·실행·게시할 수 있다.
  • 전이·평가 본인 업무를 I/P/O로 분해해 재실행 가능한 업무자동화 하네스를 개발하고, 수료 루브릭 3기준(실데이터 동작·결과 지향·재현성)으로 자기 검증할 수 있다.

역방향 설계(UbD) 앵커

  • Step 1 (원하는 결과): 본인 업무를 자동화하는 에이전트팀 + 이를 재생산하는 하네스를 스스로 구축.
  • Step 2 (평가 증거): 배포된 데모 URL + 재실행 가능한 하네스 산출 영상/기록 → 수료 루브릭 3기준 통과 (5강 판정).
  • Step 3 (학습 경험): 1강(배포 채널)→2강(콘텐츠 포맷)→3강(회의록 에이전트=스킬+Gmail)→4강(에이전트팀)→5강(하네스)의 누적 부품 조립 경로 + 주간 과제로 강 간 정착.

선수학습 요건

  • 코딩 지식 불필요 — 자연어 지시와 결과 검증 능력만 요구.
  • 1강 전 사전 시도 (완료 확인·보정은 1강 전반부에서 대면 수행):
    • 계정 5종: Claude Pro(유료) · GitHub · Vercel · Supabase · 타 LLM 택1(ChatGPT/Gemini/Grok)
    • 설치: Node.js · Git · VS Code · Claude Code(CLI) · Claude 데스크톱(커넥터) · Antigravity(선택)
    • 두 안내서 숙지: ① 프로그램 설치 안내서 ② 사전과제 작성 안내서
  • 콘텐츠 계정 2종(블로그·유튜브)은 선수 요건이 아니다 — 2강에서 정식 실습으로 개설한다.
  • 미완료자는 1강 블록 1-2에서 조교가 개별 보정. 1강 종료 시 도구 체크리스트 100%가 2강 이후의 절대 선수조건.

5강 · 업무자동화 하네스 개발 · 대면 3h

"팀을 재생산 구조로, 내 업무로 전이"

하네스 개념(재생산 구조)을 첫 도입하고, 공통 프로젝트 하네스를 본인 업무 I/P/O 시트로 미러링(복제·개조)해 재실행 가능한 본인 업무자동화 하네스를 완성합니다. 수료 루브릭 3기준으로 자기 판정하고 공유·확산으로 마무리합니다.

모듈 목표

  • 이해 하네스 개념(5강에서 첫 도입 — 재생산 구조)을 에이전트팀과의 관계로 설명할 수 있다.
  • 전이 공통 프로젝트 하네스를 본인 업무 I/P/O 시트로 미러링(복제·개조)할 수 있다.
  • 창조 재실행 가능한 본인 업무자동화 하네스를 완성할 수 있다.
  • 평가 수료 루브릭 3기준(실데이터 동작·결과 지향·재현성)으로 자기 판정할 수 있다.

  • 원칙⓵ 강제: 모든 실습은 스타터(스켈레톤/템플릿/스니펫) 제공. 난이도 피라미드는 "빈칸 채우기 → 수정 → 확장" 순.
  • 원칙⓶ 강제: 실습 전 완성본 데모 산출물(배포된 랜딩페이지, 게시된 블로그·유튜브, 완성 회의록 에이전트, 실행되는 에이전트팀, 재실행되는 하네스)을 참조용으로 제공.
  • 원칙⓷ 강제: 실습별 조교 개입 체크포인트(막힘 신호·개입 기준·백업 수단 — 예: 1강 배포 실패 시 조교 백업 계정) 명시.

  • 주간 과제 연동: 각 강 실습 산출물이 주간 과제의 출발점이 되도록 설계(과제 = 강 내 실습의 소폭 변형·실전 적용). 4강 후 I/P/O 시트는 과제가 아니라 5강 실습의 입력물이므로 시트 템플릿 + 작성 예시 2종(직군 상이)을 배포자료로 제공.
