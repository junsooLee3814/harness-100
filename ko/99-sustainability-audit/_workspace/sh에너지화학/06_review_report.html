  • (실측) 표기: E/S/G 보고서 모두 분기보고서 기재 항목에 적절히 적용 ✓

3. ESG 등급 타당성 검증

3.1 환경(E) — D 등급

검증 항목 판정 비고
D 등급 근거 충분성 ✓ 타당 GRI 공시율 4%, 환경 위반 3건, ISO 14001 미인증
C 등급 배제 근거 ✓ 적절 "일부 공시" 기준도 미달 (공시 전면 부재)
E 등급 배제 근거 ✓ 적절 형사 처벌·조업 정지 없음, 환경오염 대형사고 없음
과태료 5백만원의 D→E 상향 검토 ✓ 불필요 소액 과태료, 형사 처벌 아님 → D 유지 타당
셰일가스 자회사 리스크 반영 ✓ 적절 좌초자산·Scope 3 리스크로 분류

→ E:D 등급 타당. 유지.

3.2 사회(S) — C 등급

검증 항목 판정 비고
C 등급 근거 충분성 ✓ 타당 중대재해 없음(D 배제), 공시율 11%(B 미달)
B 등급 배제 근거 ✓ 적절 안전 KPI 전무, DEI 취약, 인권 체계 미구축
정규직 98.7%, 평균연봉 6,900만원 강점 반영 ✓ 균형 긍정 요소 인정하되 공시 부재로 C 유지
중대재해 1분기 기준 한계 △ 주의 연간 데이터 아님 — 보고서에 1분기 한정 명시 필요

→ S:C 등급 타당. "1분기 기준 중대재해 미발생"으로 표현 제한 적절.

3.3 거버넌스(G) — C- 등급

검증 항목 판정 비고

D 등급 배제 근거 ✓ 적절 감사의견 적정, Big 4 감사인, 내부회계관리제도 유효

여성이사 0명 법적 면제 반영 ✓ 적절 자산 2조 미만으로 법적 의무 없으나 ESG 취약점으로 기재

→ G:C- 등급 타당. 유지.

4. GRI Standards 적용 정확성 검증

4.1 Universal Standards (GRI 2) 적용

  • GRI 2-9 이사회 구성: 분기보고서 이사회 명단 정확 반영 ✓
  • GRI 2-11 의장 현황: 의장=대표이사 겸직 실측 ✓
  • GRI 2-24 내부통제: 내부회계관리제도 운영 사실 실측 ✓
  • GRI 2-27 법규 준수: 환경 제재 3건 실측 반영 ✓

4.2 Topic Standards 적용

  • GRI 305 배출: 목표관리제 제외 사실로 15,000 tCO2eq 미만 간접 확인 — 부분 공시로 적절 분류 ✓
  • GRI 401 고용: 인원·성비·근속·급여 실측 반영 ✓
  • GRI 403 안전: 중대재해 없음 실측 + 체계 미공시 구분 ✓
  • GRI 405 다양성: 여성 비율 7.3%, 이사회 여성 0명 실측 ✓

6. 개선 계획 실행 가능성 검증

6.1 비용 적정성

  • 총 5개년 투자 1.5억~2.8억원: 자본 692억 대비 0.02~0.04% — 영업손실 기업으로서 감내 가능한 수준 ✓
  • P0 긴급 과제 (배관 교체 + 안전체계): 환경 위반 재발 시 조업 정지 리스크 vs 예방 비용 — ROI 타당 ✓
  • 정부 지원 활용 제안: 고용노동부·환경부·중소기업진흥공단 지원 사업 언급 — 현실적 ✓

6.2 우선순위 타당성

우선순위 과제 타당성
P0 긴급 노후 배관 교체 ✓ 2025년 실제 위반 → 재발 방지 최우선
P0 긴급 중대재해 안전체계 ✓ 대표이사 형사처벌 리스크 → 즉시 필요

P2 ESG 위원회 ✓ 이사회 개편과 연동 가능
P3 집중투표제 재검토 ✓ 지배주주 동의 필요 — 장기 과제 적절

6.3 KPI 체계 적절성

  • 측정 가능한 지표 설정 (GHG 배출량, 안전재해율, 여성 비율, 공시율 등) ✓
  • 기준치 = 현재 실측치 활용 ✓
  • 목표치가 과도하지 않고 달성 가능한 수준 ✓

7. 불일치 발견 및 조치 사항

7.1 Minor Issues (경미한 사항)

번호 발견 사항 영향도 조치
M-1 S평가에서 "중대재해 없음"이 전사 연간 기준이 아닌 1분기 기준임을 명시 필요 낮음 보고서 내 "1분기 기준" 표기로 충분 — 수정 없이 진행
M-2 E평가 Scope 3 추정치(75,000~100,000 tCO2eq)가 보고서에서 범위로만 표기됨 낮음 추정치 범위 표기는 적절 — 유지
M-3 G평가에서 기타비상무이사 2명의 최대주주 추천 여부를 "추정"으로 처리 낮음 분기보고서 미공시 사항 → 추정 표기 정당

7.2 Major Discrepancy

발견 없음 — E/S/G 3개 평가 결과, 보고서, 개선 계획 간 중대한 불일치 없음.

8.1 ESG 종합 평가

영역 등급 핵심 근거

통합 의견: SH에너지화학은 법적 최소 의무를 형식적으로 충족하고 있으나, KOSPI 상장사로서의 ESG 정보 공개 의무와 기관 투자자의 공시 수요에는 크게 미달하는 수준이다. 3년 연속 영업손실과 시장 점유율 하락이라는 재무·사업적 압박 하에서 ESG 투자 여력이 제한적이나, 제시된 최소 비용(연 3,000만원 수준) 개선 과제부터 우선 이행하는 것이 기관 투자자 이탈 방지와 규제 리스크 감소 양면에서 합리적이다.
