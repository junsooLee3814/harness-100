## 3. 헌법 (타협 불가 5조)

1. 분양가상한제 적용지역은 분양가 임의 산정 금지 — 택지비+기본형건축비+가산비 구조로만
2. 재건축 수지에서 재초환 예정액 미반영 금지 — 불가 시 "이익 과대 가능" 경고 필수
3. 비례율·분담금은 "가평가(참고치)" 표기 — 법정 감정평가 대체 금지
4. PF 자기자본비율 등 시행 예정 규제는 시행 시점 명시 — 현행 확정 규제로 서술 금지
5. 조합원 개인정보(실명·주소·연락처) 노출 금지 — 익명 ID만

## 5. QC 결과 — 자기검증 금지 적용

제조자가 아닌 **별도 Verification Subagent**가 2라운드 검증. 코드는 실행·파손 시험까지 수행.

| Round | 점수 | Critical | High | 판정 |
|:-:|:-:|:-:|:-:|---|
| 1차 | 71/100 | 2 | 3 | 조건부 |
| 2차 | **87/100** | **0** | **0** | 조건부 → 조건 4건 해소 완료 |

### 1차에서 잡힌 치명 결함 (제조자 자신은 못 본 것)

**Critical 1 — 비례율 로직이 낙관 편향을 생성**
정비사업 비례율 계산에서 토지비 **그룹 전체**를 총사업비에서 빼도록 짜, 현금청산금·국공유지 매입비·주거이전비 같은 **실제 현금지출까지 제외**되고 있었다. 검증관 실측 **비례율 +22.0%p 과대**. → 항목 단위 플래그 `"비례율제외": true`로 전환, 현물출자분만 제외. 2차 재검증에서 소멸 확인.

**Critical 2 — 정비 견본이 사업으로 성립하지 않음**
세대수 120인데 조합원 500명, revenue에 조합원분양분 없음. → 800세대(조합원 470 + 일반 330, 현금청산 30명 제외)로 재작성, 면적·분양가·종전자산 전부 정합.

**High 3건** — 비용 그룹 누락 시 지출총계로 조용히 대체 / 60개월 무경고 절단 / `broken_refs` 검사가 구조상 실패할 수 없는 공허한 검사.

### 실증 결과 (2차)

| 검증 | 결과 |
|---|---|
| `py_compile` | exit 0 |
| 민간 견본 빌드 | 6시트 · broken_refs 0 · warnings 0 · exit 0 |
| 정비 견본 빌드 | 7시트 · broken_refs 0 · warnings 0 · exit 0 |
| **Excel COM 실제 재계산** | **오류 셀 0건**, 정합성 검증 6항목 전부 통과 |
| 정비 비례율 | 109.95% · 평균 권리가액 5.28억 · 평균 분담금 3.22억 (실무 범위) |
| 가드 파손 시험 | 12종 — 스키마 오류 exit 1 / 경고 exit 3. **조용한 오염 0건** |
| 회귀 검사 4종 | 소계 None 안전 / note() 무손상 / LTV·LTC 분모 정확 / 준공 적립비율 경계 정확 |

## 6. 엑셀 엔진 핵심

`build_xlsx.py` — openpyxl, **값이 아니라 수식을 기입**한다. `00_입력`의 노란 셀만 바꾸면 전 시트 재계산.

| 자동 처리 | 효과 |
|---|---|
| **PF이자 자동연결** | config의 임시 이자를 현금흐름 계산값으로 치환. 실측: 이자 31억→54억, 사업이익 42억→18.5억 정정. **이자 과소계상이라는 대표적 낙관 편향을 구조적으로 차단** |
| **자동 인출** | 현금이 마이너스인 달에만 부족분 인출 → 피크자금 = PF 잔액 최대치로 산출 |
| **행별 균형 검증** | 배분 행마다 Total 열 + 총액 일치 검증. 불일치는 `05_검증`에 표시 |
| **종료 코드** | 0 정상 / 1 스키마 오류 / 2 깨진 참조 / **3 경고** — 경고를 종료 코드로 강제 |

**선언된 한계** (`skill.md` "구현 범위와 한계", `excel_schema.md` §4-1) — 첫 트랜치만 월별 모델링 · 금리는 표 대신 입력 셀 재계산 · IRR 미산출 · RLV 미구현 · 정비 조합원분양분 회수 시점 근사.

## 7. 사용법

```bash
cp -r ko/101-real-estate-development/.claude/ /경로/내프로젝트/.claude/
```
`/real-estate-development` 호출 또는 "사업계획서 만들어줘".

**필수 9변수 — 3층 구조**

| 층 | 변수 | 누락 시 |
|---|---|---|
| **① 좌표** | 소재지 · 사업유형 · 현재단계 | **1개라도 없으면 즉시 질의, 작업 시작 금지** |
| ② 규모 | 분양면적(평) · 평당분양가 · 평당공사비 | 3개 이상 누락 시 중단 |
| ③ 자금·시간 | 토지매입비(정비: 현금청산·국공유지·주거이전비) · 사업기간 · 조달금리 | 1~2개 누락은 `[가정]` + 민감도 |

① 층을 최우선으로 둔 이유 — **소재지 없이는 분양가상한제·HUG 관리지역 판정이 불가해 헌법 1조를 적용할 수 없고**, 부담금 5종이 조례 위임이라 세무 검토가 불가하며, 지역별 초기분양률 실적이 없어 분양률 가정의 근거가 사라진다. 즉 검증되지 않은 분양가를 그대로 삼키게 되어 이 하네스가 막겠다고 선언한 낙관 편향을 스스로 생성한다.

건폐율·주차대수는 **참고정보**다 — 배치·층수 판단용이며 사업수지 계산에 쓰이지 않는다(엔진 실측 확인). 대지면적·용적률은 분양면적을 모를 때의 **도출 경로**이지 독립 변수가 아니다.

산출물은 `_workspace/00~06_*.md` + `사업수지_{프로젝트}_{YYYYMMDD}.xlsx`.
