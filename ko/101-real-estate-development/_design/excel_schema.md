> 출처: PO 제공 실제 PF 금융모델 1건 (대주 제출 최종본, 2023) — 저장소 외부 파일에서 **구조만** 추출.
> 사업명·금액·당사자 등 딜 정보는 본 문서에 기록하지 않음. 요율은 일반 실무 관행 수준만 기재.
> 원본 워크북 = 2시트 구성: `손익`(131행×28열) + `PF CASH`(955행×68열)

## 0. 핵심 발견 — 왜 이 구조가 표준인가

리서치(Phase 2.5)에서 "국내 도구에 약하다"고 지목했던 4가지가 이 실물에 전부 있다.

| 리서치가 지적한 공백 | 실물에서의 구현 |
|---|---|
| 자본구조·트랜치 | Tr.A(한도대출) / Tr.B·C(일시대출) 분리, 각각 약정한도·기초·증가·감소·잔액·이자 |
| 수지표 ↔ 현금흐름 연동 | 지출 항목을 `=손익!E35`, `=손익!I35`로 셀 참조. **이자는 역방향** — `손익!I114 = 'PF CASH'!BL121` |
| 자금 워터폴 | 분양수입금 → 대출금적립계좌(60%)/운영계좌(40%) → Tr.A 한도차감 → Tr.A→B→C 순차 상환 |
| 정합성 검증 | BL열 = 월별 합계, **BM열 = `BL=G` TRUE/FALSE 행별 자동 검증** |

→ 우리 엑셀 산출물은 이 4가지를 그대로 계승한다.

## 1. 시트 1 — `손익` (사업수지)

### 1-1. 사업개요 블록 (상단 좌측)

| 항목 | 비고 |
|---|---|
| 대지위치 / 지역지구 / 필지·지주수 | 텍스트 |
| 사업면적 · 매입면적 · 지상연면적 · 지하연면적 · 연면적 합계 | **㎡ 입력 → 평 = ㎡ × 0.3025 자동 환산 열 병기** |
| 건폐율 · 용적률 | % |
| 건축규모 · 구조 | 텍스트 |
| 공사기간 · 대출기간 | 개월 |

### 1-2. 대출개요 블록 (상단 우측) ★ 트랜치 테이블

열 구성: `구분 | 인출방식 | 대출한도 | 금융자문수수료 | 취급수수료 | 대출이자 | LTV | LTC`

- 행 = Tr.A / Tr.B / Tr.C / 합계
- 인출방식 = 한도대출 / 일시대출
- **LTV = 대출한도 ÷ 수입총계**
- **LTC = 대출한도 ÷ 지출총계**

### 1-3. 수입 블록

열: `구분 | 세부구분 | 분양면적(평) | 평당분양가 | 총규모 | 수입총액 | 구성비%`

- 용도별 그룹(주거/근생/기타) → 그룹 소계 → **분양 총액 → VAT → 수입 총계**
- 구성비 = 각 행 ÷ `$수입총계$` (절대참조)
- 면적은 ㎡ 원본에서 `×0.3025` 수식으로 연결 (하드코딩 금지)

### 1-4. 지출 블록 ★ 4대 분류

열: `구분 | 세부항목 | 산출근거(수량) | 단가·요율 | 지출총액 | 구성비%`
계산식: **지출총액 = 산출근거 × 단가·요율** (전 행 동일 패턴)

| 분류 | 대표 항목 |
|---|---|
| **토지비** | 토지매입비 · 제세공과금(취득세) · 법무사수수료 · 지주작업용역비 · 명도비 |
| **건축비** | 직접공사비 · 토목공사비 · 설비공사비 · 건축설계 · CM/감리 · 기계소방 · 전기소방 · 사급자재 · 인입공사 |
| **부대비용** | 신탁수수료 · 시행사 일반관리비 · 입주관리비 · 민원처리비 · **예비비** · PM수수료 · 분양대행 · 광고선전 |
| **금융비용** | 금융자문수수료 · 취급수수료(트랜치별) · **PF이자(트랜치별)** · 중도금대출이자 |

**요율 참조 방식** (실물에서 확인된 패턴 — 값이 아니라 *무엇에 곱하는가*가 핵심):

| 항목 | 산출근거(무엇에 곱하나) |
|---|---|
| 취득세·법무사 | 토지매입비 |
| 건축설계 · CM/감리 | 연면적(평) |
| 신탁수수료 | **수입 총계** |
| 예비비 | **분양 총액** |
| 시행사 일반관리비 | 사업기간(개월) × 월 정액 |
| 금융자문수수료 | 대출 합계한도 |
| 취급수수료 | **트랜치별 한도** (각각 별 행) |
| PF이자 | **PF CASH 시트 계산값 역참조** |

### 1-5. 자금집행 구분 매트릭스 ★ 이 파일의 백미

지출 각 행마다 재원을 4갈래로 쪼갠다.

```
예산(O) = 기투입비(P, Equity) + 필수사업비(Q, PF) + 분양불사업비(R) + 준공후불(T)
```

- 배분율 열 3개: `필수사업비율(W) / 분양불사업비율(X) / 정산사업비율(Y)`
- 계산: `Q = (예산 − 기투입비) × W`, `R = (예산 − 기투입) × X`, `T = (예산 − 기투입) × Y`
- **검증 열 V: `=O=(P+Q+R+T)` → TRUE/FALSE**
  - 공사비는 통상 `W=0.9, Y=0.1`(준공후불 10% 유보), 토지비·수수료는 `W=1`
- 대주가 "내 돈이 언제 얼마 나가는가"를 보는 열이므로 **PF 심사용 필수**

### 1-6. 사업이익

```
사업이익 = 수입 총계 − 지출 총계
이익률   = 사업이익 ÷ 수입 총계
```

## 2. 시트 2 — `PF CASH` (월별 현금흐름)

### 2-1. 타임라인 (열 방향)

| 행 | 내용 |
|:-:|---|
| 1 | `=YEAR()&"년"&MONTH()&"월"` 표시 |
| 2 | 기준일 → 이후 열은 `=이전열+31` |
| 3 | `-2개월차 / -1개월차 / 1개월차 …` |
| 4 | **PF 스케줄** — 기표 / D+1 / D+2 … |
| 5 | **공사 스케줄** — 착공 / D+1 … |
| 6 | 주요일정 마커 — 기투입 / **입주** / 정산 (워터폴 IF 조건에 사용) |

### 2-2. 진행률 드라이버 ★ 모든 배분의 기준

| 행 | 내용 |
|---|---|
| 공정률 | 월별 + **누계** (누계 = 전월누계 + 당월) |
| 분양률 | **용도별 2트랙**(주거/근생) 각각 월별 + 누계 |

→ 지출은 공정률에, 수입은 분양률에 곱해져 월별로 흩뿌려진다.

### 2-3. 수입 배분

납입 스케줄: `계약금 10% + 중도금 1~5차 각 10% + 잔금 30%` (근생은 잔금 50% 등 용도별 상이)

- 각 회차 금액 = `수입총액 × 회차비율`
- 월별 유입 = `회차금액 × 해당월 분양률` — 계약금은 월분양률, 중도금 1차는 **누계분양률** 사용
- 중도금 차수마다 도래 시점을 4개월 간격 등으로 배치
- 부가세는 `VAT × 당월수입 ÷ 분양총액`으로 비례 배분

### 2-4. 지출 배분 — 3가지 패턴

| 패턴 | 적용 | 수식 형태 |
|---|---|---|
| **공정률 연동** | 직접공사비 | `(총액 − 기투입) × 당월공정률` |
| **균등 분할** | 관리비·용역비 | `총액 ÷ 개월수` (`/24`, `/18`, `/12`, `/6`, `/3`) |
| **조건부 발생** | 분양불사업비 | `IF(분양률>0, 총액÷N, 0)` |

기투입비(Equity)는 `-2개월차` 열에 선반영.

### 2-5. 자금조달 상세

**Equity**: 기초잔액 → 증가액 → 감소액 → 기말잔액

**PF 트랜치별** (Tr.A/B/C 각 5행):
```
기초잔액 → 증가액(인출) → 감소액(상환) → 대출금 잔액 → 이자 = 전월잔액 × 이자율 ÷ 12
```

**한도대출(Tr.A) 자동 인출 로직**:
```
운영계좌 잉여현금 = 기초 + (인출+수입이체) − 사업비지출
재원조달 요구액 = ROUNDUP(−잉여현금, −5) × (잉여현금<0) × IF(PF만기, 0, 1)
```
→ 자금이 마이너스로 떨어지는 달에만, 1억 단위 올림으로 자동 인출. **피크자금이 여기서 산출된다.**

### 2-6. 분양수입금 워터폴 ★

```
분양수입금 ─┬→ 대출금적립계좌  (준공전 60% / 준공후 100%)
            └→ 운영계좌        (준공전 40% / 준공후 0%)

대출금적립계좌 감소 순서 (순차 우선):
  ① Tr.A 한도차감 및 운영계좌 이체
  ② Tr.A 상환  = IF(일정="입주", MIN(Tr.A잔액, 가용액), 0)
  ③ Tr.B 상환  = IF(일정="입주", MIN(Tr.B잔액, 잔여가용액), 0)
  ④ Tr.C 상환  = IF(일정="입주", MIN(Tr.C잔액, 잔여가용액), 0)
```

한도차감액은 `MIN(시점별 한도잔액, ROUNDDOWN(누적적립 − 누적차감, −5))` — 1억 단위 절사.

### 2-7. 검증 열 ★ 반드시 계승

| 열 | 내용 |
|---|---|
| BL (Total) | `=SUM(월별 전체)` |
| BM | **`=BL=G` → TRUE/FALSE** — 월별 배분 합계가 총액과 일치하는지 행별 검증 |

→ 우리 산출물도 **모든 배분 행에 이 2열을 붙인다.** 하나라도 FALSE면 리포트에 경고.

리서치의 6시트 표준 + 실물의 2시트 구조를 통합한다.

| # | 시트 | 근거 | 비고 |
|:-:|---|---|---|
| 1 | `00_입력` | 리서치 (Input 시트) | 필수 9변수 + 권장 5변수 + 요율표. **여기만 사용자가 수정** |
| 2 | `01_사업수지` | 실물 `손익` | 개요·트랜치·수입·지출 4분류·자금집행 매트릭스·사업이익 |
| 3 | `02_현금흐름` | 실물 `PF CASH` | 월별 타임라인·공정률/분양률·수입배분·지출배분·트랜치·워터폴 |
| 4 | `03_민감도` | 리서치 (실물에 없음 — **우리 추가**) | 분양가·분양률·공사비·금리 4변수, **손익분기 분양률** |

| 6 | `05_검증` | 실물 BM열 확장 | 균형식 TRUE/FALSE 집계, FALSE 목록 |

**정비사업 모드 추가 시트** (사업유형 = 정비사업일 때만 생성):

| 시트 | 내용 |
|---|---|
| `06_비례율` | 종전자산 총액 · 종후자산 총액 · 총사업비 → **비례율 = (종후 − 총사업비) ÷ 종전** · 권리가액 · 조합원 분담금 · 비례율 민감도 |

## 4. 실물에서 발견한 결함 — 우리가 피할 것

| 결함 | 내용 | 우리 대응 |
|---|---|---|
| `#REF!` 잔존 | Tr.B 상환 행 수식에 `MIN(#REF!, …)` | 생성 후 전 셀 `#REF!`·`#DIV/0!` 스캔, 발견 시 실패 처리 |
| 빈 라벨 행 다수 | 템플릿 원형(아파트용)에서 미사용 행이 라벨 없이 잔존 | 미사용 항목은 행 자체를 생성하지 않음 |
| 용도 라벨 불일치 | 물류 딜인데 행 이름이 `분양률(아파트)` | 라벨을 입력 시트의 용도명에서 동적 생성 |
| 하드코딩 혼재 | 일부 금액이 수식 없이 상수 | 상수 입력은 `00_입력` 시트로만 한정, 나머지는 전부 수식 |

## 4-1. 구현 범위 확정 (설계 → 실제 반영 결과)

위 §3의 설계안 중 **실제 구현된 범위**는 다음과 같다. 설계안을 그대로 사양으로 인용하면 사양-구현 불일치가 되므로, 아래를 기준으로 삼는다.

| 설계 항목 | 구현 여부 | 비고 |
|---|:-:|---|
| 6~7시트 구성 | ✅ | 정비사업 시 `06_비례율` 추가 |
| 수입·지출 4대 분류 + 자금집행 매트릭스 | ✅ | 균형 검증식 포함 |
| 월별 현금흐름 (공정률·분양률 드라이버, 자동 인출) | ✅ | |
| 행별 Total + 검증 열 | ✅ | 배분 행 전체 |
| LTV · LTC | ✅ | `04_요약`. 트랜치 합계 한도 기준 |
| 트랜치 A/B/C 각각의 월별 잔액·이자·순차 상환 | ⚠️ **부분** | **첫 트랜치만** 월별 모델링. 다중 트랜치는 `04_finance_plan.md`에 서술 |
| 분양수입금 워터폴 (적립계좌 준공 전/후) | ⚠️ **부분** | 준공 시점 자동 전환은 구현. 계좌 분리·순차 상환은 단일 트랜치 기준 |
| 민감도 4변수 (분양가·분양률·공사비·금리) | ⚠️ **3변수** | 분양가×공사비 2변수 표 + 분양률 근사표. **금리는 표 대신 입력 셀 변경으로 실시간 재계산** |
| IRR | ❌ | 미산출. 필요 시 월 순현금 행에 Excel `IRR()` 적용 |
| 잔여지가(RLV) 역산 | ❌ | 미구현 |

> 금리 민감도를 표로 만들지 않은 것은 축소가 아니라 설계 판단이다. 이 워크북은 수식이 살아 있으므로 `00_입력`의 금리를 바꾸면 이자·PF잔액·사업이익이 전부 재계산된다. 정적 근사표보다 정확하다.
