### ② 학술·표준·규제 (16건 확인, 조문·고시 대조)

- **정비사업**: 사업시행계획서 법정 13항목(도정법 §52①), 관리처분계획 9항목(§74①), 감정평가 주체(§74④ — 재개발은 시장·군수 선정 2인↑, 재건축은 시장·군수 1인↑ + 총회 의결 1인↑), 수립기준(§76①)
- **2025 개정 시행 확인**: 2025.5.1 조합설립 동의요건 75%→**70%** / 2025.6.4 안전진단→**재건축진단** 개칭·실시기한 사업시행계획인가 전까지 연기·추진위도 요청 가능 / 2025.12.4 전자서명 동의·온라인총회
- **민간**: 주택법 사업계획승인 30세대↑(단지형 연립·다세대 일부 50세대), 부동산개발업 등록 자본금 3억(법인)
- **분양가상한제**: 분양가 = 택지비 + 기본형건축비 + 가산비 (주택법 §57). HUG 고분양가 관리 = 법령 아닌 **내규**, 인근 평균의 110% 초과 시 보증 거절
- **PF**: 사업성 평가 4단계(양호·보통·유의·부실우려, 2024.6 시행). 자기자본비율 규제는 **시행 시점 트랙 간 진술 불일치** → §4 참조
- **부담금**: 재초환(1인 평균 8천만원 초과분 10~50% 누진, 장기보유 최대 70% 감경), 학교용지(100→**300세대**, 0.8%→**0.4%** 완화, 공포·시행일 확인 필요), 광역교통(표준건축비×부과율×연면적−공제), 개발부담금(20% / 지목변경 수반 25%)
- **감정평가**: 개발법(공제방식) = 분양수입 현재가치 − 개발비용 현재가치

## 2. 종합 발견 — 패턴 5건

1. **"숫자 엔진"과 "문서"의 단절** — 국내외 어떤 도구도 수지 계산과 대주단 제출용 서술형 사업계획서를 함께 내지 않는다. 보고서는 여전히 용역 수작업.
2. **실무 표준은 엑셀 6시트** — 유료 강의가 팔릴 만큼 어렵고, 도구화되지 않았다.
3. **수지표(발생주의) ≠ 현금흐름표(현금주의)** — 두 표의 분리와 연동, 피크자금 산출이 실무 최대 병목.
4. **사업성 단일 최대 변수는 지상연면적당 토지비** — 용적률이 곧 사업성 레버(서울시 사업성 보정계수 최대 2.0).
5. **낙관 편향이 구조적** — 분양률 100% 가정, 공사비 물가 미반영, 사업기간 과소, 금융비 과소, 예비비 누락의 5종 세트가 반복된다.

## 3. 차별점 후보 3건

1. **수지 엔진 + 서술형 사업계획서 동시 산출** — 확인된 모든 경쟁 도구의 공백.
2. **한국 고유 계정 전체 반영** — 부담금 5종 + 분양보증료 + 중도금 무이자 + 신탁수수료 + 책임준공. ARGUS 계열에 없고, 국내 도구는 반대로 자본구조·IRR이 약하다.
3. **정비 / 민간 이중 트랙** — 비례율·분담금 엔진과 IRR·LTC 엔진을 한 하네스에서 분기 처리. 정비사업 비례율 민감도 도구는 사실상 부재.

## 5. 적용 표준·규제 → 헌법 제약 5조 (하네스에 명문화)

1. 분양가상한제 적용지역은 분양가 임의 산정 금지 — 택지비+기본형건축비+가산비 구조로만. 지역 지정 여부 미확인 시 "미확인" 명시
2. 재건축 수지에서 재건축부담금 예정액 미반영 금지
3. 비례율·분담금은 법정 감정평가액을 대체하지 않음 — 에이전트 산출은 "가평가(참고치)"로만 표기
4. PF 자기자본비율 규제는 시행 시점을 명시하고 현행 확정 규제로 서술 금지
5. 조합원 개인정보(실명·주소·연락처) 노출 금지 — 종전자산 명세는 익명 ID

## 7. 최신성 주의 — 매 실행 시 검색 필요

1. 분양가상한제 적용지역 지정·해제 현황 + 기본형건축비 고시(연 2회↑ 변동)
2. HUG 고분양가 관리지역 목록·심사기준(내규, 수시 변경)
3. 재초환 폐지·유예 입법 진행 (2026년 현재 존치, 논의 지속)
4. **PF 자기자본비율 시행 시점 — 트랙 간 진술 불일치**: 트랙②는 "2027년부터 4년간 5→10→15→20%", 트랙④는 "2026년 10% → 2027년 15% → 2028년 20%". 어느 쪽도 확정 인용 금지, 매번 금융위 원문 확인
5. 학교용지부담금 개정법(300세대·0.4%) 공포·시행일
6. 도정법 2025.12.4 시행분 후속 시행령·조례, 정비구역 입안 노후도 요건(지자체 조례)
7. 도정법 §52·§74 현행 조문 — 조사 원문이 2021년 버전이라 국가법령정보센터 재확인 필요
