**수지분석 시트의 2,495세대는 1차 사업 설계도서의 3개 단지 합계와 정확히 일치한다** (59형 457 · 74형 241 · 84형 1,747 · 110형 50 — [00_input.md](00_input.md) §2-2 참조). 토지 55,241평(≒182,606㎡) 역시 1차 제안구역 184,660㎡에 근접한다.

즉 **"2차부지" 파일에 1차 전체 사업의 규모가 들어가 있다.**

### 워크북이 스스로 남긴 증거

```
2.용도별 분양내역!Y19  =  W18 - 수지분석!F13
                      =  175,029,929 - 955,605,700
                      = -780,575,770 천원   (△7,805.8억원)
```

`Cash Flow!BN6`·`BN13`에도 동일한 780,575,770이 기록되어 있다. 작성자가 격차를 인지하고 검산 셀을 남겨둔 상태로 보인다.

### 연결 구조 확인

수지분석 5~8행(실제 매출을 만드는 행)은 **전부 하드코딩**이며 `2.용도별 분양내역`을 참조하지 않는다. 참조가 걸린 9~11행은 값이 전부 0이다.

```

토지비·공사비 산정면적도 하드코딩이다.

```

수지분석!H32 = 115626.39    (평, 하드코딩)  → 도급공사비 6,128.2억
수지분석!H35 = =H32   H40 = =H32   H41 = =H32

> `H32`의 115,626.39평(≒382,258㎡)은 사업개요 연면적(110,250.88㎡)의 **3.5배**이며, 1차 설계도서 총 연면적(406,689.53㎡)과도 일치하지 않는다. **출처 불명 수치다.**

**→ 어느 사업의 수지인지부터 확정해야 한다.** 877세대라면 매출·토지·공사비 전부 재작성, 2,495세대라면 사업개요·분양내역 시트가 폐기 대상이다.

## 12. 산출 근거

- 모든 수치는 openpyxl로 **캐시값과 수식을 동시에 추출**해 대조했다. 표기한 셀 주소는 원본 그대로다.
- BEP 평당가는 총사업비가 분양가와 독립임을 확인한 뒤(광고선전비 정액, 분양대행비 세대당 정액, 분양보증수수료는 공사비 연동) `세전이익 = 아파트매출 − 895,889,780`을 풀어 산출했다.
- 금융비용 누락액 423.3억은 **금액 셀이 0인 상태에서 구성비 셀에만 남아있는 값**(G81 0.7%, G83 4.0%)을 총사업비에 되곱해 역산한 추정치다. 실제 조건에 따른 재산정이 필요하다.
- 두 xlsx 파일 동일성은 전 시트 8,279개 비어있지 않은 셀 전수 대조로 확인했다.
