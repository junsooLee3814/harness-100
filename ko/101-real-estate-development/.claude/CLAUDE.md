# Real Estate Development Harness

부동산개발사업 사업계획 — 인허가·절차 → 분양성 → 사업수지 → 자금조달 → 세무 → 리스크·사업계획서를 에이전트 팀이 협업하여 수행하는 하네스.

**정비사업 조합 시행(재개발·재건축)** 과 **민간 자체시행(토지매입→인허가→분양)** 두 트랙을 모두 다루며, 구역지정·토지매입 단계부터 준공·이전고시·청산까지 전 단계를 커버한다.

## 사용법

`/real-estate-development` 스킬을 트리거하거나, "사업계획서 만들어줘", "사업성 검토해줘" 같은 자연어로 요청한다.

## 산출물

모든 산출물은 `_workspace/` 디렉토리에 저장된다:
- `00_input.md` — 사업 개요 및 입력 변수 정리
- `01_permit_schedule.md` — 인허가·절차 일정 보고서
- `02_sales_analysis.md` — 분양성 분석 보고서
- `03_feasibility.md` — 사업성(사업수지) 분석 보고서
- `04_finance_plan.md` — 자금조달 계획 보고서
- `05_tax_review.md` — 세무·부담금 검토 보고서
- `06_business_plan.md` — 리스크 매트릭스 + 최종 사업계획서
- `사업수지_{프로젝트명}_{YYYYMMDD}.xlsx` — 수식이 살아있는 사업수지 워크북 (6~7시트)

## 헌법 (타협 불가 5조)

1. **분양가상한제 적용지역에서는 분양가 임의 산정 금지** — 택지비 + 기본형건축비 + 가산비 구조로만 산출. 지역 지정 여부 미확인 시 "미확인" 명시.
2. **재건축사업 수지에서 재건축부담금(재초환) 예정액 미반영 금지** — 산정 불가 시 "미반영 — 사업이익 과대 가능" 경고 필수.
3. **비례율·분담금은 법정 감정평가액을 대체하지 않는다** — 에이전트 산출은 반드시 "가평가(참고치)"로 표기.
4. **PF 자기자본비율 등 시행 예정 규제는 시행 시점을 명시** — 현행 확정 규제로 서술 금지.
5. **조합원 개인정보(실명·주소·연락처) 노출 금지** — 종전자산 명세는 익명 ID로만.
