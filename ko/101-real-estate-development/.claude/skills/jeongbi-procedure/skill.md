# 정비사업 절차 지식 베이스

도시 및 주거환경정비법(이하 "도정법") 기준. **각 단계는 앞 단계의 완료가 다음 단계의 선행요건이 되는 연쇄 구조**이며, 특히 준공인가 → 대지확정측량 → 이전고시 → 청산금 → 해산 → 청산이 법적으로 연동되어 있다.

> ⚠️ **최신성 경고**: 도정법은 2025~2026년 개정이 잦다. 아래 내용을 인용하기 전에 **반드시 웹 검색으로 현행 여부를 확인**하고, 확인 실패 시 "법령 미조회"를 명시하라. 조문번호가 불확실하면 "조문 확인 필요"로 표기하고 추정 인용하지 않는다.
> 세부 절차·시점은 개별 사업의 **정관·인가조건·지자체 조례**에 따라 달라진다.

## 1. 전체 절차 흐름

```
[준비 단계]
기본계획 수립 → 정비계획 입안·정비구역 지정 → (재건축) 재건축진단
  → 추진위원회 구성·승인 → 조합설립인가

[시행 단계]
시공자 선정 → 사업시행계획인가 → 분양공고·분양신청
  → 관리처분계획인가 → 이주·철거 → 착공

[완료 단계]  ※ 아래 §3에서 12절차로 상세
준공인가 → 대지확정측량·토지분할 → 이전고시 → 소유권등기
  → 청산금 징수·교부 → 조합 해산 → 청산인 선임 → 청산 종결
```

## 2. 준비·시행 단계 요점

| 단계 | 근거 | 핵심 요건 | 확인 상태 |
|---|---|---|---|
| 정비구역 지정 | 도정법 제2장 | 노후·불량건축물 비율 등 입안요건 — **지자체 조례 위임분이 크다** | 조례 확인 필요 |
| 재건축진단 | 2025.6.4 시행 개정 | 舊 '안전진단' 개칭. 실시기한을 **사업시행계획인가 전까지**로 연기. 현지조사(예비진단) 폐지, 인접단지 통합진단, **추진위·사업시행자도 요청 가능** | 검색 확인 |
| 추진위원회 구성 | 도정법 제3장 | 토지등소유자 동의 요건 + 시장·군수 승인 | 동의율 검색 확인 |
| 조합설립인가 | 도정법 제3장 제2절 | **재개발과 재건축의 동의요건이 다르다.** 2025.5.1 시행으로 재건축 동의요건 **75% → 70%**, 복리시설 과반 → **1/3** 완화 | 검색 확인 필수 |
| 시공자 선정 | 도정법 / 국토부 고시 | 경쟁입찰 원칙. 계약 방식·공사비 검증 절차 | — |
| 공사비 검증 | 도정법 제29조의2 | 의무 대상: 조합원 20% 요청 / 사업시행인가 前 선정은 10%·後 선정은 5% 이상 증액 / 재검증은 3% 추가 증액. 한국부동산원 수행 | 요건 검색 확인 |
| 사업시행계획인가 | 도정법 제52조 | **계획서 법정 기재사항 13항목** (§4 참조) | 조문 확인 |
| 분양신청 | 도정법 제3장 제5절 | 분양공고 → 분양신청 기간 → 미신청자 현금청산 | — |
| 관리처분계획인가 | 도정법 제74조 | **계획 법정 내용 9항목** (§4 참조). 인가·고시일부터 **종전 토지·건축물 사용·수익 정지** → 이주·철거·착공의 법적 기점 | 조문 확인 |
| 전자서명·온라인총회 | 2025.12.4 시행 | 동의 전자서명(제36조), 온라인총회(제44조의2) | 검색 확인 |

## 3. 완료 단계 12절차 ★ 시계열 연동

| # | 단계 | 근거·주관 | 핵심 효과 / 실무 포인트 |
|:-:|---|---|---|
| 1 | **관리처분계획인가** | 제74조 / 시장·군수등 | 종전자산(권리가액)·종후자산·조합원별 분담금·일반분양분 확정. **인가·고시일부터 종전 토지·건축물 사용·수익 정지** → 이주·철거·착공의 법적 기점 |
| 2 | 이주·철거·착공 | 조합(시행자) | 관리처분인가 고시 이후 진행. 이주비·이주기간 관리, **명도 완료가 착공 전제** |
| 3 | 준공인가 전 사용허가 | 제83조제5항 / 시장·군수등 | 완공된 동·세대에 한해 조기 입주 허용. **'사용' 허용일 뿐 소유권 이전·청산금 정산의 효력은 없음** |
| 4 | **준공인가** | 제83조 / 시장·군수등 | 사업시행계획대로 시공되었는지 검사 후 준공 인가·고시. 건축물대장 생성. **대지확정·이전고시의 선행요건** |
| 5 | 대지확정측량·토지분할 | 제86조 / 조합·지적소관청 | 지적확정측량 후 종후 필지로 분할·정리. **이전고시의 필수 선행절차** — 대지의 위치·경계·면적이 확정되어야 개별 소유권 이전 가능 |
| 6 | **이전고시** | 제86조 / 시장·군수등 | 관리처분계획대로 대지·건축물 소유권을 이전한다는 사실을 고시. **이전고시일 '다음 날' 분양받은 자가 소유권 취득.** 사업의 실질적 완료 시점이자 해산·청산 기산점 |
| 7 | 소유권보존·이전등기 | 제86조 / 조합·등기소 | 이전고시 후 지체 없이 등기. 등기 완료 전에는 원칙적으로 종후자산 처분 제한 |
| 8 | **청산금 징수·교부** | 제89조·제90조 / 조합 | 종전·종후자산 차액(분담금·환급금)을 부과·징수 또는 지급. **이전고시일 다음 날 청산금 확정.** 미납 시 공법상 강제징수 가능, **소멸시효 5년** |
| 9 | 조합 해산 | 제86조의2 / 조합 총회 | **조합장은 이전고시일부터 1년 이내 해산총회 소집 의무.** 조합원 과반수 출석·출석 과반수 찬성 의결(정관 우선) |
| 10 | 청산인 선임·청산 개시 | 도정법 / 민법 준용 | 정관·총회에 정함 없으면 조합장이 청산인. 해산 시점부터 조합은 **'청산 목적 범위'에서만 존속** |
| 11 | 청산 사무 수행 | 민법 준용 / 청산인 | 현존사무 종결·채권추심·채무변제·잔여재산 분배. **조세채무 등 변제 후 분배가 원칙.** 미변제 분배 시 청산인의 제2차 납세의무·손해배상 책임 발생 가능 (국세기본법 제38조) |
| 12 | 청산 종결·청산등기 | 민법 준용 / 청산인·등기소 | 결산보고 총회 승인 + 청산종결등기로 법인격 소멸. 다만 **청산 종결 후에도 미처리 사무가 있으면 실질적 미종료로 봄** |

### 핵심 기산점 4개

- **관리처분계획인가 고시일** — 조합원 권리·의무 확정, 종전 부동산 사용·수익 정지의 기점
- **준공인가(공사완료 고시)** — 건축물 사용가능 확정, 대지확정·이전고시의 선행요건
- **이전고시일 다음 날** — 소유권 취득 및 **청산금 확정**, 해산·청산 절차의 기산점
- **이전고시일부터 1년 이내** — 해산총회 소집 법정기한

### 완료 단계 실무 유의사항

- '준공전 사용승인'은 입주만 허용할 뿐 소유권·청산금 효력이 없다 → **정산·회계마감의 기준시점은 이전고시일**
- 준공인가 후 **대지확정측량·토지분할이 지연되면 이전고시가 늦어지고**, 해산·청산 및 청산금 정산 전체가 연쇄 지연된다
- 청산 단계에서 잔여재산 분배 전에 **조세·미납채무 변제 여부를 먼저 확정**해야 한다. 분배 후에는 정정·회수가 사실상 불가능하다
- 조합장(청산인)은 이전고시 다음 날부터 **반기별로 해산·청산 계획을 관할 행정청에 제출할 의무**가 있다

## 4. 법정 기재사항

### 사업시행계획서 (제52조제1항, 13호)

토지이용계획(건축물배치 포함) / 정비기반시설·공동이용시설 설치계획 / 임시거주시설 포함 주민이주대책 / 세입자 주거·이주대책 / 범죄예방대책 / 임대주택 건설계획(재건축 제외) / 국민주택규모 주택 건설계획 / 공공지원민간임대주택 계획 / 높이·용적률 등 건축계획 / 폐기물 처리계획 / 교육환경 보호계획 / **정비사업비** / 대통령령·조례 위임사항

### 관리처분계획 (제74조제1항, 9호)

분양설계 / 분양대상자 명세 / **분양예정 대지·건축물 추산액** / 보류지 명세·추산액·처분방법 / **종전 토지·건축물 명세 및 사업시행계획인가 고시일 기준 가격** / **정비사업비 추산액 및 조합원 분담규모·분담시기** / 소유권 외 권리명세 / 세입자 손실보상 평가액

### 감정평가 주체 (제74조제4항)

- 재개발·주거환경개선: **시장·군수 선정 2인 이상**
- 재건축: **시장·군수 선정 1인 이상 + 조합총회 의결 선정 1인 이상**
- 산술평균. 비용은 사업시행자 예치 → 시장·군수 직접 지급·정산

### 관리처분 수립기준 (제76조제1항)

종전 면적·이용상황·환경 종합고려 균형배분 / 과대·과소 토지 조정 / 과소토지·구역지정 후 분할취득자 현금청산 가능 / 1주택 공급 원칙 및 예외(과밀억제권역 등)

## 5. 비례율·분담금 ★ 법정 산식 아님

도정법에 직접 규정된 산식이 아니라, 제74조제1항 3·5·6호 항목들의 조합으로 실무에서 확립된 계산이다.

```
비례율   = (종후자산 총액 − 총사업비) ÷ 종전자산 총액 × 100
권리가액 = 개별 종전자산 평가액 × 비례율
분담금   = 조합원 분양가 − 권리가액        (음수면 환급금)
```

**적용 규칙**
- 종전·종후자산은 **감정평가법인등의 법정 평가액**에 의한다. 에이전트 산출은 반드시 **"가평가(참고치)"로 표기**한다
- 비례율은 총사업비에 극도로 민감하다 → **공사비 ±10%, ±20% 민감도를 반드시 제시**한다
- 비례율 100% 미만은 정상적으로 발생할 수 있다. **숨기지 말고 조합원 추가 분담 발생을 명확히 경고**한다
- 사업 초기(정비계획 수립 시기)의 추정분담금은 부정확할 수밖에 없다 — 추정분양가·추정공사비·구역 특수용역비·사업기간·금융비가 복합 작용한다. **정확도 한계를 반드시 명시**한다

## 6. 정비사업 세무 접점 (tax-accountant용)

| 항목 | 기산점·기준 | 비고 |
|---|---|---|
| 재건축부담금(재초환) | 재건축초과이익 환수에 관한 법률 | 조합원 1인당 평균 초과이익 기준선 초과분 누진 부과. 장기보유 감경, 60세 이상 납부유예. **폐지·완화 입법 논의 지속 → 현행 여부 반드시 검색 확인** |
| 조합원 입주권 양도세 | 관리처분계획인가일 전후로 과세 성격 변동 | 1세대1주택 비과세 요건 별도 |
| 청산금 | 이전고시일 다음 날 확정 | 소멸시효 5년 |
| 조합 법인세 | 일반분양 수입 관련 | 청산 시 조세채무 변제 후 분배 (국기법 §38 제2차 납세의무) |
| 부가가치세 | 전용 85㎡(국민주택규모) 기준 과세·면세 구분 | 토지분 면세, 건물분 과세 |

## 7. 재개발 vs 재건축 주요 차이

| 항목 | 재개발 | 재건축 |
|---|---|---|
| 진단 절차 | 없음 | **재건축진단** (2025.6.4 개칭·기한 완화) |
| 조합원 자격 | 토지 또는 건축물 소유자, 지상권자 | 건축물 및 부속토지 **모두** 소유 |
| 미동의자 처리 | 수용·손실보상 | **매도청구** |
| 감정평가 주체 | 시장·군수 선정 2인 이상 | 시장·군수 1인 + 총회 의결 1인 이상 |
| 임대주택 건설 | 의무 | 제외 |

## 8. 사용 규칙

1. 이 문서를 **인용하기 전에 웹 검색으로 현행 여부를 확인**한다
2. 검색 실패 시 보고서에 **"법령 미조회 — 시행일 확인 필요"**를 명시한다
3. 조문번호가 불확실하면 **"조문 확인 필요"**로 표기한다. 추정 조문번호를 만들지 않는다
4. 동의율·기한 등 숫자는 **지자체 조례·정관 우선** 원칙을 함께 안내한다
5. 조합원 개인정보는 어떤 경우에도 산출물에 포함하지 않는다 (헌법 5조)
