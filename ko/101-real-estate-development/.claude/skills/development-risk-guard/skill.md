# Development Risk Guard — 낙관편향 차단 규칙

부동산개발 사업계획이 실패하는 방식은 대체로 정해져 있다. **사업이 나빠서가 아니라, 계획 단계에서 좋게 잡아서** 실패한다. 이 스킬은 그 왜곡을 기계적으로 차단한다.

> 근거: Phase 2.5 도메인 리서치 트랙 ④ 실패사례 18건 분석 (`_design/phase_2.5_research_2026-07-28.md`)

---

## 1. 낙관편향 차단 5종 ★ 위반 시 산출물 무효

> **용어 정리** — 차단 규칙 자체는 **5종**이다. 여기에 헌법 2조(재초환 반영)와 부담금 5종 전수 점검
> 2개를 더해 risk-reporter의 **낙관편향 감사표는 7항목**이 된다. 두 숫자는 같은 체계의 다른 단위다.

### 차단 1 — 분양률 100% 가정 금지

전형적 왜곡: "분양은 다 될 것"으로 잡고 수지를 짠다.

**규칙**
- 기준 시나리오의 분양률은 **해당 지역 초기분양률 최근 실적을 상한**으로 캡한다
- 실적 미확인 시 그 사실을 명시하고 보수적으로 잡는다 — 모르면 낙관이 아니라 보수로 간다
- **보수 시나리오는 반드시 별도로 만든다.** 기준안 하나만 제시하는 보고서는 반려 대상
- 지방 사업은 준공후 미분양 리스크를 별도 항목으로 다룬다 (준공후 미분양은 지방에 압도적으로 집중)

**검증 질문**: 분양률 가정의 근거가 "인근 실적"인가 "희망"인가?

### 차단 2 — 공사비 물가상승 미반영 금지

전형적 왜곡: 오늘 단가로 3년 뒤 준공하는 사업의 공사비를 계산한다.

**규칙**
- 착공~준공 기간에 **건설공사비지수 상승분을 반드시 적용**한다
- 참고: 2020년을 100으로 할 때 2024년 130 수준 — 4년간 약 +29%. 연도별 편차가 크므로(급등기 +15%, 안정기 +2%대) 최신 지수를 검색해 반영한다
- 도급계약의 **물가변동 조정식(에스컬레이션) 유무**를 확인하고, 없으면 리스크로 명시한다
- 공사비 단가가 `[가정]`이면 민감도에서 **±20% 범위를 반드시** 검토한다

**검증 질문**: 준공 시점 기준 공사비인가, 오늘 기준 공사비인가?

### 차단 3 — 사업기간 과소 설정 금지

전형적 왜곡: 모든 절차가 순조롭게 진행된다고 가정한다.

**규칙**
- 인허가·이주·소송 지연 버퍼를 **각각 별도 라인으로 계상**한다. 총기간에 녹여서 은폐하지 않는다
- **표준 일정과 지연 일정 두 가지**를 함께 제시한다
- 사업기간은 곧 금융비용이다. 기간이 늘면 이자가 늘고, 이자가 늘면 사업이익이 준다 — 이 연쇄를 수지에 반영한다
- 정비사업은 총회 하자·인가 취소소송 리스크로 **연 단위 지연**이 발생할 수 있다

**검증 질문**: 지연 버퍼가 표에 별도 행으로 보이는가?

### 차단 4 — 금융비용 과소 계상 금지

전형적 왜곡: 브릿지 금리를 본PF 금리로 계산하고, 한 번에 전환된다고 본다.

**규칙**
- **브릿지와 본PF의 금리를 분리**해 계산한다. 브릿지가 통상 높다
- **브릿지 연장 2회를 기본 가정**한다. 1회 전환 성공은 낙관 시나리오
- 취급수수료·금융자문수수료를 **트랜치별로 각각** 계상한다
- 중도금 무이자 조건이면 그 이자를 **시행사 부담으로 수지에 계상**한다
- 금리 민감도 **+1%p / +2%p**를 필수 검토한다

**검증 질문**: 브릿지 이자와 본PF 이자가 별도 행으로 있는가?

### 차단 5 — 예비비 미계상 금지

전형적 왜곡: 계획대로 될 것이므로 예비비가 필요 없다.

**규칙**
- 예비비를 **반드시 계상**하고 비율(총사업비 또는 분양총액 대비)을 명시한다
- 예비비가 흡수해야 할 것을 역산 검증한다 — 공사비 증액분, 소송 손해배상, 지연 금융비용
- 참고: 공사중단 시 손실보상 청구가 도급액의 상당 비율(30%대 사례 확인)에 이를 수 있고, 시공사 계약해지 손배는 수십억~수백억대 실적이 있다
- 예비비가 이를 흡수 못 하면 **"예비비 부족"을 리스크로 명시**한다

**검증 질문**: 예비비가 최악의 시나리오를 감당하는가?

## 2. 함정 회피 체크리스트 10건

사업계획서에 반드시 담겨야 할 항목. 빠지면 결손으로 기록한다.

| # | 항목 | 확인 내용 |
|:-:|---|---|
| 1 | 자기자본비율 | 총사업비 대비 실측치 명기. 규제 로드맵 대비 위치 (시행 시점 명시 필수) |
| 2 | 본PF 전환 조건 | 조건 명문화 + **전환 실패 시 exit 시나리오**(토지 매각·사업권 양도) |
| 3 | 분양률 시나리오 | 기준·보수·최악 3안. 보수안은 지역 실적 하한 적용 |
| 4 | 물가변동 조정식 | 도급계약의 지수·기준시점·적용범위. 배제특약은 무효 위험 검토 |
| 5 | 도급계약 시점 | 실시설계 확정 후 계약이 원칙. 개산 도급 시 증액 상한·검증 절차 사전 합의 |
| 6 | 시공사 신용보강 | 보증총액/자기자본 배수, 부도 시 승계 절차, 책임준공 이중화 |
| 7 | 공사중단 손실보상 | 산정식을 계약에 규정했는가 |
| 8 | 소송 리스크 | 조합설립인가·총회결의·관리처분·시공사 해지별 예상 기간·손배 상한 |
| 9 | 문화재·영향평가 | 지표조사 결과, 발굴 시 공사중지·비용 부담 주체 |
| 10 | 청산 계획 (정비) | 이전고시→청산금→조세채무 변제→분배 순서. **조세 미납 상태 분배 금지** |

## 3. 리스크 매트릭스 표준 8요인

리스크에는 반드시 **조기경보지표(관측 가능한 선행지표)**를 붙인다.

| 리스크 | 통상 가능성 | 영향도 | 조기경보지표 |
|---|:-:|:-:|---|
| 본PF 전환 실패 | 높음 | 치명 | 브릿지 연장 횟수 ≥2, 대주 요구 스프레드 확대 |
| 공사비 증액 분쟁 | 높음 | 대 | 건설공사비지수 분기 상승률, 공사비 검증 신청 |
| 미분양 | 지방 높음 / 수도권 중 | 치명 | 관할 시군구 미분양 재고, 인근 초기분양률, 청약경쟁률 |
| 시공사 부도 | 중 | 치명 | 시평 순위 변동, 폐업·법정관리 동향, 회사채 스프레드 |
| 조합 내부 분쟁 | 중~높음 | 대 | 비대위 결성, 해임총회 발의, 가처분 접수 |
| 인허가 지연 | 중 | 중~대 | 지표조사 결과, 심의 재상정 횟수 |
| 현금청산자 급증 | 중 | 대 | 분양신청률, 추정분담금 대비 시세 |
| 청산·조세 | 낮음 | 중 | 이전고시 후 경과기간, 미확정 소송 잔건 |

## 4. 수치 환각 차단

**입력값이 없으면 만들어내지 않는다.**

| 상황 | 올바른 처리 | 금지 |
|---|---|---|
| 사용자가 공사비를 안 줌 | `[가정] 평당 ○○만원 — 근거: 업계 참고 단가` + 민감도 ±20% | 근거 없이 확정값처럼 기재 |
| 인근 분양가 검색 실패 | "시장데이터 미조회 — 사용자 입력 필요" | 유사 지역 값을 임의 차용 |
| 법령 조문번호 불확실 | "조문 확인 필요" | 그럴듯한 조문번호 생성 |
| 부담금 요율 조례 위임 | "해당 지자체 조례 확인 필요" + 일반 범위 | 단일 값 단정 |
| 재초환 산정 정보 부족 | "산정 불가 — 필요 정보 목록" + **최상단 경고** | 조용히 생략 |

**모든 `[가정]`은 가정 목록 표에 등재**되어야 하며, 최종 사업계획서에 반드시 실린다.

## 5. 자기 점검 — 산출물 제출 전 필수

```
[ ] 분양률 100% 가정이 없는가
[ ] 공사비에 물가상승이 반영되었는가
[ ] 지연 버퍼가 별도 라인으로 있는가
[ ] 브릿지·본PF 이자가 분리되었는가
[ ] 예비비가 계상되었고 최악 시나리오를 흡수하는가
[ ] 재초환·부담금 5종이 전수 점검되었는가 (미해당도 사유 기재)
[ ] 모든 [가정]이 가정 목록에 등재되었는가
[ ] 리스크마다 조기경보지표가 붙었는가
[ ] 조합원 실명·주소가 없는가
[ ] 결론이 데이터에 의해 뒷받침되는가 (희망이 아니라)
```

하나라도 미충족이면 **산출물을 제출하지 않고 보완**한다.
