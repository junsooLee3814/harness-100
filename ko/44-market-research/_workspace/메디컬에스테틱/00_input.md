# 00. 조사 입력 정리 — 올리디아 인도네시아 JV 투자검토

- **작성일**: 2026-07-23
- **목적**: 인도네시아 올리디아 판권 보유사로부터 받은 **주매/판매/유통 조인트벤처(JV) 투자제안**의 검토 근거자료
- **관점 지침**: **중립·객관**. 낙관 시나리오와 보수 시나리오를 병기하고, 근거 없는 낙관(hype) 및 과도한 비관 모두 배제. 추정치는 반드시 산출 근거와 신뢰도를 명시.
- **가독성 지침 (사용자 요청)**: 최종 독자는 **메디컬에스테틱 산업 비전공자(문과 배경)**다. 모든 보고서는
  ① 문서 서두에 「이 보고서를 읽기 전 알아야 할 용어」 표(용어 / 한 줄 정의 / 왜 중요한가) 배치,
  ② 전문용어 첫 등장 시 괄호 설명 병기,
  ③ 각 섹션 끝에 「한 줄 요약(쉬운 말로)」 첨부,
  ④ 금액은 원화 환산 + 감각적 기준점 병기.
  **분석 깊이는 낮추지 않고 표현만 쉽게 한다.**

2. **시장 규모 자료 간 극단적 불일치** — 인도네시아 메디컬 에스테틱 시장을 한 벤더는 2025년 **USD 14.8B**, 다른 벤더는 2028년 **USD 450M**으로 제시. 32배 차이. 벤더 리포트를 그대로 인용하면 안 되는 사안 → 상향식 재산출 필요.

   **▶ 2026-07-23 정정 (05 종합검증에서 확정, 본 기재는 오류였음)**
   - **2026.10.17~18 의무화는 의약품·화장품·사용재 기준**이며, **의료기기에는 그대로 적용되지 않는다.**
   - 의료기기는 **위험등급별 단계 시행**이다: **Class A = 2026.10 / Class B = 2029 / Class C = 2034 / Class D(및 생물학적 제제) = 2039.** (근거: PP 42/2024, BPJPH·LPPOM MUI 공표. ⚠️ Class D의 2039 시점은 **PP 42/2024 부속 별표 원문 미대조 — 실사 확인 필요**)
   - 더말 필러는 **2024.12.19 Kemenkes 공문(FR.03.01/E.V/2728/2024)으로 의료기기 Class D**로 분류되었다. 따라서 올리디아의 할랄 인증 의무 시점은 **빨라도 2034년, 유력하게는 2039년**이며, **본 JV의 투자 회수 기간(3~7년) 내 법적 의무가 발생하지 않는다.**
   - ⚠️ **협상 유의**: 판권사가 "2026년 할랄 의무화 전에 서둘러야 한다"고 시급성을 압박한다면 **그 전제는 사실과 다르다.** 이는 협상 타이밍에서 우리 측 카드다.
   - 다만 **PLLA는 합성 고분자로 동물 유래가 아니라는 점은 유리**하나, **제조공정 보조물질·배지·용매·포장재**까지 추적 대상이므로, **자발적 할랄 취득(규제 리스크가 아닌 마케팅 투자)**을 검토할 때는 원료 추적성 문서를 미리 확보해야 한다.
