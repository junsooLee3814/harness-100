# 프리티/프리텔레콤 생존 로드맵 & 체크리스트

- 작성: research-reviewer · 작성일 2026-07-05 · ★사용자 특별 요청 산출물
- 근거: 01(산업 KSF 7개) + 02(SWOT·전략 매트릭스) + 03(소비자 반응·여정) + 04(트렌드 시사점 8개·시나리오) + 05(교차 검증·정정 반영)
- 전제 수치(05 정정 반영): 프리티 통합 약 56만 회선·점유율 ~5.5% / MVNO 매출 931.6억(부문 이익률 9.2%는 검증 보류) / 누적결손 1,337.7억(1Q26)·계속기업 불확실성 / 1Q26 영업이익 -15.1억 / 101억 조달(유상증자 50 + CB 51) 검토 중 / 전파사용료 90% 감면 '27 시행 예정(연 20억+ 재원, 27억 주장은 재검증 대상)

## 1. 생존 필요 조건 정의 (7개)

산업 KSF 7개(01 §6)와 트렌드 전략 시사점 8개(04 §5)를 통합하고, 소비자 실증(03)과 재무 현실(02 W1)로 보정한 결과다. 진단: **충족 / 부분충족 / 미충족**.

### 조건 1. 재무 정상화 — 계속기업 불확실성 해소 (모든 조건의 관문)
- **왜 필요한가**: 통폐합 국면에서 W1 미해소 사업자는 인수 주체가 아닌 매물로 분류된다(04 T3·시나리오 C). 시장 역풍기(순유출·보조금 전쟁)에는 조달 창구가 먼저 닫힌다(02 WT1, 04 PESTLE L). 재무가 무너지면 조건 2~7은 논의 자체가 무의미.
- **현재 수준**: **미충족** — 누적결손 1,337.7억, 감사보고서 계속기업 강조사항, 1Q26 영업적자 -15.1억, CB 잔액 발행 후 108억 예상 + 최대주주 변경(2026.4) 직후의 지배구조 불확실성(02 W1·W2·W4).
- **격차**: 분기 영업흑자 복귀 + 감사 강조사항 해소 + 오버행 관리. 101억 조달의 용처 설계가 격차 해소의 유일한 지렛대.

### 조건 2. 규모 임계점 도달 — 100만 회선 (점유율 ~10%)
- **왜 필요한가**: 영업이익률 0.2~2.8%의 박리 시장(01 §4, 05 🔴-3 정정)에서 고정비(전산·CS) 흡수와 도매 선구매 물량 협상력은 회선 수가 결정(01 KSF①③). 사후규제 전환으로 "협상력 = 물량 + 연합"이 된 이상(04 T2), 단독 56만은 구조적 열위.
- **현재 수준**: **미충족** — 56만(KT엠 170만의 1/3). 유기적 순증만으로는 순유출 시장에서 도달 불가(02 WO1).
- **격차**: +44만. 경로는 ① 리텐션으로 순유출 방어(하한 유지) ② 15~25만 규모대 2~3개사 통폐합(04 T3 — 매물화 진행 중, 2026 하반기가 매물 최저가 구간 개연성).

### 조건 3. 리텐션 중심 사업모델 전환 — "덜 잃는 자가 이기는 시장"
- **왜 필요한가**: 시장은 1,011만 정점 통과 후 2개월 연속 순유출(01 §1.3), 교체 예정자 48%가 보조금 조건부 이탈 의향(01·03·04 공통). 프리티의 이탈 트리거는 M+7 프로모션 절벽("0원 7개월 → 24,200원", 03 §4.3)로 특정됨. 신규 CAC 전쟁 재참전은 자멸 경로(04 시사점 1).
- **현재 수준**: **미충족** — 1Q26 공격적 마케팅으로 영업적자 재진입(성장-수익 트레이드오프 역주행). 장기고객 락인 장치 사실상 부재(03 여정 맵 "이탈 방어" 칸 공백).
- **격차**: CAC 회수기간 규율, 착지 요금 설계, 장기 자동할인·가족결합, 코호트 이탈 계기판.

### 조건 4. 통합 운영체계 — CS 단일화 + 법인/전산 통합
- **왜 필요한가**: 핵심 자산(3사망)이 고객센터 3원화라는 최다 불만으로 전이되는 구조(03 §4.4 — "자산과 불만의 뿌리가 같다"). CS 통합 없이는 신뢰 서사(조건 6) 불성립(04 T5 전제 조건). 법인 이원화(프리티/프리텔레콤)의 중복 비용은 감면·도매 원가 효과를 상쇄(02 W7·WO3). AICC는 알뜰폰 도입 공백 = 선행자 기회(04 T6).
- **현재 수준**: **미충족** — 망별 고객센터 3개 번호·평일만 운영, "연결 어려움" 최다 불만, 앱 사용량 조회 오류(03 §4.3), 전산·CS 법인별 분산.
- **격차**: 단일 대표번호 + 구독형 AICC + 콜백, 프리티·프리텔레콤 전산/CS 통합, 셀프서비스 앱 안정화.

### 조건 5. 도매 원가·협상력 확보 — 사후규제 시대 적응
- **왜 필요한가**: 원가 결정 메커니즘이 정부 협상 → 사업자 자율 협상으로 이동했고, 첫 협상 결과는 RM만 인하·RS 동결(04 T2). RS 동결은 5G 중용량 전략의 원가 전제를 흔든다. 3사망 복수 소싱은 프리티만 가진 경쟁 입찰 지렛대(01 KSF③).
- **현재 수준**: **부분충족** — 3사망 소싱 구조(경쟁 입찰 잠재력)와 자체 빌링은 보유. 그러나 단독 물량 56만으로는 선구매 커밋 협상력 미달.
- **격차**: 독립계 공동 협상 채널 주도, 통폐합에 의한 물량 확대(조건 2와 직결), 사전규제 부활 입법 대관.

### 조건 6. 정책 수혜 자격 유지 + "정책 이후"의 자산 구축
- **왜 필요한가**: 독립계의 원가 격차는 정책(전파사용료 90% 감면 '27~, 도매 보호)이 만든 것(01 KSF④)이며, 도매 축은 이미 약화됨(05 인사이트 2). 감면 시행령 개정(2026 하반기)·중소 지위 요건이 흔들리면 원가 우위 소멸(02 T6). 동시에 정책이 사라져도 남는 자산 — 브랜드 신뢰·보안 서사 — 을 2026 하반기 골든타임에 구축해야 함(03 §5.4, 04 T5).
- **현재 수준**: **부분충족** — 중소 지위·감면 자격 보유, 평판 1위('26.6 단월)·만족도 상위권 이력 보유. 그러나 "1위" 자산은 프로모션 의존적 임차 자산(03 §5.2)이고, 보안·신뢰 서사는 미착수(망 전환 보장·유심보호 상품화 부재).
- **격차**: 시행령 개정 모니터링·대관, 수상 이력의 신뢰 서사 전환("3사망 다 되는 알뜰폰" 소비자 언어화), 유심보호 기본 탑재·망 전환 보장 프로그램.

### 조건 7. ARPU 다변화 — MNO 비경합 니치에서
- **왜 필요한가**: 프리티 평균 ARPU 1.37만 원(역산)은 시장 평균(1.6만) 이하(02 §3.1) — 회선 정체 국면에서 저ARPU는 매출 성장의 이중 족쇄(01 KSF⑦). 단, 5G 정면 승부는 RS 동결·MNO 통합요금제 국면에서 불리(04 시사점 7). 풀MVNO 설비는 규모 300만+ 회선에서 경제성 성립 — 프리티 규모의 5배로 시기상조(04 기술 로드맵).
- **현재 수준**: **부분충족** — eSIM·해외유심·선불·B2B/M2M 포트폴리오와 프리티CA(캐나다 Telus망, Active 약 3,000회선) 보유. 그러나 매출 기여는 아직 니치 수준이고 eSIM 즉시개통 전면화 미완.
- **격차**: eSIM 세컨드심·외국인 선불 확대, B2B/M2M 영업 체계화, MVNE 위탁운영 상품화(금융권 수요 — 04 T4), 프리티CA 손익분기 관리.

> **조건 간 위계**: 조건 1(재무)이 관문 → 조건 3·4(리텐션·통합 운영)가 손익 엔진 → 조건 2·5(규모·협상력)가 구조 개선 → 조건 6·7(정책+서사·ARPU)이 지속 가능성. 01의 요약("①~④ 없이는 이익 불가, ⑤~⑦ 없이는 성장 불가")과 정합.

## 2. 생존 로드맵 (3 Phase)

### Phase 1. 즉시 (0~6개월, 2026.7~2026.12) — "지혈과 재장전"

| 항목 | 내용 |
|---|---|
| **목표** | 분기 영업흑자 복귀 가시화 + 이탈 출혈 지점 봉합 + 통폐합 기회 정찰 |
| **핵심 과제** | ① **101억 조달 확정 및 용처 배분** — 권고 배분: 손익분기 방어·운전자금 ~40%, 전산/CS 통합 및 AICC ~30%, 경자산 인수(가입자 이관)·MVNE 준비 ~20%, 예비 ~10%. 신규 CAC 프로모션 투입 금지(04 시사점 2) ② **CAC 회수기간 상한 규율(12개월) 도입** — 1Q26식 공격 마케팅 중단(02 WT2) ③ **M+7 절벽 해소** — 프로모션 착지 요금 재설계(완만한 정상화 커브 + 종료 60일 전 선제 안내·전환 제안, 03 페르소나 A) ④ **코호트 이탈 대시보드 + 해지자 서베이** 가동(03 §7 1순위) ⑤ **유심보호 서비스 기본 탑재** — 보안 서사의 물증, 저비용(04 기술 로드맵) ⑥ **매물 파이프라인 정찰** — 15~25만 규모대(아이즈비전·에넥스·스마텔 등) 접촉 개시: 감면 시행 전 2026 하반기가 매물 최저가 구간(04 T3) ⑦ **조기 경보 체계 가동**(§4) |
| **담당 기능** | CFO/IR(①②), 상품·마케팅(③), 데이터/CRM(④), 상품(⑤), 전략/M&A(⑥), 전략기획(⑦) |
| **선행 조건** | 이사회의 "리텐션 우선" 전략 승인(점유율 통계 후퇴 감수), 조달 클로징 |
| **성공 지표 (KPI)** | 월 순증감 ≥ -0.3%/월(시장 순유출률 이하), M+7 코호트 잔존율 +10%p, 4Q26 영업이익 흑자 전환, 마케팅비/매출 비율 전년 동기 대비 -20%, 매물 실사 착수 1건+ |

### Phase 2. 단기 (6~18개월, 2027.1~2027.12) — "통합 완성과 서사 전환"

| 항목 | 내용 |
|---|---|
| **목표** | 통합 CS·전산 완성으로 3사망 자산 활성화 + 감면 재원의 리텐션 전환 + 첫 비유기적 성장 |
| **핵심 과제** | ① **고객센터 단일 대표번호 통합 + 구독형 AICC 도입**(알뜰폰 선행자 포지션, CAPEX 회피 — 04 T6) + 콜백·챗봇 선처리, 셀프서비스 앱(사용량 조회) 안정화 ② **프리티·프리텔레콤 전산/CS 통합** — 법인 이원화 중복 비용 해소(02 WO3), 감면·도매 효과를 원가 절감으로 온전히 전환 ③ **전파사용료 90% 감면 시행('27) 재원(연 20억+ 추정)을 장기고객 자동할인·가족결합에 전액 투입**(02 §8-2) — 신규 보조금 투입 금지 ④ **"믿을 수 있는 최저가 + 망 선택권" 캠페인** — 망 전환 보장 프로그램 상품화(위약금 없이 망 변경), "3사망 다 되는 알뜰폰" 소비자 언어화(03 §3 기회, 04 T5) ⑤ **가족 통합 관리 상품 출시** — 복수 회선·복수 망 통합 청구/관리(03 JTBD 유일 미충족 Job, 페르소나 B) ⑥ **소형사 1건 가입자 이관형 인수 실행**(경자산 방식 우선 — 04 T3) ⑦ **MVNE/위탁운영 B2B 씨뿌리기** — 금융권(KB·우리·후속 진입 은행) 대상 선제 제안(02 §8-5) ⑧ **독립계 공동 도매 협상 주도**(협회 채널) + 사전규제 부활·60% 제한법 입법 대관 |
| **담당 기능** | CS/운영·IT(①②), 상품·마케팅(③④⑤), 전략/M&A(⑥), B2B사업(⑦), 대외협력(⑧) |
| **선행 조건** | Phase 1의 4Q26 흑자 전환(③⑥의 전제), 감면 시행령 개정 확정(2026 하반기), AICC 벤더 선정 |
| **성공 지표 (KPI)** | CS 불만 언급률(리뷰·VOC) 50% 감소, 고객센터 응답률 90%+, 컨슈머인사이트 만족도 3위 이내 유지, 연간 영업흑자(연결), 가입자 60만+ 회복(이관 포함), 가족결합 가입 5만 회선, MVNE 제안 2건+ 발송, 감사보고서 계속기업 강조사항 해소 |

### Phase 3. 중기 (18~36개월, 2028.1~2029.6) — "독립계 구심점과 구조적 지위"

| 항목 | 내용 |
|---|---|
| **목표** | 80~100만 회선(점유율 8~10%) 도달로 도매 협상 지위 격상 + ARPU 믹스 개선 + 신사업 수익화 |
| **핵심 과제** | ① **통폐합 2~3건 누적 → 80~100만 회선** — 인수 후 통합(PMI): 자체 빌링으로 이관 원가 최소화(02 §8-3) ② **도매 협상 지위 격상** — 물량 기반 선구매 커밋 + 3사망 경쟁 입찰 구도 상시화(04 T2) ③ **ARPU 믹스 개선** — eSIM 세컨드심(월 0~5천 원 회선 수 방어), 외국인 선불(다국어 CS), B2B/M2M 영업 체계화(01 KSF⑦), 목표 평균 ARPU 1.37만 → 1.5만 ④ **MVNE 수주 1건+ 실현** — 자체 빌링의 플랫폼화, 위탁 고객·소매 브랜드 이해상충 규정 정비 ⑤ **프리티CA** — Active 3,000회선의 손익분기 관리, 확장은 국내 재무 정상화 확인 후 ⑥ **5G는 방어 라인업 유지** — RS 인하 재개 확인 전 주력화 금지, 풀MVNO 설비 투자 보류 지속(04 기술 로드맵) |
| **담당 기능** | 전략/M&A·PMI(①), 구매/도매(②), 상품·B2B(③), 플랫폼사업(④), 해외사업(⑤) |
| **선행 조건** | Phase 2의 연간 흑자·강조사항 해소(①의 자격 요건), 인수 자금 조달(추가 전환성 조달은 실적 가시성 확보 후 — 02 WT3) |
| **성공 지표 (KPI)** | 가입자 80만+(점유율 8%+), MVNO 부문 영업이익률 5%+ 안정화(04 시나리오 A 수준), 평균 ARPU 1.5만 원, MVNE 수주 1건+, 도매대가 실효 인하율 업계 평균 초과 달성 |

## 6. 한 장 요약

> **프리티의 생존 방정식**: (재무 정상화)를 관문으로, (리텐션 전환 × CS 통합)으로 손익을 지키고, (통폐합 × 도매 협상력)으로 규모의 벽을 넘으며, (정책 수혜 유지 + 3사망 신뢰 서사)로 정책 이후를 대비하고, (니치 ARPU 다변화)로 성장 여력을 보탠다. — 기본 시나리오(50%)의 시장은 "덜 잃는 자가 이기는 시장"이며, 2026 하반기는 매물 최저가 구간이자 신뢰 서사 전환의 골든타임이라는 이중의 시간 창이다.
