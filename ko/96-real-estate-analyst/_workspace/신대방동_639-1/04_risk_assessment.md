## 1. 구조적 리스크

### 1-1. 접도(진입로) 미확보 리스크 — [Critical]

| 항목 | 내용 |
|------|------|
| **리스크 내용** | 현황 보행전용도로만 접해 있어 건축법 제44조 접도 의무 미충족 → 건축 인허가 법적 불가 |
| **발생확률** | **상 (이미 발생 · 확정)** |
| **영향도** | **상 (사업 전체 무산 가능)** |
| **등급** | **Critical** |

**상세 분석:**

- 건축법 제44조: 건축물 대지는 너비 4m 이상 도로에 2m 이상 접해야 함
- 639-1번지는 현황 진입로가 보행전용도로로, 차량 통행 불가 → 접도 의무 미충족
- 현재 상태로는 639-1(전·나지), 639-2(위반건축물), 산144-4(임야) 모두 **적법한 건축 행위 불가**
- 접도 해결 없이는 어떠한 개발 시나리오도 현실화 불가능

**해결 시나리오별 리스크:**

| 해결 방안 | 성공 가능성 | 추가 비용 | 리스크 포인트 |
|----------|-----------|---------|------------|
| 632-68 그린빌 매입 (4m 도로 확보) | 중간 | 16~32억원 [추정치] | 8세대 전원 매도 동의 필요. 1인 거부 시 전체 무산 |
| 그린빌 매입 후 6m 도로 확폭 | 낮음 | 추가 도로 확폭 비용 불확실 | 서울시 도로 편입 절차 복잡. 이행 보장 없음 |
| 정비사업 편입 (접도 자동 해소) | 중간~높음 | 별도 비용 불필요 | 구역 편입 여부 현재 미확인 |
| 공원 측(북측) 도로 활용 | 불가 | — | 도시공원법 상 사유지 접근 허가 불가 |

**대응 전략: 회피/전가**
- **즉시 조치:** 동작구청 도시재생과에 639번지 정비구역 편입 여부 서면 질의 (1~2주 내)
- **매각 전략:** 현 상태 매각 시 반드시 매수자에게 사전 서면 고지 필수 (고지 누락 시 손해배상 청구 리스크 발생)
- **중장기:** 그린빌 소유자 사전 접촉 및 패키지 딜 구조 검토 병행
- **최선 전략:** 정비구역 편입 확인 후 매각 일정 결정

### 1-2. 위반건축물 리스크 (639-2) — [High]

| 항목 | 내용 |
|------|------|
| **리스크 내용** | 639-2 단독주택(160㎡, 지하1/지상2층) 위반건축물 — 양성화 가능 여부 미확인 |
| **발생확률** | **상 (위반 사실은 확정, 양성화 불가 시 리스크 현실화)** |
| **영향도** | **중** |
| **등급** | **High** |

**상세 분석:**

- 위반건축물은 매수자가 취득 시 이행강제금 납부 의무 승계 가능
- 이행강제금: 건축법 제80조 기준 시가표준액의 일정 비율, 연 1~2회 부과
- 양성화(허가 취득) 가능 여부에 따라 하자 범위가 결정적으로 달라짐
- 양성화 불가 시: 철거 강제 가능성 → 건물 가치 제로 + 철거 비용 매수자 부담

**양성화 가능 시나리오:**
- 건축 당시 규정 위반 내용이 현재 기준으로 적법화 가능한 경우
- 과거 미신고 증축의 경우 경미한 위반으로 처리 가능한 경우
- 접도 미확보로 인해 기존 건물 자체도 허가 요건 미충족일 경우 양성화 불가 가능성 높음

**대응 전략: 완화**
- 동작구청 건축과에 위반 내역 및 양성화 가능 여부 공식 확인 (현장 확인 필요)
- 매각 조건에 "위반건축물 현 상태 인수" 명시 또는 가격 반영 협상
- 양성화 불가 확정 시: 매각가에서 철거 비용 및 이행강제금 현재가치 공제 협상

### 2-1. 공유자 비동의 리스크 — [Critical]

| 항목 | 내용 |
|------|------|

| **발생확률** | **상** |

**상세 분석:**

- 공유물 처분(매각)은 **공유자 전원의 동의** 필요 (민법 제264조)
- 의뢰인 이옥준은 공유자 중 1인 → 단독 매각 권한 없음
- 재외국민·재미 거주자 포함 시 연락 자체가 장기화 가능
- 해외 거주 공유자의 경우 위임장 공증(국내 영사관 또는 현지 공증) 절차 필요
- 공유자 중 1인이라도 반대 시: 매각 자체 불가능

**최악 시나리오 분기:**
1. 공유자 연락 두절(장기 해외 거주): 매각 보류 장기화 → 이행강제금·재산세 누적
2. 공유자 가격 이견(희망 매각가 불일치): 협상 장기화
3. 공유자 중 채권자 별도 압류 추가 가능성: 권리 관계 추가 복잡화

**법적 대안 (공유물 분할 청구):**
- 공유자 간 협의 불성립 시 법원에 공유물 분할 청구 가능 (민법 제269조)
- 단, 분할 소송은 1~3년 소요, 경매로 처분될 경우 시가 대비 30~50% 할인 가능

**대응 전략: 완화/전가**
- 즉시 모든 공유자 소재 파악 및 연락 착수
- 재외 공유자 대상 해외 법무법인 또는 현지 교민 네트워크 활용 위임 협의
- 공유자 전원 합의 가능성을 매각 선행 조건으로 설정
- 만약 합의 불발 시 공유물 분할 청구 옵션 검토 (매각대행 계약 시 이 시나리오 포함 조건 설정 권고)

- 동작구청이 압류 해제를 조건으로 전액 즉시 납부 요구 시 유동성 리스크 발생

**대응 전략: 완화**

## 3. 규제·인허가 리스크

### 3-1. 정비사업 편입 불확실성 리스크 — [High]

| 항목 | 내용 |
|------|------|
| **리스크 내용** | 신대방역세권 도시환경정비사업 구역에 639번지 편입 여부 미확정 |
| **발생확률** | **중** (편입 여부 자체가 불확실) |
| **영향도** | **상** (편입/미편입에 따라 매각가 100억원 이상 차이 가능) |
| **등급** | **High** |

**상세 분석:**

- 신대방역세권 재개발(2026.04 대우건설 시공사 선정 완료, 1,525세대)과 639번지의 관계

## 7. 복합 리스크 시나리오 (최악 시나리오 분석)

### 7-1. 최악 시나리오: 3중 동시 발생

**시나리오: 정비사업 미편입 + 접도 미해결 + 공유자 갈등 동시 발생**

| 단계 | 상황 | 영향 |
|------|------|------|
| 1단계 | 정비구역 경계 확정 → 639번지 미포함 공식 확인 | 시나리오 A 완전 소멸. 기대 매각가 130~250억 → 75~95억으로 급락 |
| 2단계 | 그린빌 협상 결렬 (소유자 1인 거부) | 단독 개발 시나리오 B 불가. 시나리오 C(현상 유지)로 귀결 |
| 3단계 | 공유자 이견으로 매각 동의 무산 | 매각 프로세스 전면 중단 |
| 4단계 (장기화) | 공유물 분할 청구 소송 (1~3년) | 경매 강제 처분 리스크 → 시세 30~50% 할인 매각 |

**3중 동시 발생 시 최악 추정가:**

| 구분 | 추정 처분가 | 공제 후 순수령 |
|------|-----------|-------------|
| 공유물 분할 경매 | 31~47억원 [추정치] | 권리 정리 비용 공제 시 0~27억원 |
| 총 손실 (투자원가 대비) | 원가 불명 (취득 시기·금액 미확인) | — |

> **결론:** 3중 복합 리스크 동시 발생 시 매도자 실수령액이 0~27억원 수준으로 대폭 감소. 현재 92.3억 목표가의 0~29% 수준. 이는 단순 손실을 넘어 보유 비용(이행강제금, 재산세, 소송비) 고려 시 실질 손실 발생 가능.

**대응 방향:**
- 3중 복합 리스크 중 하나라도 사전에 해소하면 시나리오 차단 가능
- 우선순위: ①정비구역 편입 확인 → ②공유자 전원 동의 확보 → ③그린빌 협상 (이 순서가 최적)

---

### 7-2. 경매 강제 처분 리스크 시나리오

**시나리오: 교보생명 채무 연체 → 임의 경매 → 강제 처분**

| 단계 | 내용 |
|------|------|
| 트리거 | 근저당 채무(교보생명 13.5억) 연체 발생 |
| 1개월 | 교보생명 경매 신청 |
| 3~6개월 | 경매 개시 → 감정평가 → 입찰 |
| 결과 | 시세 대비 30~50% 할인 낙찰 예상 (접도 미확보 특수 물건) [추정치] |
| 경매 예상 낙찰가 | 30~55억원 [추정치] |
| 공유자 배분 후 의뢰인 수령 | 지분 비율에 따라 극소 |

> 경매 강제 처분은 최악의 결과. 현재 채무 연체 여부 확인이 최우선.

**대응 전략: 회피**
- 교보생명 채권 연체 여부 즉시 확인
- 연체 사실 있을 경우 긴급 상환 협의 또는 매각 선행 조치

### 7-3. 금리 2%p 상승 + PF 조달 불가 시나리오

**전제:** 기준금리 2.5% → 4.5%로 상승, 브리지론 8~10%, 본 PF 조달 불가

| 항목 | 현재 시나리오 | 금리 +2%p 시나리오 |
|------|------------|----------------|
| 개발사 매수 유인 | 낮음 (접도 미확보) | 매우 낮음 |
| 가능 매수자 유형 | 자기자금 100% 보유 시행사 + 정비사업 투자자 | 정비사업 투자자 (편입 전제) |
| 매각가 협상 영향 | 현재 92.3억 목표 | 70~80억원으로 하향 압박 [추정치] |
| 예상 매각 기간 | 6개월~1년 | 1~2년 이상 |

> 금리 2%p 상승 시 사실상 개발 목적 매수자가 시장에서 이탈. 매각대행 전략을 '정비사업 편입 기대 장기 투자자' 중심으로 전환 필요.
